## 30秒要約

ポーカー大会の経理管理ツール（スタッフ125名規模の給与計算・出退勤・領収書・契約書）を、2026年4月から約4ヶ月・102コミットで開発。7月末に木村さんのご指摘4点（実サーバ移行／Basic認証／DBスキーマ提出／監視）へ対応し、Railway上のnginx＋Basic認証構成へ移行済み。8月は本番同等環境での運用テストを3周実施し、金額計算を全件手計算と突合。発見した欠陥は修正・回帰テスト化済み。残課題は本書末尾に列挙。

## 1. 現在のシステム構成

- **アプリ**: Streamlit（Python 3.12）× Supabase（PostgreSQL）。テーブル15・列197（スキーマ資料は別紙 2026-08-06版）
- **本番**: Railway。nginx リバースプロキシで二段構成
  - 管理画面（`/`）: Basic認証 ＋ アプリ内ログイン（二段。WebSocketも認証の内側）
  - スタッフ向け（`/staff/…`）: 認証免除だが**管理機能のファイルを持たない別プロセス**（URLを直接叩いても管理側へ到達できない）
- **URL・ファイル名**: 2バイト文字を全廃（`ccb6c17`, `08b9127`）
- **監視**: アプリ内例外・ログイン連続失敗のメール通知＋起動セルフテスト8項目（`36dc1c0`, `86e9267`）
- **CI**: GitHub Actions でテスト自動実行（`a53e448`）。本番と同じ Python 3.12 に統一（`201e57f`）
