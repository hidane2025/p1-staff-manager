## 先に知っておいてほしい3つ

### ① ヒダネの商談は「売る」ではなく「判定する」

商品は助成金とセットで価格が成立している。助成金が使えない相手に売ると、40万円/人がそのまま相手の負担になる。
だから商談の前半でやるのは提案ではなく、**条件に当てはまるかの確認**。

### ② 最初の質問はいつも同じ

> **「従業員さんは何名ですか？　雇用保険には入られてますか？」**

従業員0名なら助成金は使えない。ここで全部が決まる。

### ③ 2026年8月3日の改正を知らないと事故る ⚠️

**2週間前**に施行された改正で、「**全社員向けAIリテラシー研修**」「**汎用的なプロンプト講座**」は、8/3以降に提出する計画届から**助成対象外**になった。

ヒダネの主力はAI研修と動画研修。**そのまま売ると対象外になる。**
「誰の・どの職務のための訓練か」を特定した設計に組み替える必要がある。

→ 詳細は [02_助成金の基礎.md 第5章](02_助成金の基礎.md)

## 使ってはいけない言葉

> 「ぜひ」「お得」「今だけ」「特別」「革命的」「最強」
> 「確実に受給できます」「必ず通ります」

---

## 数字を口に出す前に

この資料の数字は二次情報（社労士事務所・研修会社の解説記事）から集めたもので、**出所によって食い違う箇所があった**（大企業の助成率など）。

**金額を相手に伝える前に、必ず提携社労士に確認を通すこと。**
わからないときは「確認して折り返します」でいい。それは負けではない。
