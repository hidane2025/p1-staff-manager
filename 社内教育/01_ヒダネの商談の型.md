# 01. ヒダネの商談の型

対象：祖父江さん（営業担当）
作成日：2026-08-16

---

## 0. 最初に頭に入れてほしい一文

> **ヒダネの商談は「売る」ではなく「条件に当てはまるかを確認して、当てはまる会社にだけ勧める」仕事。**

理由は単純で、うちの商品は**国の助成金とセットで初めて価格が成立する**から。
助成金が使えない相手に売ると、40万円/人という価格がそのまま相手にのしかかる。それは相手にとって損だし、うちにとっても後で必ず問題になる。

だから商談の前半でやることは、提案ではなく**判定**。ここを飛ばして提案から入るのが、新人が一番やりがちな事故。

---

## 1. ヒダネが売っているものの構造

### 3本柱

| 柱 | 意味 | 相手にとっての価値 |
|---|---|---|
| **助成金活用** | 国の制度で研修費の一部が戻る | 出ていくお金が減る |
| **外注費削減** | 動画やSNSを外注せず社内で作れるようにする | 毎月の固定費が減る |
| **業務内製化** | AIを社内で使えるようにする | 人を増やさず処理量が増える |

この3つは**別々の商品ではなく、同じ話の3つの言い方**。相手が何に反応するかで、どの言い方から入るかを変える。

- 社長がコスト意識強め → 「外注費」から
- 人手不足で困ってる → 「内製化」から
- とにかく予算がない → 「助成金」から

### 商品ラインナップ

| 記号 | 商品 | 価格 | 時間 | 形式 |
|---|---|---|---|---|
| A | AI活用研修（ヒダネAI） | 40万円/人（税込） | 15時間 | 対面 or オンライン |
| B | SNS動画編集・運用研修 | 40万円/人（税込）× 最大3コース | 15時間 | 対面 or オンライン |
| C | DX・AIリスキリング eラーニング（LMS） | 定額24万 / カスタム30万 / 伴走40万（税別/人） | — | eラーニング |
| — | SNS運用代行 | 月30万円〜 | — | 継続 |

コース構成は **AI研修5コース＋動画内製化3コース＝計8コース**、各12〜15時間。

**覚え方：** A と B は「人を育てる」、SNS運用代行は「代わりにやる」。
相手が「自分でできるようになりたい」なら A/B、「丸投げしたい」なら運用代行。ここを取り違えると提案がズレる。

## 2. 商談の30分の型

ヒダネの商談は30分を4つに割る。**時間配分そのものが型**なので、まずこれを体に入れる。

| 時間 | やること | 話す割合（自分:相手） |
|---|---|---|
| 0〜3分 | アイスブレイク＋本日の流れ説明 | 7 : 3 |
| 3〜10分 | **ヒアリング** | **3 : 7** |
| 10〜20分 | 提案説明 | 7 : 3 |
| 20〜25分 | 質疑応答 | 3 : 7 |
| 25〜30分 | クロージング | 5 : 5 |

### 【0〜3分】アイスブレイク＋流れ説明

やること：**今日の30分で何をするかを先に宣言する。**

```
「本日はお時間ありがとうございます。
 30分いただいて、前半で御社の状況をお聞かせいただいて、
 後半で、もし合いそうなら弊社でできることをご説明する、
 という流れで考えています。
 合わなそうならその場で正直にお伝えしますので、そのつもりでお聞きください。」
```

**「合わなそうなら正直に言う」を最初に宣言するのが、ヒダネのやり方。**
これを言っておくと、後半で「今回は合いません」と言っても裏切りにならない。逆に信用が上がる。

### 【3〜10分】ヒアリング — ここが本番

**相手に7割話させる。** 自分が話したくなったら、質問に変換する。

聞く順番は次章のヒアリングシート参照。

**この7分間で絶対に確認すること（これを聞かずに提案したら失敗）：**
1. 従業員数と、雇用保険に入っているか
2. 中小企業か大企業か
3. 誰に、何ができるようになってほしいのか（＝職務）

### 【10〜20分】提案説明

**ヒアリングで出た言葉を使って説明する。** ここが一番差が出るところ。

悪い例：
> 「弊社のAI研修は15時間で、実技7割・座学3割の構成でして…」（＝商品説明）

良い例：
> 「さっき『見積書を作るのに1件30分かかる』とおっしゃってましたよね。
>  そこが2〜3分になるところまでを、研修の成果物として作ります。」（＝相手の課題の話）

**原則：商品の話をするな。相手の課題が解決した状態の話をしろ。**

### 【20〜25分】質疑応答

想定Q&Aは第5章。**知らないことは「調べて折り返します」と言う。**
特に助成金は、曖昧なまま答えると後で取り返しがつかない。「社労士に確認します」は恥ではなく、正しい対応。

### 【25〜30分】クロージング — 温度感で3段階

相手の温度感を見て、出す球を変える。

| 温度感 | サイン | 出す球 |
|---|---|---|
| **高い** | 「いつから？」「いくら？」と自分から聞いてくる | 計画届の締切から逆算した日程を提示。次回日程をその場で押さえる |
| **中くらい** | 「検討します」「社内で相談します」 | 稟議に使える検討資料を送る約束。**期限を切る**（「今週中にお送りします」） |
| **低い** | 反応が薄い、質問が出ない | 深追いしない。「制度が変わったらまたご連絡します」で終える |

**温度が低い相手を押さない。** これはヒダネのルール。押して取った案件は後で必ず崩れる。

## 3. ヒアリングの型

### 判定質問（これを聞かないと何も始まらない）

| # | 質問 | 何を判定しているか |
|---|---|---|
| **Q1** | **「従業員さんは何名ですか？　雇用保険には入られてますか？」** | **助成金が使えるかの大前提。0名なら助成金は使えない** |
| Q2 | 「資本金と従業員数だと、中小企業さんの区分になりますか？」 | 助成率が変わる（中小75% / 大企業60%） |
| Q3 | 「今年度、他に助成金を使われた研修はありますか？」 | 同一労働者は年度3回まで。eラーニングは年度1回まで |

**Q1で「従業員はいません」と返ってきたら、そこで助成金の話は終わり。**
その場合は正直にそう伝えて、別の制度（デジタル化・AI導入補助金、小規模事業者持続化補助金）を調べる価値がある、という情報提供に切り替える。

### 課題を掘る質問

| # | 質問 | 狙い |
|---|---|---|
| Q4 | 「今、社内で一番時間を食っている作業って何ですか？」 | AI研修の入口 |
| Q5 | 「動画やSNSは、今どうされてますか？　外注ですか、社内ですか？」 | 動画内製化・運用代行の入口。外注なら金額も聞く |
| Q6 | 「その作業、**誰が**やってますか？」 | **8/3改正で「職務」の特定が必須になった（後述）** |
| Q7 | 「研修をやるとしたら、何人くらいが対象になりそうですか？」 | 見積の母数 |
| Q8 | 「教育や研修に、これまで予算をつけたことはありますか？」 | 意思決定の経験値 |
| Q9 | 「これを決めるのは、どなたになりますか？」 | 決裁者の確認。ここを聞き忘れると最後で止まる |

### 掘り方のコツ

**「なぜ」ではなく「具体的には」で掘る。**

```
✕「なぜ外注されてるんですか？」  → 相手が責められた気になる
◯「具体的には、月に何本くらい外注されてます？」 → 事実が出てくる
◯「1本あたりだと、だいたいおいくらくらいですか？」 → 金額が出てくる
```

金額が出たら、それがそのまま提案の根拠になる。
例）動画1本3万円 × 月10本＝月30万円 → 「内製化できれば年360万円が浮く計算になります」

## 4. 提案の作り方（金額の出し方）

### 対面/オンライン研修（A・B）の場合

```
研修費用   = 受講人数 × 40万円
経費助成   = 研修費用 × 75%（中小企業の場合）
             ※1人1訓練あたりの上限あり（10〜100時間未満なら30万円）
賃金助成   = 受講人数 × 15時間 × 1,000円（中小企業の場合）
実質負担   = 研修費用 − 経費助成 − 賃金助成
```

**5名で計算してみる：**

| 項目 | 金額 |
|---|---|
| 研修費用 | 5名 × 40万円 = **200万円** |
| 経費助成 | 200万円 × 75% = 150万円（1人30万円＝上限ちょうど） |
| 賃金助成 | 5名 × 15時間 × 1,000円 = 7.5万円 |
| **実質負担** | **42.5万円**（1人あたり約8.5万円） |

※ ヒダネのサイトで言っている「実質10万円/人」は、**対面・15時間・中小企業**という条件下の数字。条件が変わると変わる。

### eラーニング（C）の場合 — 計算が違うので注意

**eラーニングは「経費助成のみ・賃金助成なし」＋「上限15万円」。**

| プラン | 単価 | ×75% | 上限適用後 | 実質負担 |
|---|---|---|---|---|
| 定額制 | 24万円 | 18万円 | **15万円** | 9万円 |
| カスタム | 30万円 | 22.5万円 | **15万円** | 15万円 |
| 伴走型 | 40万円 | 30万円 | **15万円** | 25万円 |

**ここを間違えると大事故。** eラーニングに「実質10万円」と言ってはいけない。

### 受講人数がわからないとき

5名で仮置きして「受講人数に応じて変動します」と注記する。勝手に多く見積もらない。

### 概算に必ず付ける注記（コピペして使う）

> ※助成金の受給には審査があります。企業の状況により受給額や要件が異なる場合がありますので、詳細は個別にご確認ください。

## 5. 想定Q&A

| 相手の質問 | 返し方 |
|---|---|
| 「本当に助成金おりるんですか？」 | 「審査があるので、確実とは申し上げられません。ただ、条件の確認は提携している社労士と一緒に事前にやります。**通りそうにない場合は、その時点で正直にお伝えします**」 |
| 「うちみたいな小さい会社でも使えますか？」 | 「従業員さんを雇用保険に入れて雇われていれば、規模は問いません。むしろ中小企業のほうが助成率は高いです（75%）」 |
| 「手続きが大変なんじゃないですか？」 | 「計画届と支給申請の2回、書類の提出があります。そこは社労士と弊社で進めますが、御社にご用意いただく書類もあります。何が必要かは最初にリストでお渡しします」 ← **「全部やります」と言わない** |
| 「すぐ始められますか？」 | 「**計画届を訓練開始の1か月前までに出す必要がある**ので、逆算すると最短で◯月◯日開始になります」 ← 即答できるようにしておく |
| 「他社と何が違うんですか？」 | 「弊社は社員3人とAI社員12人で会社を回しています。**自分たちが実際に使って回している**ので、教える内容が実務ベースです」 |
| 「AIリテラシー研修をやりたい」 | 「そのままだと**助成金の対象外になる可能性が高い**です（8/3の改正）。職務に直結する形に設計し直せば残せる余地があるので、どの部署の、どの業務向けかを一緒に決めさせてください」 ← **第2章の改正を知らないと答えられない** |
| 「見積もりだけもらえますか？」 | 「お出しします。ただ**人数と対象業務が決まらないと金額が動く**ので、そこだけ先に伺わせてください」 |
| 「今すぐは無理」 | 「承知しました。**この制度は令和8年度で終了予定**なので、もし年度内にお考えがあれば逆算だけしておきます。急かす意図はないです」 ← 事実の共有であって、煽りではない |

## 6. NG集（ヒダネのトーンルール）

### 言ってはいけない言葉

> 「ぜひ」「お得」「今だけ」「特別」「革命的」「最強」

理由：これらは相手の判断を急かす言葉。ヒダネは信用で仕事を取る会社なので使わない。

### 助成金について言ってはいけない表現

| ✕ NG | ◯ OK |
|---|---|
| 「確実に受給できます」 | 「条件を満たせば申請できます」 |
| 「必ず通ります」 | 「活用の可能性があります」 |
| 「実質10万円です」（無条件に） | 「対面・15時間・中小企業の場合、実質10万円程度になります」 |

### 課題の指摘の仕方

| ✕ NG | ◯ OK |
|---|---|
| 「御社はDXが遅れています」 | 「◯◯のような課題をお持ちではないでしょうか」 |
| 「このままだと取り残されます」 | （言わない） |

**課題は仮説として出す。断定しない。** 相手の会社のことは相手のほうが詳しい。

### 絶対にやってはいけないこと

- ❌ 支払い能力を確認せずに高額契約を勧める（**適合性原則違反**。2025年12月に行政処分の実例あり）
- ❌ 助成金の可否を確認しないまま「実質10万円」と言う
- ❌ 契約や法務の話をその場で確定させる（**中野さんの確認が必要**）
- ❌ 知らないことを推測で答える

## 7. 商談後にやること

| いつ | やること | 使うツール |
|---|---|---|
| 当日中 | ヒアリング内容を記録 | 商談メモ |
| 当日〜翌日 | フォローメール送付 | `hidane-followup-email` スキル |
| 商談後 | Notionプロジェクトdbに登録 | `hidane-sales-pipeline` の PHASE 5 |
| 失注時 | 失注理由を分析して記録 | `hidane-lost-analysis` スキル |
| 受注時 | キックオフ・計画届準備 | `hidane-onboarding` スキル |

**失注も必ず記録する。** なぜ落ちたかが溜まると、次の商談が強くなる。
