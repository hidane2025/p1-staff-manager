# 02. 助成金の基礎 — 営業が最低限わかっておくこと

対象：祖父江さん
作成日：2026-08-16

> **この章の位置づけ**
> ヒダネの商品は助成金とセットで価格が成立している。つまり**助成金を理解していない営業は、自社の商品を理解していないのと同じ**。
> ただし営業が社労士になる必要はない。**「判定できる」と「危ない匂いを嗅ぎ分けられる」の2つ**ができればいい。

---

## 1. そもそもこれは何の制度か

**人材開発支援助成金／事業展開等リスキリング支援コース**（厚生労働省）

ひとことで言うと：

> **会社が従業員に、新しい分野の仕事に必要なスキルを身につけさせる訓練をやったら、国が費用の一部を後から払い戻してくれる制度。**

大事なのは「**後から**」。先に会社が全額払って、終わってから申請して、審査を経て入ってくる。
だから相手には「**一時的には全額のキャッシュアウトが必要です**」と必ず伝える。ここを曖昧にすると後で揉める。

### 「補助金」との違い（よく混同される）

| | 助成金 | 補助金 |
|---|---|---|
| 財源 | 主に雇用保険料 | 主に税金 |
| 採択 | **条件を満たせば原則受給できる** | 予算枠があり、審査で落ちることがある |
| 所管 | 厚生労働省が中心 | 経済産業省・中小企業庁など |
| 例 | 人材開発支援助成金 | IT導入補助金、小規模事業者持続化補助金 |

**営業トークでの意味：** 助成金は「条件が合えば通りやすい」。ただし**「確実」とは言わない**（審査はある）。

---

## 2. 誰が使えるか — 判定の急所

### 3つの条件を全部満たす必要がある

```
① 雇用保険の適用事業所である
        ↓
② 雇用保険の被保険者である従業員がいる
        ↓
③ その従業員に訓練を受けさせる
```

### ここから導かれる、営業として最重要の結論

> **従業員が1人もいない個人事業主は、この助成金を使えない。**
> **事業主本人が受講しても対象にならない**（本人は雇用保険の被保険者ではないため）。

だから商談の最初に聞くのは **「従業員さんは何名ですか？　雇用保険には入られてますか？」** の一択。

### 従業員0名だった場合に案内できる別ルート

顧客にならなくても、**知っていることを教えるのはギブになる**。

| 制度 | 概要 |
|---|---|
| デジタル化・AI導入補助金（旧IT導入補助金） | フリーランス・個人事業主も対象。小規模事業者なら補助率 最大4/5 |
| 小規模事業者持続化補助金 | 経営計画に基づく販路開拓・生産性向上の経費 |

※どちらも所管が違う（経産省系）ので、うちの社労士のスコープ外。**「調べる価値がある」までに留める。**

## 3. いくら戻るか

### 基本の数字（事業展開等リスキリング支援コース）

| 項目 | 中小企業 | 大企業 |
|---|---|---|
| 経費助成率 | **75%** | 60% |
| 賃金助成（1人1時間あたり） | **1,000円** | 500円 |
| 1人1訓練あたりの経費助成上限（10〜100時間未満） | **30万円** | 20万円 |
| 同上（100〜200時間未満） | 40万円 | 25万円 |
| 同上（200時間以上） | 50万円 | 30万円 |
| eラーニング・通信制の経費助成上限 | **一律15万円** | — |
| 1事業所あたりの年度上限 | 1億円 | 1億円 |
| 同一労働者の受講回数 | 1年度 **3回**まで | 同左 |
| eラーニングの受講回数 | 1年度 **1回**まで（2026/8/3〜） | 同左 |

### 覚えるべき3つの区別

**① 経費助成と賃金助成は別物**

- **経費助成** = 研修そのものの費用に対する助成
- **賃金助成** = 研修を受けている間の従業員の給料に対する助成（従業員は働いていないのに給料が出ているため）

**② eラーニングには賃金助成がつかない**

理由：eラーニングは業務時間外にも受けられるため、「働けなかった時間」が特定できないから。
→ **LMS（Cプラン）を提案するときは、賃金助成を計算に入れてはいけない。**

**③ eラーニングの経費助成上限は15万円**

対面の30万円（10〜100時間未満）と比べて**半分**。
→ 40万円のeラーニングを提案しても、戻るのは15万円まで。

## 4. 手続きの時間軸 — ここを外すと全部パー

```
 ①計画届を出す        ②訓練を実施        ③支給申請        ④審査 → 入金
      │                   │                  │                 │
      │←── 1か月以上 ──→│                  │                 │
      │                   │←── 2か月以内 ──→│                 │
      │                                                        │
  訓練開始日の                                            数か月後
  1か月前まで
  （1〜6か月前の範囲で提出可）
```

### 絶対に外してはいけない2つの締切

| 手続き | 期限 | 外すとどうなるか |
|---|---|---|
| **訓練実施計画届** | 訓練開始日の**1か月前**まで | 遅れた日数分の訓練が助成対象から外れる |
| **支給申請** | 訓練終了日の翌日から**2か月以内** | 受給できない（厳守） |

**営業としての実務的な意味：**

商談で「いつから始められますか？」と聞かれたら、**今日から1か月以上先の日付**しか言えない。
さらに計画届の作成に社労士とのやり取りが要るので、**実際には1.5〜2か月先**を見ておくのが安全。

```
例）今日が8月16日 → 計画届を9月上旬に提出 → 訓練開始は10月上旬以降
```

**もう一つ：** 計画を変えるときは事前に「訓練実施計画変更届」が必要。
出さずに内容を変えると、その部分が支給対象外になる。**「日程がずれそう」と相手が言ったら、即座に社内に共有する。**

## 5. 【最重要】2026年の3つの制度改正

ここが今、一番危ない。**去年の知識で商談すると、確実に事故る。**

### 改正①：2026年2月 — 対象が広がった（ヒダネにプラス）

- これまで「新規事業展開・DX推進」に限定されていた対象に、**「人事配置計画に基づく、今後従事する予定の職務」の訓練**が追加された
- 3年以内の人事に関する計画を作成すると、助成率が45%→75%に引き上げられる

**営業での使い方：** 「新規事業じゃないから使えない」と諦めていた会社にも入口ができた。
「来年◯◯部に異動させる予定の人がいる」といった話が出たら、それが根拠になり得る。

### 改正②：2026年4月8日 — eラーニングの上限が下がった（ヒダネにマイナス）

- eラーニング・通信制訓練の経費助成上限が、**訓練時間にかかわらず一律15万円**に（中小企業。従来は訓練時間に応じ最大30万円）
- 支給申請時期が柔軟化、定額制サービス利用時の提出書類が簡素化

**営業での使い方：** LMS（Cプラン）の実質負担が上がった。**古い資料の数字を使わない。**

### 改正③：2026年8月3日 — AI研修が対象外になりうる（ヒダネに直撃）⚠️

**これは2週間前に施行されたばかり。最優先で頭に入れる。**

変わったのは2点：

**(1) 助成対象にならない訓練の範囲が広がった**

対象外になったもの：
- 職務に**間接的にしか**必要でない内容
- **職業人として共通して必要な**内容

具体的に名指しされている例：
- ❌ **全社員向けのAIリテラシー研修**
- ❌ **汎用的なプロンプト講座**

→ **8月3日以降に提出する計画届から適用。**

**(2) eラーニングの受講回数に上限がついた**

- 同一の労働者について、**一の年度で1回まで**

---

### 改正③がヒダネにとって何を意味するか

うちの主力は「AI活用研修」と「SNS動画編集・運用研修」。**この2つは、両方とも対象外になりやすい形をしている。**

| 危ない売り方 ❌ | 残せる売り方 ◯ |
|---|---|
| 「全社員向けAIリテラシー研修」 | 「経理部門の請求書処理を自動化するためのAI活用研修」 |
| 「汎用プロンプト講座」 | 「営業部門の提案書作成業務に特化したプロンプト設計」 |
| 「SNSの使い方研修」 | 「採用担当者が求人動画を内製するための編集研修」 |

**共通しているのは「誰の、どの職務のための訓練か」が特定されているかどうか。**

だからヒアリングの **Q6「その作業、誰がやってますか？」** が、単なる雑談ではなく**助成金を通すための必須情報**になった。

> ⚠️ **注意：** 「設計を変えれば残せる余地がある」というのは複数の専門家の見解だが、最終的な判断は労働局が行う。
> **提案の前に必ず提携社労士に確認を通すこと。**「たぶん大丈夫」で計画届を出さない。

## 6. この制度はいつまで使えるか

> **令和4年度〜令和8年度の期間限定。令和8年度末（2027年3月31日）で終了予定。**

つまり**今年度が最後**。

**営業での伝え方：**

```
◯ 「この制度は令和8年度で終了予定なので、年度内にお考えがあれば
    逆算だけしておきましょうか。急かす意図はないです」

✕ 「今年度で終わりなので今すぐ決めてください！」
```

事実として伝えるのはいい。**急かす道具に使わない。** これはヒダネのトーンルールの範囲。

## 7. 数字の扱いについての注意（これも実務スキル）

この資料の数字は、**厚生労働省の一次資料ではなく、社労士事務所や研修会社の解説記事（二次情報）から集めたもの**。
実際、調べている最中に**出所によって数字が食い違う箇所**があった：

| 項目 | 食い違い |
|---|---|
| 大企業の経費助成率 | 「60%」とする記事と「30%」とする記事があった |
| 大企業の賃金助成 | 「500円」と「400円」の両方が見つかった |
| 経費助成の上限 | 「eラーニングのみ15万円」とする記事と「一律15万円」と読める記事があった |

**ここから学んでほしいこと：**

> **ネットの解説記事は、それ自体が営業目的で書かれていることが多い。数字は必ず一次情報で裏を取る。**

営業の現場での運用ルール：

1. **社内資料・過去の提案書の数字をそのままコピペしない**（改正で変わっている可能性がある）
2. **金額を口に出す前に、提携社労士に確認を通す**
3. 相手に数字を言うときは「**現時点の条件では**」を付ける
4. わからなければ「**確認して折り返します**」。これは負けではない
