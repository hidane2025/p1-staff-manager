# AI社員フック テレアポ設計（v2）

作成日：2026-08-16 ／ 改訂：2026-08-17

> **v1からの改訂**
> 主軸業務を「見積書の作成」から「**採用の応募者対応**」に変更。受付トークも全面的に作り直した。
> 理由 → [なぜ見積を捨てたか](#なぜ見積を捨てたか)

## 結論：4つの設計判断

### 判断① 「AI社員」は**証拠**として使い、**商品**として売らない

| | |
|---|---|
| ✕ | 「AI社員を導入しませんか」→ 商品の輪郭が曖昧なまま話が進み、商談で崩れる |
| ◯ | 「うち社員3人しかいないんですけど」→ **自己紹介**であり、提案ではない |

ヒダネの収益の中心は研修。AI社員導入は「本当にやっている会社だ」という**証明**としては最強だが、単体商材としては価格も提供形態も定義しきれていない。フックと売るものが乖離すると「釣り」になる。だから**フックは自己紹介の位置に置く**。

そして電話口で「研修です」と言えば即切られる。**電話では商品を売らない。売るのは次の30分だけ。**

---

### 判断② 主軸業務は「採用の**応募者対応**」

<a id="なぜ見積を捨てたか"></a>

#### なぜ見積を捨てたか

球として使えるのは、次の4条件を**全部**満たすものだけ。見積は2つ落ちる。

| # | 条件 | 見積書の作成 |
|---|---|---|
| 1 | どの業界にもある | **✕ 製造・建設に偏る**。介護・小売・士業には薄い |
| 2 | 社長が痛みを知っている | △ 経理・事務の話。社長事案になりにくい |
| 3 | 「AIでできるの!?」の意外性 | **✕ ゼロ**。「AIで見積」は聞き飽きられている |
| 4 | ヒダネが実際にやっている | ◯ |

#### なぜ応募者対応か

| # | 条件 | 採用の応募者対応 |
|---|---|---|
| 1 | どの業界にもある | **◎ 100%**。採用していない会社はない |
| 2 | 社長が痛みを知っている | **◎** 人手不足は中小企業の経営課題の筆頭。採用は社長事案 |
| 3 | 「AIでできるの!?」の意外性 | **◎** 求人原稿を書くAIは想像できるが、**深夜に応募者と会話するAI**は想像しにくい |
| 4 | ヒダネが実際にやっている | ◎（要・運用確認 → [前提条件](#前提条件)） |

#### そして最大の武器は「社長が知らない事実」

社長は「**応募が来ない**」と思っている。
実際は「**来た応募を取りこぼしている**」。

```
応募から初回返信までの理想は 4〜6時間。24時間を超えると他社で決まっている
        ↓
中小企業は採用担当が兼任 → 返信が2〜3日後になる
        ↓
月5件の応募のうち、実際に会えているのは2人
        ↓
「じゃあ3人はどこかで消えてるんですね」
```

**この気づきを渡すことが、この電話の最大の価値。**
中小企業（3〜300人）の採用単価は**30万円台前半**。取りこぼしの重さは社長が自分で計算する。

### 判断③ インパクトは「説明」ではなく「**事実 → 矛盾 → 種明かし**」で作る

```
✕ 「AIで応募者対応を自動化してます」
   → 説明。想像できる。「AIで効率化」と同じ棚に入れられて終わり

◯ 「夜中の2時に応募が来ても、3分で返信してます」  ← ① 不可能に聞こえる事実
   （一拍）
   「人間、誰も起きてないです」                    ← ② 矛盾
   「AIが返してるので」                            ← ③ 種明かし
```

**「AI」という単語を必ず最後に置く。** これが全球共通のルール。
先に言うと、相手の頭の中で「またAIの営業か」という既存の棚に分類されてしまう。

---

### 判断④ ターゲットは「**求人を出している会社**」

v1では加点シグナルだった「求人」を、**必須条件に格上げ**する。

求人を出している会社は、この設計の条件を**同時に4つ**満たす：

| | |
|---|---|
| 痛みが確定している | 人が足りないから求人を出している |
| **仕込みができる** | 求人原稿を読めば、具体的な指摘が1つ必ず見つかる → **受付突破の弾になる** |
| 数字が出る | 応募数・面談到達数を聞ける → 取りこぼしが可視化できる |
| **8/3改正をクリアする** | 「採用担当者が求人原稿と応募者対応を内製する研修」＝ 職務が特定済み |

詳細 → [01_ターゲット選定.md](01_ターゲット選定.md)

## 受付突破：v1の何が弱かったか

```
v1 ✕「AIで業務時間を減らす取り組みをしている会社でして…」
```
→ **受付が「営業ですね」と判断できてしまう。判断できるものは断られる。**

受付が社長に取り次ぐのは、次の3条件が揃ったときだけ。

1. **受付の権限外の話である**（判断できないので、上げるしかない）
2. **固有名詞が入っている**（調べてきた＝一斉架電ではないと分かる）
3. **短い**（1つだけ、と分かる）

```
v2 ◯ お世話になります。名古屋のヒダネと申します。

     御社の求人の件でお電話しました。
     Indeedに出されている「製造スタッフ」の募集を拝見しまして、
     応募数に関わる点で1つだけお伝えしたいことがあります。

     社長さん、いらっしゃいますでしょうか。
```

| 要素 | 効き方 |
|---|---|
| 「求人の件」 | **人事案件は受付の権限外。**判断できないので上げるしかない |
| 「Indeedの**「製造スタッフ」**の」 | **固有名詞。**実際に見てきた証拠 |
| 「応募数に関わる点」 | 会社の利益に直結。無視しづらい |
| 「1つだけ」 | 短いと分かる |

**これは架電前の仕込み（1社5分）とセットでのみ成立する。**
求人を読まずに「1つお伝えしたいことがあります」と言うと、社長が出た瞬間に詰む。

## アポの切り方

> **「御社の求人原稿をその場でAIに書き直す ＋ 取りこぼしを数字で出す 30分」**

```
30分だけいただいて、2つやります。

1つは、御社の求人原稿をその場でAIに書き直させます。どう変わるか見ていただければ。
もう1つは、応募が来てから会うまでに何人消えてるか、御社の実際の数字で出します。

それだけ持ち帰っていただければ、それで結構です。売り込みはしません。
```

**「その場でAIに書き直させる」が肝。**
相手は「AIで効率化」という言葉を100回聞いている。でも**目の前で自社の求人原稿が書き変わるのを見た人**はほぼいない。
「AIでできるの!?」を言葉ではなく**体験**で示す。

## 全体の流れ

```
 ①リスト作成          ②仕込み           ③架電            ④アポ            ⑤商談
 hidane-teleapo-list → 求人を読む   → 求人の件で    → 実演30分      → 提案
   ＋求人の有無         指摘を1つ       受付突破         原稿を書き直す
                        用意する          ↓                ↓
                                     取りこぼしを     採用担当という
                                     数字で出す       職務が特定される
                                                           ↓
                                                    そのまま計画届に載る
```

**この設計の狙いは、架電から計画届までを一本の線にすること。**
各段階で集める情報が、次の段階でそのまま使われる。だから無駄な会話がひとつもない。

<a id="前提条件"></a>
## ⚠️ この設計を使う前提条件

```
「夜中の2時に応募が来ても3分で返信してます。AIが返してるので。」
```

**この一言は、ヒダネが実際に採用AIを運用していて初めて使える。**

やっていなければ嘘になり、商談で「見せてください」と言われた瞬間に終わる。
そしてヒダネの最大の強みは「**自分たちが実際に使っているものを売る**」ことそのもの。ここが崩れると全部崩れる。

### まだ運用していない場合の手順

```
1. ヒダネの採用フローにAIを組む（応募検知 → 一次返信 → 質問対応 → 日程調整）
2. 1〜2か月運用して、実際の数字を取る（返信までの中央値、応募→面談の到達率）
3. その数字を持ってから架電を始める
```

**運用実績のない台本は使わない。** 設計上の前提であって、努力目標ではない。

## KPI

BtoBテレアポの相場は**アポ率 0.5〜3%**、コンタクト率 30〜40%。
仕込み込みのAランク中心なので、保守的に置く。

| 指標 | 目標 |
|---|---|
| 架電数 | 100件 |
| 接触 | 35件（35%） |
| 決裁者に到達 | 10件（10%） |
| **アポ獲得** | **2〜3件（2〜3%）** |

```
1受注 = 5アポ = 約200架電
1受注の売上 = 5名 × 40万円 = 200万円
→ 架電1件あたりの期待値 ≒ 1万円
```

**ただし仕込みに1社5分かかる。** 1日70本かけるなら、仕込みだけで約6時間。
現実的には **1日30〜40件（仕込み込み）** が上限。
**100件を雑にかけるより、30件を仕込んでかけるほうが取れる。**

### 架電の時間帯

| 時間帯 | 業種 |
|---|---|
| 8:30〜9:30 | 建設・工務店（現場に出る前） |
| **10:00〜11:30** | **全業種の本命** |
| 12:00〜13:00 | 避ける（製造業は昼休みが早い） |
| 14:00〜16:00 | 介護・福祉 |
| **16:00〜17:00** | **第2の山** |
| 17:00〜 | 建設（社長が戻る時間） |
