# AI社員フック テレアポ設計

作成日：2026-08-16

---

## 結論：3つの設計判断

### 判断① 「AI社員」は**証拠**として使い、**商品**として売らない

これが一番大事な線引き。

| | |
|---|---|
| ✕ | 「AI社員を導入しませんか」→ 商品の輪郭が曖昧なまま話が進み、商談で崩れる |
| ◯ | 「うちは社員3人でAI社員12体と回してます」→ **自己紹介**であり、提案ではない |

**なぜか。** ヒダネの収益の中心は研修（40万円/人 × 人数、助成金75%）。AI社員導入は「本当にやっている会社だ」という**証明**として最強だが、単体商材としては価格も提供形態も定義しきれていない。

フックと実際に売るものが乖離すると「釣り」になる。だから **フックは自己紹介の位置に置く**。これなら乖離が起きない。

そして電話口で「研修です」と言うと即切られる。だから**電話では商品を売らない**。売るのは次の30分だけ。

---

### 判断② アポの名前は「試算」にする

「どういう形でアポを切るのが理想か」への答え。

> **「御社の業務を1つ、AIで何分になるか試算する30分」**

他の切り方と比べる：

| アポ名 | 判定 | 理由 |
|---|---|---|
| サービスのご説明 | ✕ | 売り込み確定。断る理由が相手にある |
| 情報交換 | ✕ | 目的が不明確。ドタキャン率が高い |
| 助成金のご案内 | ✕ | 助成金屋に見える。かつ8/3改正で審査が厳しくなった今、期待値を先に上げるのは危険 |
| **業務1つの試算** | **◎** | 下の4条件を全部満たす |

**試算アポが優れている4つの理由：**

1. **相手の得が明確** — 自社の数字が手に入る。持ち帰るものがある
2. **範囲が狭い** — 「業務1つ」だから30分で終わると信じてもらえる
3. **売り込みではないと言い切れる** — 実際に売り込まないので、嘘にならない
4. **8/3改正とそのまま噛み合う** ← これが決定的

**4番目の説明：** 2026年8月3日の改正で、助成金を通すには「**誰の・どの職務のための訓練か**」の特定が必須になった。
試算アポは、その特定作業そのもの。**営業活動と計画届の材料集めが一本化される。**

```
試算アポ  →  「経理の◯◯さんの請求書処理」が特定される
                        ↓
          そのまま計画届に書ける職務になる
                        ↓
          8/3改正をクリアした研修設計ができる
```

---

### 判断③ ターゲットは「業種」ではなく「**繰り返しの定型業務があるか**」で選ぶ

従来のスコアリング（業種・従業員数・地域）は「**かけられるか**」の軸。
8/3改正後は、そこに「**通せるか**」の軸を足す必要がある。

> **必須条件：1つの職務に、繰り返しの定型業務が大量にある会社**

これを満たすと3つ同時に成立する：
- 助成金が通る（職務直結）
- 試算で数字が出る（繰り返し回数 × 1件あたり時間 = 削減効果）
- 研修の成果物が作れる（その業務専用のAI）

詳細 → [01_ターゲット選定.md](01_ターゲット選定.md)

## 全体の流れ

```
  ①リスト作成            ②架電              ③アポ                ④商談
 hidane-teleapo-list  → AI社員フック    →  試算30分        →  提案
                        ↓                    ↓                   ↓
   A/B/C/Dランク      相手に数字を        職務を特定      計画届の材料が
   ＋定型業務軸        言わせる           ＋従業員数確認    もう揃っている
```

**この設計の狙いは、架電から計画届までを一本の線にすること。**
各段階で集める情報が、次の段階でそのまま使える構造にしてある。

## KPI（目標値）

BtoBテレアポの一般的な相場は **アポ率 0.5〜3%**、コンタクト率 30〜40%。
Aランク中心のリスト＋強いフックなので、保守的に置く。

| 指標 | 目標 | 相場との比較 |
|---|---|---|
| 架電数 | 100件 | — |
| 接触（誰かが出る） | 35件（35%） | 相場並み |
| 決裁者に到達 | 10件（10%） | — |
| **アポ獲得** | **2〜3件（2〜3%）** | 相場の上限帯 |

### 1アポ = 約40架電。1受注に必要な架電数は？

商談→受注率を仮に20%とすると：

```
1受注 = 5アポ = 約200架電
1受注の売上 = 5名 × 40万円 = 200万円
→ 架電1件あたりの期待値 ≒ 1万円
```

**架電1本に1万円の価値がある**、という前提で運用する。
「今日100本かけた」＝「100万円分の期待値を積んだ」。数を追う根拠になる。

## 架電の時間帯設計

| 時間帯 | 状況 | 業種メモ |
|---|---|---|
| 8:30〜9:30 | 建設業はここ。現場に出る前 | 建設・工務店 |
| **10:00〜11:30** | **全業種の本命**。始業1時間後〜11時台が最も繋がる | 製造・卸・士業 |
| 12:00〜13:00 | 製造業は昼休みが早い。避ける | — |
| 14:00〜16:00 | 介護・福祉はここ | 介護・福祉 |
| **16:00〜17:00** | **第2の山**。夕方も繋がりやすい | 全業種 |
| 17:00以降 | 建設業の社長が戻る時間 | 建設 |

**1日の型：** 午前（10:00-11:30）に40本、夕方（16:00-17:00）に30本。合計70本。
残り時間はリスト整備と記録に使う。

## 社内向けのデッドライン逆算（電話では言わない）

助成金は **令和8年度末（2027年3月31日）で終了予定**。安全側で逆算すると：

```
訓練を2027年2月までに終える（安全側）
      ↓
訓練開始は2027年1月まで
      ↓
計画届は訓練開始の1か月前 → 2026年12月まで
      ↓
商談〜社内稟議〜社労士確認に1〜2か月 → 商談は2026年11月まで
      ↓
テレアポの実質勝負期間 ＝ 2026年8月〜10月末（約3か月）
```

> ⚠️ **これは社内の計画数字。電話でも商談でも「今だけ」「急がないと」の材料に使わない。**
> ヒダネのトーンルールに反する。相手から「いつまで？」と聞かれたときだけ、事実として答える。

## 使うツール

リスト作成は手作業でやらない。

```
「テレアポリストを作って」 → hidane-teleapo-list スキル
```

CSV統合 → クレンジング → A/B/C/Dランク付け → Web検索での情報補完 → 架電管理列の追加 → Excel出力まで自動。
本設計で追加した「**定型業務軸**」は、スコアリング後に手で見る（→ 01章）。
