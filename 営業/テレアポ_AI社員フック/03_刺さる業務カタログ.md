# 03. 刺さる業務カタログ

主軸（採用）が刺さらなかったときの**第2・第3の球**。
どれも「**どの業界にもある**」×「**AIでできるの!?**」の2条件を満たすものだけを載せる。

---

## 選定の基準

球として使えるのは、次の**4条件を全部満たすもの**だけ。

| # | 条件 | 満たさないとどうなるか |
|---|---|---|
| 1 | **どの業界にもある** | 業種ごとに台本を作り直すことになる |
| 2 | **社長が痛みを知っている** | 受付を突破できない・決裁が動かない |
| 3 | **「AIでできるの!?」の意外性がある** | 「AIで効率化」と同じ扱いになり、聞き流される |
| 4 | **ヒダネが実際にやっている** | 見せてくださいと言われた瞬間に終わる |

**「見積書の作成」が主軸から外れた理由：** 条件1（製造・建設に偏る）と条件3（意外性がゼロ）を満たさないため。

---

## 球の一覧（驚き度順）

| 順位 | 業務 | 一言 | 驚き | 全業界 | 社長事案 |
|---|---|---|---|---|---|
| **1** | **応募者への即時返信** | 「夜中の2時に応募が来ても3分で返信してます。人間、誰も起きてないです」 | ★★★ | ◎ | ◎ |
| **2** | **面接の日程調整** | 「面接の日程調整、うち誰もやってないです。全部AIが往復してます」 | ★★★ | ◎ | ○ |

| 4 | 電話の一次対応 | 「かかってきた電話、最初に出るのAIです」 | ★★☆ | ◎ | ○ |
| 5 | 議事録から「やること」だけ抽出 | 「会議の録音を放り込むと、誰が何をいつまでにやるかだけ出てきます」 | ★★☆ | ◎ | ○ |
| 6 | 社長宛メールの下書き | 「社長宛のメール、返信の下書きまでAIが作ってます」 | ★★☆ | ◎ | ◎ |
| 7 | クレーム対応の返信文 | 「クレームの一次返信、AIが書いてます。人間が最後に見るだけ」 | ★★☆ | ◎ | ○ |

## 各球の使い方

### 球1 ｜応募者への即時返信 【主軸】

**痛みの構造：** 社長は「応募が来ない」と思っている。実際は「**来た応募を取りこぼしている**」。

**数字：**
- 応募から初回返信までの理想は **4〜6時間**。24時間以内の対応率90%が目標
- 中小・成長企業では採用担当が他業務と兼任で、対応が遅れる構造
- 中小企業（3〜300人）の採用単価は**30万円台前半**

**一点確認：**
```
応募が来てから最初に連絡されるまで、どのくらいかかってます？
月に何件くらい応募来てます？
そのうち実際に会えてるのは何人ですか？
→ 「じゃあ◯人はどこかで消えてるんですね」
```

詳細 → [02_トークスクリプト.md](02_トークスクリプト.md)

---

### 球2 ｜面接の日程調整

**痛みの構造：** 「候補日を3つ出す → 全部ダメ → また3つ出す」の往復。1人あたり平均3〜5往復。
その間に候補者は他社で決まる。**誰もこれを「業務」だと認識していない**のが特徴。

**一言：**
```
面接の日程調整、うち誰もやってないんですよ。
AIが候補者と直接やり取りして、カレンダーに入れるところまでやってます。
```

**一点確認：**
```
面接の日程って、どなたが調整されてます？
1人あたり何回くらいやり取りされます？
```

**なぜ驚くか：** 「AIが文章を書く」は想像できるが、「**AIが相手と往復してカレンダーに入れる**」は想像しにくい。

---

### 球3 ｜ベテランの頭の中（属人化の解消）

**痛みの構造：** 20〜100名の会社で、社長が夜眠れない理由の上位。
「あの人が辞めたら、あの業務は止まる」。しかも**本人も何をやっているか言語化できていない**。

**一言：**
```
うち3人しかいないので、1人辞めたら終わりなんですよ。
だから業務ごとAIに覚えさせてます。

判断の基準まで含めて全部です。
「この条件ならこう見積もる」みたいなところまで。
```

**一点確認：**
```
今、この人が辞めたら止まるな、って業務ありますか？
その方、何年目です？
```

**なぜ驚くか：** 「マニュアルを作る」は誰でも知っている。でも**誰も作れていない**（書く時間がないから）。
「AIに覚えさせる」＝ 作業を横に置いて話すだけで型が残る、という点が意外。

**注意：** 効果が出るまで遅く、数字が測りにくい。**試算アポには向かない。**
球1・球2が刺さらず、かつ社長が採用に興味を示さないときの第3球として使う。

---

### 球4 ｜電話の一次対応

**一言：**
```
かかってきた電話、最初に出るのAIなんです。
用件を聞いて、必要なものだけ人間に回してます。
```

**注意：** AI電話サービスは既に世に多いので、**意外性が下がってきている**。
かつ「電話に出ないのは失礼」と考える社長には逆効果。相手を見て使う。

---

### 球5 ｜議事録から「やること」だけ抽出

**一言：**
```
会議の録音を放り込むと、議事録じゃなくて
「誰が・何を・いつまでに」だけが出てくるようにしてます。
```

**なぜ驚くか：** 「議事録をAIで文字起こし」は既知。
**「決定事項とToDoだけを抽出する」**は一段深く、かつ社長にとって価値が明確（読む時間がゼロになる）。

---

### 球6 ｜社長宛メールの下書き

**一言：**
```
社長宛のメール、返信の下書きまでAIが作ってます。
社長は読んで直すだけです。
```

**社長事案としては最強**（自分の時間が空く）。ただし社長のメール量が少ない会社には刺さらない。

---

### 球7 ｜クレーム対応の返信文

**一言：**
```
クレームの一次返信、AIが書いてます。
一番気を使う文章なので、人間が書くと1時間かかるんですよ。
```

**痛みの構造：** クレーム対応は「時間がかかる」より「**精神的に重い**」。
だから後回しになり、対応が遅れてさらに拗れる。ここを突く。

---

### 球8 ｜補助金・助成金の申請書類

**一言：**
```
補助金の申請書、AIに書かせてます。
書類が面倒で諦める会社が多いので。
```

**注意：** ヒダネが助成金屋に見えるリスクがある。**電話では使わない。**
商談で相手から助成金の話が出たときの補足として使う。

---

## 球の出し方（順序）

```
STEP 0 の仕込みで求人を確認
        │
        ├─ 求人を出している ──────→ 球1（応募者対応）でスタート
        │                              │
        │                              ├─ 刺さった → アポ
        │                              └─ 「間に合ってる」 → 球2（日程調整）
        │
        └─ 求人を出していない ────→ 球3（属人化）でスタート
                                       │
                                       ├─ 刺さった → アポ
                                       └─ 刺さらない → 球5 or 球6 → ダメなら引く
```

**1回の電話で3球以上投げない。** 4球目は「何か売りたいだけの人」に見える。
2球投げて反応がなければ、次の接触時期だけ取って引く。

---

## 共通の型（どの球でも同じ）

すべての球は、この3ステップの形に落とす。

```
① 不可能に聞こえる事実を先に置く
   「夜中の2時に応募が来ても3分で返信してます」

② 一拍おいて、矛盾を提示する
   「人間、誰も起きてないです」

③ 種明かしする
   「AIが返してるので」
```

### この順番でなければいけない理由

```
✕ 「AIで応募者対応を自動化してます」
   → 説明。想像できる。驚きがない。聞き飽きられている

◯ 事実 → 矛盾 → 種明かし
   → 相手の頭に「?」が立ってから答えが来るので、記憶に残る
```

**「AI」という単語を、必ず最後に置く。** これが全球共通のルール。

---

## ⚠️ 全球共通の前提

**ヒダネが実際にやっている球しか使わない。**

商談で「見せてください」と言われる。そのとき出せないものは、電話で言ってはいけない。
そしてヒダネの最大の強みは「**社員3人＋AI社員12体で実際に回している**」という事実そのもの。
ここが崩れると、研修を売る資格そのものが崩れる。

### 運用チェック

架電を始める前に、使う球について以下を確認する。

- [ ] 実際に運用しているか
- [ ] 運用期間はどのくらいか（最低1〜2か月ほしい）
- [ ] 数字を持っているか（返信までの中央値、往復回数、削減時間など）
- [ ] 商談でその場で見せられるか

**全部 ✓ が付いた球だけを、架電で使う。**
