# 05. 「採用しなくてよくなる」という切り口

作成日：2026-08-17

---

## 1. なぜこれが最強の切り口なのか

中小企業の社長が今いちばん困っているのは「**人が採れない**」。
そして採用は「**やって当たり前のこと**」なので、**そもそも必要かを疑ったことがない。**

```
人が足りない
     ↓
求人を出す        ← ここしか選択肢がないと思っている
     ↓
採れない / 採ってもすぐ辞める
     ↓
また求人を出す
```

**この輪の外側を見せるのが、今回の切り口。**

そしてヒダネは、それを**自分の会社で証明している**。社員3人＋AI社員12人。
売り物の説明ではなく、**自社の経営そのものが証拠**になる。

---

## 2. ⚠️ 絶対に守る言い分け

**ここを間違えると即切られる。** 最重要。

| ✕ 言ってはいけない | ◯ 言う |
|---|---|
| 「**人を減らせます**」 | 「これから**増やさなくて済みます**」 |
| 「人件費を削減できます」 | 「**増員の判断をしなくて済みます**」 |
| 「AIに置き換えます」 | 「**今いる人の手が空きます**」 |
| 「省人化」「無人化」 | 「**人を増やさずに回る**」 |

### なぜここまで厳密にやるのか

20〜100名の会社の社長は、**社員を家族のように見ている人が多い**。
「AIで人を減らす」はリストラの話に聞こえ、**その瞬間に敵になる。**

一方で「**これから増やさなくて済む**」は、
- 今いる人を守る話であり
- 社長が今まさに悩んでいる求人の話であり
- しかも金の話

**同じことを言っているようで、社長の受け取り方が正反対になる。**

> **原則：今いる人には触れない。これから増える予定の1人の話だけをする。**

---

## 3. 数字で言うとどうなるか

社長が「1人増やす」と判断するとき、実際に動く金。

| 項目 | 金額 |
|---|---|
| 採用コスト | **30万円台前半**（中小企業 3〜300人規模の平均採用単価） |
| 年収 | 300〜400万円 |
| 社会保険料の会社負担 | 年収の約15% |
| 教育期間3か月 | その間、**教える先輩の工数が半分消える** |
| 3か月で辞めた場合 | **上記が全部消える** |

> **1人増やす判断は、年間400〜500万円の固定費を背負う判断。**

対して、AI社員を1体作るための研修は **40万円/人（税込）**。
条件が合えば助成金で実質10万円前後（※電話では絶対に言わない）。

### ただし、正直に扱うこと

- **「AI社員1体＝人間1人分」とは言い切れない。** 言うと誇大になる
- 言えるのは「**うちは3人で回している**」という事実だけ
- 相手の会社で何人分になるかは、**業務を見ないと分からない**。だから商談する

```
◯「うちは3人でやってます。御社でどこまで行けるかは、業務を見ないと分からないです」
✕「AI社員1人で、人間1人分の仕事をします」
```

---

## 4. 助成金と矛盾しないのか → むしろ整合する

**よくある誤解：**「採用しなくていい」と言うと、
「従業員への訓練」が前提の人材開発支援助成金と矛盾するのでは？

**矛盾しない。逆に説明しやすくなる。**

```
今いる社員が受講者になる（増員はしない）
        ↓
これまで「人を増やして対応していた業務」を、AIで処理できるようになる
        ↓
＝「新しい職務に必要な知識・技能の習得」
        ↓
2026/8/3改正の「職務直結」要件を、むしろ満たしやすい
```

**8/3改正で対象外になったのは「全社員向けAIリテラシー」「汎用プロンプト講座」。**
「**増員で対応していた◯◯業務を、既存社員がAIで処理できるようになる訓練**」は、
職務が特定されているので要件を満たす方向に働く。

> ⚠️ ただし最終判断は労働局。**提案前に必ず提携社労士に確認を通すこと。**
> そして**電話では助成金の話を一切しない。**

---

## 5. 電話で使う一言

### 本命

```
うち、人が足りなくなったら、AI社員を1人作るんです。

採用しないので。
```

（一拍）

```
人って、採用する時代から、作る時代になったなと思ってて。
```

### 「採用する → 作る」が効く理由

**動詞が1つ変わるだけ。** だから理解が速く、対比が鮮やかで、記憶に残る。

そして**この言い方は誰も傷つけない。**
「人を減らす」は敵を作るが、「人を作る」は**増やす話**なので、社長の側に立っている。

| 版 | 文面 | 使いどころ |
|---|---|---|
| **標準** | 「採用する時代から、**作る時代になったなと思ってて**」 | **基本。**主観の形なので反論されない |
| **強め** | 「もう**採用する時代じゃないんですよ。作る時代です**」 | 相手が乗ってきている／勢いのある社長 |

> **必ず「事実 → 一般化」の順で。**
> 先に一般化すると意識高い系に聞こえ、「で、あなた何者？」となる。
> 自社の実践（3人で回している）を先に置いてから言うと、重みが乗る。

**効いている理由：**

| 要素 | 効き方 |
|---|---|
| 「人が足りなくなったら」 | **相手と同じ状況から入る。**共感の土台 |
| 「AI社員を1人作る」 | 行動が具体的。「増やす」と同じ動詞なので像が浮かぶ |
| **「採用しないので」** | **結論が短い。**しかも採用を否定していない（自社の方針を述べただけ） |

### 補強（相手が食いついたら）

```
5年後に社員が10人に増えてるより、
3人のままでAI社員が30人いるほうが、
うちは強いと思ってまして。
```

※ 具体的な年数・人数は**実態に合わせて調整すること**。分からない数字は言わない。

## 6. 想定される反論と返し

| 相手の反応 | 返し |
|---|---|
| **「人がいないとできない仕事もある」** | 「そうです。**現場は絶対に人です。**うちが渡してるのも、資料作るとか調べるとか、そういう部分だけです」 ← **即座に同意する。反論しない** |
| **「うちの仕事は特殊だから」** | 「そうだと思います。だから**うちの業務をそのまま渡せるとは言えない**んです。御社のどれが渡せるかは、見ないと分からないので」 |
| **「AIに任せて品質は大丈夫なのか」** | 「最初は落ちます。うちも。**人間が最後に見る前提**で回してます」 ← **正直に言う。ここで誇張すると信用を失う** |
| **「社員が反発しないか」** | 「うちは逆でした。**面倒な作業が減るので**。ただ『置き換える』と言うと反発すると思います」 |
| **「結局、人を減らすってことでしょ」** | **「今いる方はそのままです。**これから増やす予定の1人の話です」 ← **最重要の切り返し。必ず即答できるように** |
| **「うちは人を大事にしてるので」** | 「同じです。**人にしかできない仕事に集中してもらうため**にやってます」 |

## 7. この切り口が向かない相手

**押してはいけない相手がいる。** 見極めて引く。

| 相手 | 理由 |
|---|---|
| 現場作業が business の中心（施工、運転、調理、介護の直接処遇） | **渡せる業務が少ない。**無理に押すと嘘になる |
| 「人を育てるのが経営」と明言する社長 | 価値観がぶつかる。**論破しない。**別の切り口（引き継ぎ）に変える |
| 従業員5名未満 | 受講者を出せない＝助成金が使えない |
| 直近で人員整理をした会社 | センシティブ。**触れない** |

> **合わない相手に押さないのがヒダネのやり方。** 押して取った案件は後で崩れる。

---

## 8. 商談で見せるもの

電話で「人を増やさずに回してます」と言った以上、商談で示す必要がある。

- [ ] AI社員12体の一覧（何を何人分やっているか）
- [ ] 「これは人を雇っていたらこの工数」という対比が1つ以上
- [ ] 実際に1体が動くところ
- [ ] **人がやっている部分との線引き**（全部AIではない、と示すことが逆に信用になる）

**「全部AIでやってます」と言わないこと。** 嘘っぽくなる。
「ここは人、ここはAI」と線を引けるほうが、はるかに信用される。
