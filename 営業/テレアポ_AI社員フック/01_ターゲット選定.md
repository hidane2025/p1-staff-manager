# 01. ターゲット選定（v2）

> **v1からの変更点**
> 「求人を出しているか」を加点シグナルから**必須条件に格上げ**。
> 業種軸は「どの業界にもある業務」を主軸にしたため、優先度を下げた。

---

## 1-1. 必須条件（1つでも欠けたら D ランク）

| # | 条件 | 確認方法 | 欠けるとどうなるか |
|---|---|---|---|
| 1 | **従業員が1名以上いる**（雇用保険の被保険者） | 架電時に確認 | 助成金が使えない。40万円/人が全額自費になる |
| 2 | **中小企業**（資本金3億円以下 or 従業員300名以下） | HP・リストで判定 | 助成率が75%→60%に落ちる |
| 3 | **求人を出している**（Indeed / 求人ボックス / 自社採用ページ） | **会社名 + 求人 で検索** | 仕込みができず、受付を突破できない |

---

## 1-2. なぜ「求人を出している」が必須条件なのか

求人を出している会社は、この設計の条件を**同時に4つ**満たす。

```
求人を出している
      │
      ├─ ① 痛みが確定している
      │     人が足りないから出している。仮説ではなく事実
      │
      ├─ ② 仕込みができる  ← これが決定的
      │     原稿を読めば具体的な指摘が1つ必ず見つかる
      │     → 受付突破の弾になる（「1つお伝えしたいことがあります」）
      │
      ├─ ③ 数字が出る
      │     応募数・面談到達数を聞ける → 取りこぼしが可視化できる
      │
      └─ ④ 8/3改正をクリアする
            「採用担当者が求人原稿と応募者対応を内製する研修」
            ＝ 誰の・どの職務か が特定済み
```

**②が本体。** この設計の受付突破は「御社のIndeedの◯◯の募集を拝見して、1つお伝えしたいことがあります」で成り立っている。
求人が存在しなければ、この一言が使えない。

---

## 1-3. スイートスポットは従業員20〜100名

| 規模 | 判定 | 理由 |
|---|---|---|
| 〜4名 | **✕ 除外** | 受講者を出せない。助成金の実務負担に見合わない |
| 5〜19名 | △ | 可能だが受講者1〜2名。単価が小さい |
| **20〜100名** | **◎ 本命** | 社長が採用に直接関わっている／決裁が短い／受講者を3〜5名出せる |
| 100〜300名 | ○ | 人事部があり、採用が社長事案でなくなる |
| 300名超 | ✕ | 大企業扱い（助成率60%）。既存ベンダーがいる |

**20〜100名が本命の理由：**
この規模だと **社長が採用の最終面接に出ている**。だから「月5件の応募で2人しか会えていない」が自分の実感として分かる。
100名を超えると人事部が採用を持つので、社長に話しても「担当に聞いて」で終わる。

---

## 1-4. 業種の扱い（v1から降格）

主軸業務（採用の応募者対応）が**どの業界にもある**ため、業種は絞り込みの主軸ではなくなった。
業種が効くのは「**求人の出し方**」と「**架電の時間帯**」だけ。

| 業種 | 求人の傾向 | 架電の時間帯 |
|---|---|---|
| 製造業 | Indeedに常時掲載。技能職・製造スタッフ | 10:00〜11:30 |
| 建設業 | 職人・施工管理。慢性的に不足 | 8:30〜9:30 / 17:00〜 |
| 運輸・物流 | ドライバー。**採用難が最も深刻** | 10:00〜11:30 |
| 介護・福祉 | 常時募集。**応募単価が高く取りこぼしの痛みが大きい** | 14:00〜16:00 |
| 小売・飲食 | アルバイト中心。応募数が多く取りこぼしも多い | 14:00〜16:00 |
| 士業・不動産 | 求人が少ない。**優先度低** | 10:00〜11:30 |

**特に狙い目：運輸・介護・建設。** 採用難が最も深刻で、かつ応募者の取りこぼしが痛い業界。

---

## 1-5. 除外リスト（かけない）

| 除外対象 | 理由 |
|---|---|
| 個人事業主・従業員0名 | **助成金が使えない** |
| 従業員5名未満 | 受講者を出せない |
| 大企業（300名超） | 助成率が低い・決裁が長い・人事部が採用を持つ |
| **求人を出していない** | **仕込みができない。**→ 出したタイミングで再架電リストへ |
| 研修会社・コンサル・広告代理店 | 同業。情報だけ抜かれる |
| 人材紹介会社・求人媒体の代理店 | **完全に同業。**絶対にかけない |
| 助成金コンサル | 同上 |
| 官公庁・学校法人・医療法人の一部 | 助成金の要件が異なる。後回し |
| 過去6か月以内に断られた先 | 心証を悪くする |

## 1-6. 加点シグナル

必須条件を満たしたうえで、優先順位をつけるための材料。

| シグナル | 意味 | 重み |
|---|---|---|
| **求人の掲載が3か月以上続いている** | **採れていない証拠。**痛みが最大 | ★★★ |
| **同じ職種を複数媒体に出している** | 金をかけている。予算がある | ★★★ |
| 求人に「急募」「増員」がある | 緊急度が高い | ★★ |
| 求人原稿に応募後の流れが書いていない | **指摘が確定する**（仕込みが5分で終わる） | ★★ |
| 求人が複数職種ある | 採用が継続的な業務になっている | ★★ |
| 代表者の顔と名前がHPに出ている | 架電時に名指しできる | ★★ |
| 自社採用ページがある | 採用に投資している | ★ |
| SNS・ブログの更新が止まっている | 動画内製化研修の第2の入口 | ★ |

> **「3か月以上出し続けている求人」が最強のシグナル。**
> 出しているのに採れていない ＝ 社長が一番イライラしているところ。
> しかもその原因が「原稿」か「取りこぼし」のどちらかである可能性が高く、**両方ともこちらの守備範囲**。

## 1-7. ランク定義（v2）

| ランク | 条件 | アクション |
|---|---|---|
| **A** | 従業員20〜100名 ＋ **求人を3か月以上掲載中** ＋ 指摘が特定できた | **即架電。**仕込み済みでかける |
| **B** | 従業員10〜100名 ＋ 求人あり ＋ 指摘は要確認 | 仕込みをしてから架電 |
| **C** | 求人の有無が確認できていない | **Web検索で求人を確認**してA/Bに振り分ける |
| **D** | 必須条件（1-1節）のいずれかを満たさない | **かけない**（求人なしは再架電リストへ） |

**Aランクは全体の15〜25%が目安。**

## 1-8. リストを作る手順

```
1. LisTOSS等で 愛知県 × 従業員20〜100名 で抽出
   （業種は絞りすぎない。運輸・介護・建設を優先しつつ広めに取る）
        ↓
2.「テレアポリストを作って」→ hidane-teleapo-list スキルに投入
   （CSV統合・クレンジング・A/B/C/Dランク・Web補完・架電管理列・Excel出力）
        ↓
3. 「会社名 + 求人」で検索し、以下の列を手で埋める  ← 自動化しない
   □ 求人の有無
   □ 出している職種名
   □ 掲載期間（3か月以上か）
   □ 抜けている点（8パターンのどれか）
        ↓
4. 架電
```

### ステップ3が本体

**1社5分かかる。** そのぶん1日にかけられる件数は 30〜40件が上限になる。
それでいい。**この5分が受付突破の弾そのもの**だから。

```
仕込みなし：100件かけて、受付で95件止まる
仕込みあり： 30件かけて、受付を10件突破する
```

**求人を読まずに「1つお伝えしたいことがあります」と言ってはいけない。**
社長が出た瞬間に詰むし、それは嘘をついたことになる。
