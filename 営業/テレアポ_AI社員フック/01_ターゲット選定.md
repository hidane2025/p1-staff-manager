# 01. ターゲット選定

---

## 1-1. 2つの軸で選ぶ

```
       軸A：かけられるか            軸B：通せるか
      （既存スコアリング）        （8/3改正で必要になった）
              │                          │
     業種・従業員数・地域        1つの職務に定型業務があるか
              │                          │
              └────────┬─────────────────┘
                       ▼
                  A ランク
```

**軸Aだけで選ぶと、商談まで行っても助成金で落ちる。**
2026年8月3日の改正で「職務に間接的にしか必要でない訓練」「職業人として共通して必要な訓練」が対象外になったため。

---

## 1-2. 必須条件（1つでも欠けたら D ランク）

| # | 条件 | 確認方法 | 欠けるとどうなるか |
|---|---|---|---|
| 1 | **従業員が1名以上いる**（雇用保険の被保険者） | 架電時に確認 | 助成金が使えない。40万円/人が全額自費になる |
| 2 | **中小企業**（資本金3億円以下 or 従業員300名以下） | HP・リストで判定 | 助成率が75%→60%に落ちる |
| 3 | **1つの職務に繰り返しの定型業務がある** | HP・求人・架電時のヒアリング | 8/3改正で助成対象外になる |

---

## 1-3. スイートスポットは従業員20〜100名

| 規模 | 判定 | 理由 |
|---|---|---|
| 〜4名 | **✕ 除外** | 受講者を出せない。助成金の実務負担に見合わない |
| 5〜19名 | △ | 可能だが受講者1〜2名。単価が小さい |
| **20〜100名** | **◎ 本命** | 社長が現場を知っている／決裁が短い／受講者を3〜5名出せる |
| 100〜300名 | ○ | 決裁が長い。人事部が絡む |
| 300名超 | ✕ | 大企業扱い（助成率60%）。既存ベンダーがいる |

**20〜100名が本命の理由をもう少し：**
この規模の社長は、**現場の非効率を自分の目で見ている**。だから「見積に30分かかってる」という話が即座に通じる。
逆に300名超だと、社長は現場を見ていないので、試算アポの価値が伝わらない。

---

## 1-4. 業種 × 狙う職務 × 定型業務

**業種で選ぶのではなく、「その業種のどの職務を狙うか」まで決めてから架電する。**
これが8/3改正後の必須作業。

| 業種 | 狙う職務 | 定型業務（＝試算のネタ） | 愛知での母数 |
|---|---|---|---|
| **製造業** | 営業／技術／生産管理 | **見積書、仕様書、日報、報告書** | ◎ 最多 |
| **建設業** | 積算担当／事務 | **見積、積算、施工報告書、写真整理** | ◎ 多い |
| 運輸・物流 | 配車／営業事務 | 配車調整、請求書、日報 | ○ |
| 介護・福祉 | 生活相談員／管理者 | **介護記録、報告書、求人原稿** | ○ 人手不足が深刻 |
| 卸売 | 営業事務 | 受発注処理、見積 | ○ |
| 士業事務所 | 補助者 | 書類作成、議事録 | △ 規模が小さい |
| 不動産 | 営業 | 物件紹介文、広告原稿 | △ |

**愛知県は企業約20.9万社、うち中小企業が99.7%。製造業の集積が全国最大級。**
→ **製造業の見積・報告書業務が第一ターゲット。**

### 架電前に1社ずつ決めておくこと

```
□ この会社のどの職務を狙うか
□ その職務のどの定型業務を試算のネタにするか
□ その業務は月に何件くらいありそうか（仮説でいい）
```

これを決めずにかけると、フックの後の一点確認（→ 02章 STEP3）で詰まる。

## 1-5. 除外リスト（かけない）

| 除外対象 | 理由 |
|---|---|
| 個人事業主・従業員0名 | **助成金が使えない**（雇用保険の被保険者がいない） |
| 従業員5名未満 | 受講者を出せない |
| 大企業（300名超） | 助成率が低い・決裁が長い・既存ベンダーがいる |
| 研修会社・コンサル・広告代理店 | 同業。情報だけ抜かれる |
| 助成金コンサル | 同上 |
| 官公庁・学校法人・医療法人の一部 | 助成金の要件が異なる。個別確認が必要なので後回し |
| 過去に断られた先（6か月以内） | 心証を悪くする。記録で管理する |

## 1-6. 加点シグナル（Web検索で拾う）

`hidane-teleapo-list` のスコアリング後、A/B候補は必ずWeb検索で裏取りする。そのとき以下を探す。

| シグナル | 意味 | 点 |
|---|---|---|
| **求人を出している** | 人手不足＝内製化のニーズがある。かつ求人原稿自体が定型業務 | ★★★ |
| 求人票に「事務」「営業事務」がある | 定型業務が存在する証拠 | ★★★ |
| 採用ページ・自社ブログを更新している | 発信への意欲がある。動画研修の入口 | ★★ |
| 「DX」「業務効率化」の記載がある | 検討済み。話が早い | ★★ |
| 助成金・補助金の活用実績が載っている | 制度への抵抗がない | ★★ |
| SNSアカウントがある／更新が止まっている | 動画内製化研修の入口 | ★ |
| 代表者の顔と名前が出ている | 決裁者が明確。架電時に名指しできる | ★ |

**特に「求人」は最強のシグナル。** 人が採れないから困っている＝内製化の動機が既にある。
しかも求人原稿作成そのものがAIで短縮できる定型業務なので、**試算のネタがその場で見つかる**。

---

## 1-7. ランク定義（本設計版）

既存スキルのA/B/C/D に、定型業務軸を重ねた運用版。

| ランク | 条件 | アクション |
|---|---|---|
| **A** | 従業員20〜100名 ＋ 対象業種 ＋ **狙う職務と定型業務が特定できた** | **即架電。狙う職務を決めてからかける** |
| **B** | 従業員10〜100名 ＋ 対象業種 ＋ 定型業務は推測レベル | 架電。一点確認で職務を探る |
| **C** | 情報不足で判定できない | Web検索で補完してからA/Bに振り分ける |
| **D** | 必須条件（1-2節）のいずれかを満たさない | **かけない** |

**Aランクは全体の15〜25%が目安。** これを超えるなら基準が甘い。

---

## 1-8. リストを作る手順

```
1. LisTOSS等で 愛知県 × 製造業 × 従業員20〜100名 で抽出
        ↓
2. 「テレアポリストを作って」→ hidane-teleapo-list スキルに投入
   （CSV統合・クレンジング・A/B/C/Dランク・Web補完・架電管理列・Excel出力）
        ↓
3. A/Bランクのみ、1社ずつ「狙う職務」「定型業務」の列を手で埋める
   ← ここだけは自動化しない。ここが架電の質を決める
        ↓
4. 架電
```

**ステップ3を飛ばさない。** ここを埋めた状態でかけるかどうかで、アポ率が変わる。
100件を雑にかけるより、**30件を仕込んでかけるほうが取れる**。
