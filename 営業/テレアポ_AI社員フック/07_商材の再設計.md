作成日：2026-08-17 ／ 改訂：2026-08-17（制約条件を訂正）

## 0. 前提の訂正 ──「SNSでアポが取れない」の本当の理由

**初版で「SNS商材が売れない」と書いたのは誤り。** 実際の制約はこれ：

> **大石が忙しく、撮影に工数を割けない。**
> **だから、ショート動画の撮影が必要になるアポは取らない。**
> **物理的な撮影工数がかからないSNSアポなら取れる。**

つまり **商材の問題ではなく、供給側（ヒダネ）のリソース制約。**
「SNSが売れない」のではなく「**撮るものが売れない**」。

### この訂正で何が変わるか

| | 初版の理解 | 実際 |
|---|---|---|
| 問題の所在 | 商材（SNSが売れない） | **供給側のリソース（撮影工数）** |
| 除外すべきもの | SNS商材ぜんぶ | **ヒダネが撮影する商材だけ** |
| 生き残るもの | 非SNS商材 | **撮影不要なら、SNS商材も生きる** |

## 0-2. 商材の撮影工数マトリクス

**ヒダネ側の撮影工数がかかるかどうか**で、売る／売らないを分ける。

| 商材 | ヒダネの撮影工数 | 判定 |
|---|---|---|
| ショート動画の制作代行 | **◎ 大きい** | **✕ 売らない** |
| SNS運用代行（実写あり） | **◎ 大きい** | **✕ 売らない** |
| SNS動画編集・運用研修 | **なし**（撮るのは受講者） | ○ 売れる |
| 撮らないSNSの運用・企画設計 | なし | ○ 売れる |
| **SNSの効果分析・レポート** | **なし** | **◎ 実績あり** |
| **採用業務のAI内製化** | **なし** | **◎ 本命** |
| 見積・提案書のAI内製化 | なし | ○ |
| 経営数字の見える化 | なし | ○ |

> **この制約は、むしろ商材を絞る good news。**
> 撮影工数がかかる商材は、そもそも社員3人の会社がスケールさせにくい。
> **「撮らない商材だけを売る」と決めると、供給が詰まらない。**

## ⚠️ まず警告 ──「求人原稿をAIで書きます」は既に埋まっている

**v2で「応募者への自動返信」がATS標準機能だった失敗と、同じ構図がある。**

| 業務 | 既存で埋まっているもの | 判定 |
|---|---|---|
| **求人原稿の作成** | ビズリーチAI「求人自動作成機能」（2025年4月）／ANDASU等のAI求人作成ツール | **△〜✕ 媒体側が搭載済み** |
| **スカウト文面の作成** | ビズリーチ「スカウトメッセージAIカスタマイズ機能」（2025年10月）／AIスカウト代行が増加 | **△〜✕ 同上** |
| 応募者への自動返信・日程調整 | ATS全般（無料含む） | **✕ 標準機能** |

### ただし、媒体で分かれる

**ビズリーチ＝ハイクラス転職。** 20〜100名の製造・建設・運輸・介護が使うのは
**Indeed／求人ボックス／Airワーク**が中心で、そこにAI原稿生成が標準搭載されているとは限らない。

> **だから架電で「原稿をAIで書きます」と言う前に、必ず聞く。**
> **「どちらの媒体を使われてます？」**
>
> ビズリーチ・doda等が出てきたら、原稿とスカウトの話はしない。**別の穴を突く。**

## 2. 効率化トーク（採用担当向け）

### 前置き：必ず媒体を先に聞く

```
Q  どちらの媒体を使われてます？
```
> 「Indeedと、あと求人ボックスですね」→ **原稿の話をしてよい**
> 「ビズリーチです」→ **原稿・スカウトの話はしない。⑧⑬⑭⑮へ**

---

### トーク①：報告資料（一番刺さる）

```
Q  社長さんへの報告って、月1くらいで出されてます？
```
> 「出してますね」

```
Q  あれ、作るのにどのくらいかかります？
```
> 「半日はかかりますね…」

```
うち、そこもAIにやらせてまして。
媒体別に何件来て、何人会えて、いくら掛かったか、
そこまで出して、社長に渡すだけの形にしてます。
```

```
Q  今って、媒体ごとの費用対効果って出せてます？
```
> 「…ざっくりしか」

**★ここが本命。** 媒体をまたぐ分析は**どのツールにもできない**。
そして「媒体別の費用対効果を出せる」は、**担当が社長に対して強くなる材料**。

---

### トーク②：面接記録（地味だが確実）

```
Q  面接の記録って、どうやってまとめてます？
```
> 「メモ取って、あとで清書ですね」

```
Q  1人あたりどのくらいかかります？
```
> 「30分くらいかな」

```
うちは面接中のメモを放り込むと、
評価シートの形になって出てくるようにしてます。

面接官が複数いると、すり合わせの資料も要りますよね。
そこも一緒に出るようにしてて。
```

---

### トーク③：受け入れ計画（誰も手をつけていない）

```
Q  採ったあとの受け入れって、計画立てられてます？
```
> 「…現場任せですね」

```
そこ、実は一番もったいなくて。
せっかく採っても、最初の3か月で決まるので。

うち、業務ごとに「誰が何をいつ教えるか」を
AIに組ませてます。
```

**採用担当は「採るまで」が仕事だと思われているが、
「採ったあと辞められる」と結局その人の責任になる。** ここを助ける提案。

---

### トーク④：採用要件の言語化

```
Q  社長から「いい人採って」って言われません？
```
> 「言われます（笑）」

```
Q  その「いい人」って、要件に落ちてます？
```
> 「…なんとなくですね」

```
そこ、AIに翻訳させてます。
社長の言葉を、そのまま求人要件と面接の質問に落とす感じで。
```

**社長と担当の間の翻訳作業**は、どのツールも埋めていない。

## 3. ⚠️ 競合：RPO（採用代行）

**中小企業向けの採用代行が、月10,000円〜／中小向けは月5〜30万円で存在する。**
「採用専任がいない企業で、毎月50〜60時間のノンコア業務を削減」を謳っている。

### 差別化はここ

| | RPO（採用代行） | ヒダネ（内製化研修） |
|---|---|---|
| やり方 | **外注する** | **できるようになる** |
| 費用 | **毎月払い続ける**（年120万〜） | **一度きり** |
| ノウハウ | 社外に残る | **社内に残る** |
| 助成金 | **対象外**（外注費） | **対象になりうる**（訓練費） |
| 担当の立場 | **仕事が外に出る＝存在意義が減る** | **できることが増える＝評価が上がる** |

### そのままトークに使える

```
外注も手ではあると思うんです。ただ、
月10万円だと年間120万円で、来年も再来年も払うことになるので。

うちは、◯◯さんができるようになる形なので、一度で終わります。
あと外注費だと国の助成金は使えないですけど、
研修だと条件次第で使える可能性があります。
```

> ⚠️ **助成金は「使える可能性がある」まで。**「使えます」と言わない。
> そして**電話では助成金の話を一切しない**（商談で出す）。

**最後の一行が担当に効く：**
```
それに、外注すると◯◯さんの仕事が外に出ちゃうので。
```

## 3-2. 「撮らないSNS」は商材になるか

**なる。ただし"代行"ではなく"研修"として。**

### 既存ツールの状況（条件5のチェック）

撮影不要のSNS生成ツールは**既に充実している**。

| 領域 | 既存ツール |
|---|---|
| 投稿文＋画像 | **ChatGPT＋Canva＋手動投稿で月3,000円**という構成が広く紹介されている |
| 実写なし動画 | Runway／Pika／Dream Machine |
| アバター型説明動画 | Synthesia／HeyGen |

**「AIでSNS動画を作るツール」は競合だらけ。**

### だがヒダネの立ち位置は競合しない

```
ツールは既にある（安い・多い）
        ↓
だが中小企業は「どれを・どう使うか」が分からない
        ↓
「月3,000円でできます」という記事が量産されていること自体が、
まだ普及していない証拠
        ↓
そこを教えるのが研修 ── ツールとは競合しない
```

| | 判定 |
|---|---|
| AIでSNS動画を作る**ツールを売る** | **✕ 競合だらけ** |
| AIでSNS運用を**代行する** | **△** 競合多数。かつ撮影工数の問題は解決するが差別化が弱い |
| **AIでSNSを自社で回せるようにする研修** | **○ ツールとは競合しない** |

### そして最大の武器になりうる一言

```
うちも撮ってないです。社員3人なので。
```

**中小企業がSNSをやらない理由の1位は「撮る人・時間がない」。**
ヒダネ自身が同じ制約を持ち、それを撮らずに回しているなら、**それがそのまま証拠になる。**

> ⚠️ **要確認：ヒダネは実際に「撮らずに」SNSを回しているか。**
> 大石さんが撮影担当だったということは、**これまでは撮っていた**はず。
> 撮らない運用の実績がないなら、この一言は使えない。**まず自社で作ってから。**

### 8/3改正との関係（重要）

**「SNSの使い方研修」は職務直結でないため対象外になりやすい。**
残すには職務を特定する。

```
✕ 「SNS運用研修」
◎ 「採用担当者が、求人媒体向けの発信を内製するための訓練」
◎ 「営業事務が、既存顧客向けの案内を動画で作れるようになる訓練」
```

→ [社内教育/02_助成金の基礎.md](../../社内教育/02_助成金の基礎.md)

## 5. ★最大の発見 ── 電話と商材がズレている

**現状：**
```
テレアポ（採用の話で入る） → 商談 → AI活用研修（汎用）を売る
                                    ↑ここでギャップが生まれる
```

電話で「採用が大変ですよね」と共感してアポを取り、
商談で「AI研修です」と汎用商材を出すと、**話が繋がらない。**
相手は「採用の話じゃなかったの？」となる。

**提案：**
```
テレアポ（採用の話で入る） → 商談 → 採用業務のAI内製化研修を売る
                                    ↑ 一直線
```

### 商材を電話の切り口に合わせると、全部が繋がる

| 段階 | 内容 |
|---|---|
| リスト | 求人を出している会社（既にそう設計済み） |
| 架電 | 採用の話で共感 → 作業を減らす提案 |
| アポ | 求人原稿 or 報告資料を1つ、その場でAIに作らせる |
| 商談 | **採用業務のAI内製化研修** |
| 助成金 | 「採用担当者が、採用業務をAIで内製化するための訓練」＝ **職務が特定済み** |

**8/3改正の「職務直結」要件を、設計上いちばんクリアしやすいのがこの商材。**

## 6. 商材①の設計案：採用業務のAI内製化研修

### カリキュラム（12〜15時間・既存コースの枠に収まる）

| # | 内容 | 成果物 |
|---|---|---|
| 1 | 採用要件の言語化（社長の言葉を要件に翻訳） | 要件定義シート |
| 2 | 求人原稿の作成 ※媒体次第で扱いを変える | 原稿3本 |
| 3 | 面接記録のまとめ・評価シート化 | 評価テンプレート |
| 4 | **媒体別の効果分析** | 分析シート |
| 5 | **社長への報告資料の自動生成** | 月次report テンプレート |
| 6 | 受け入れ計画（OJT設計） | 受け入れ計画テンプレート |

**成果物が全部「その会社専用のテンプレート」になるのが肝。**
研修が終わった時点で、翌月から使えるものが手元にある。

### 価格・助成金

既存の枠をそのまま使う（新価格を作らない）。

```
受講人数 × 40万円（税込）
経費助成 75%（中小・上限30万円/人）
賃金助成 15時間 × 1,000円/人（中小）
```

**受講者は採用担当1〜2名＋総務**で、3名前後が現実的。
5名に届かない場合は、**営業職の「見積・提案書のAI内製化」（商材②）と抱き合わせ**て人数を作る。

> ※助成金の受給には審査があります。企業の状況により受給額や要件が異なる場合がありますので、詳細は個別にご確認ください。

## 8. 結論 ── 制約は、むしろ設計を良くした

**「撮影に工数を割けない」という制約は、本命の商材を否定しない。**

```
採用業務のAI内製化研修
    撮影工数：ゼロ
    効果分析：実績あり
    テレアポの切り口（採用の話）と一直線
    8/3改正の職務直結要件を最もクリアしやすい
        ↓
    制約と完全に整合する
```

**そして撮らないSNSも、"研修"の形なら生き残る。**
ショート動画の制作代行だけを外せばいい。

> **供給側の制約を先に決めると、商材が絞れる。**
> 「撮らない商材だけを売る」と決めたことで、
> 売るものと売らないものの線が、はじめて引けるようになった。
