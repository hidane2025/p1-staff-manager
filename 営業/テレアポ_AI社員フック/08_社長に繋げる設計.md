# 08. 担当アポを、社長に繋げる設計

作成日：2026-08-17

---

## 0. 前回の答えを訂正する

前章で「**採用担当は経由地に過ぎない／受注を取るなら社長**」と書いた。
**理論としては正しいが、実務の制約を無視していた。**

> **社長に繋がらないのだから、「社長を狙え」は答えになっていない。**

正しくはこう。

| ✕ 前回の答え | ◎ 訂正 |
|---|---|
| 社長アポしか意味がない | **意味がないのは「担当止まりで終わるアポ」** |
| 担当は経由地に過ぎない | **担当は受講者であり、実務の実行者であり、社内の推進者** |
| まず社長を狙え | **繋がらないなら担当から入る。ただし社長に繋げる仕掛けを必ず仕込む** |

---

## 1. 採用担当アポに意味がある4つの理由

### ① BtoBでは担当から入るのが普通

いきなり決裁者に会えるほうが例外。
**「担当者 → 課題の共有 → 決裁者を巻き込む」が基本形**であり、遠回りではない。

### ② 受講者は採用担当そのもの

40万円/人の研修を**受けるのは採用担当**。
**使う人の支持がない提案は、決裁されない。**
社長が「いいね」と言っても、現場が「いらない」と言えば止まる。

**逆に、担当が欲しがっている状態を作ってから社長に行くほうが、成約率は高い。**

### ③ 社長に直接会えても、結局担当に振られる

```
「採用の話ですか。じゃあ◯◯（担当）に聞いてみて」
```

**これは頻発する。社長アポでも1ステップ増えることがある。**
つまり **社長アポ ≠ 即決裁。**

### ④ 助成金の実務は担当がやる

計画届、支給申請、出勤簿、賃金台帳 ── これを揃えるのは総務・人事。
**担当が乗り気でないと、受注しても案件が進まない。**
社長だけで決めた案件は、実務でこける。

> **結論：担当アポには十分に意味がある。**
> **意味がないのは、担当と会っていい話をして、そこで終わるアポ。**

---

## 2. ★社長を呼ぶ最強の理由 ──「助成金」

**これが今回いちばんの発見。**

助成金は **担当の決裁範囲外であることが誰の目にも明らか**。
だから**担当の顔を潰さずに、自然に社長を呼べる。**

### 商談の中盤で、こう聞く

```
これ、国の助成金が使える可能性があるんですけど、

その話って、◯◯さんの範囲ですか？　社長さんの範囲ですか？
```

> 担当：「…社長ですね」　← **ほぼ100%こう答える**

```
ですよね。

じゃあ社長さんに一度だけ、5分でいいので説明させてもらえませんか。
◯◯さんも同席していただく形で。
```

### なぜこれが効くのか

| 要素 | 効き方 |
|---|---|
| **「◯◯さんの範囲ですか？」と聞く** | **担当に判断させる。**押しつけていない |
| 助成金は明らかに経営マター | **担当が「自分では無理」と自分から言う** |
| 「5分でいいので」 | 社長の時間を取らないと分かる |
| **「◯◯さんも同席で」** | **担当を外さない。**手柄も立場も守られる |

> ⚠️ **電話では助成金の話をしない。** 商談で出す。
> **ここが助成金の正しい使いどころ。**

### 締切を"担当の仕事"にする

```
計画届が訓練開始の1か月前なので、逆算すると
◯月までに決めないと今年度は間に合わないんです。

これ、社長さんに伝えておいてもらえますか。
```

**担当が社長に話しかける理由ができる。** しかも急かしていない（事実の伝達）。

※助成金の受給には審査があります。企業の状況により受給額や要件が異なる場合がありますので、詳細は個別にご確認ください。

## 3. 社長に繋げる5つの仕掛け

助成金以外にも、担当アポに仕込んでおくもの。

### ① 手土産を作る（前章の設計）

```
社長さんに出す報告資料を1本、無料で作らせてもらえませんか
```
→ **無料オファー自体が、担当が社長に持っていくもの。**
→ 「◯◯さんが作った形で出してもらって大丈夫です。うちの名前は出さなくていいので」

### ② 2回目を"条件付き"で約束させる

```
今日の資料、社長さんに見せてもらえます？

もし社長さんが「詳しく聞きたい」って言われたら、
その時だけもう一度お時間ください。
```

**担当に負担がない。断る理由がない。**
「必ず社長に会わせてください」だとハードルが高いが、これなら通る。

### ③ 担当を"共犯者"にする ★効く

```
社長さんって、こういう話どういう反応されます？

どう持っていったら通りやすいですか？
```

**担当に社内攻略を相談する。**
担当は自分の知見を出した瞬間に、その案件を**自分ごと**として扱い始める。

> **人は、自分がアドバイスした案件を応援する。**

### ④ 1枚ものにする

担当が読み上げれば伝わる資料を渡す。
**担当が社内で使いやすい ＝ 動いてくれる。**
分厚い提案書は、担当のカバンの中で死ぬ。

### ⑤ 社長の名前を先に聞いておく

```
ちなみに社長さんって、なんてお名前でしたっけ？
```

**次に電話するとき、名指しで受付を抜ける。**
担当アポが不発でも、この情報だけは残る。

## 4. そもそも「社長に繋がらない」を改善する

**担当ルートを整えるのと並行して、社長に繋がる確率そのものを上げる。**

### ① 時間帯を変える ── 受付がいない時間を狙う

| 時間帯 | 状況 |
|---|---|
| **8:00〜8:30** | **受付が出社前。社長が直接出る** |
| **18:00以降** | **同じく。社長は残っている** |
| 12:00〜13:00 | 受付が昼休み。ただし社長も不在がち |
| 10:00〜11:30 | 繋がりやすいが**受付が万全** |

**社長を狙うなら、繋がりやすい時間ではなく「受付がいない時間」。**

### ② 代表者名を必ず名指しする

```
✕「社長さん、いらっしゃいますか」    → 用件を聞かれる
◎「◯◯様、いらっしゃいますか」      → 知り合いかもと思われる
```

**仕込み（STEP 0）に「代表者名の確認」を必須項目として入れる。**
HPの会社概要、法人番号公表サイト、求人票の「代表者」欄から取れる。

### ③ 社長が現場にいる会社を優先する

| 規模 | 社長の所在 |
|---|---|
| 〜20名 | **社長が電話に出ることもある** |
| **20〜50名** | **社長が現場にいる。受付が薄い** |
| 50〜100名 | 受付・総務がしっかりいる |
| 100名〜 | ほぼ繋がらない |

**20〜50名を優先する。** 100名に近いほど社長は遠い。

### ④ 携帯番号が公開されている会社を狙う

建設業・不動産・運送は、**代表者の携帯がHPや名刺に出ている**ことがある。
求人票に「担当直通」が載っていることも。

### ⑤ ★社労士経由の紹介を設計する

**ヒダネは社労士と提携している。**
社労士は**顧問先の社長と直接繋がっている。**

```
テレアポで受付を抜く難易度  ＞＞＞  社労士からの紹介
```

> **これはテレアポの改善ではなく、テレアポより先にやるべきこと。**
> 提携社労士に「助成金を使える顧問先はありませんか」と聞くだけで、
> **社長に直接会える経路ができる。**

**しかも社労士にとっても得**（顧問先に価値を出せる／助成金の申請報酬が発生しうる）。

### ⑥ 商工会議所・既存顧客の紹介

同様に、テレアポより歩留まりが高い。

---

## 5. 現実的な優先順位

```
① 社労士からの紹介         ← 最短。今すぐ動かせる。テレアポより先
② 社長への直接テレアポ      ← 8:00-8:30 / 18:00以降 / 代表者名を名指し / 20〜50名
③ 採用担当アポ → 社長へ    ← 繋がらない会社はこれ。ただし仕掛けを必ず仕込む
④ 既存顧客・商工会議所の紹介
```

**③を「妥協」と考えない。**
担当が味方になっている案件のほうが、社長だけで決めた案件より実際は強い。

## 6. 記録項目

担当ルートの本当の歩留まりを測る。

| 列名 | 内容 |
|---|---|
| 架電時間帯 | 8:00台／10:00台／16:00台／18:00以降 |
| **社長に繋がったか** | ○/✕（**時間帯別に集計する**） |
| 代表者名を名指ししたか | ○/✕ |
| 従業員数 | 20〜50名の突破率を見る |
| 担当アポになった場合 → | |
| **助成金で社長を呼べたか** | **○/✕ ← 2章の質問が効いているか** |
| **社長との商談が設定されたか** | **○/✕ ← 担当ルートの真の成果指標** |
| 社長の氏名を聞けたか | ○/✕（次回の名指し用） |

> **「担当アポが取れた」ではなく「社長との商談が設定された」をKPIにする。**
> ただし**担当アポの数も記録する** ── そこからの転換率が分かれば、担当ルートの価値を数字で判断できる。

## 7. まとめ

| 問い | 答え |
|---|---|
| 社長アポしか意味がないか？ | **いいえ。担当アポにも意味がある** |
| 何に意味がないのか？ | **担当止まりで終わるアポ** |
| 担当アポで一番重要な仕掛けは？ | **助成金で社長を呼ぶ**（担当の範囲外だと担当自身が言う） |
| 社長に繋がらない問題は？ | **時間帯・名指し・規模の見直し。そして社労士紹介** |
| 何を先にやるべきか？ | **社労士経由の紹介。テレアポより歩留まりが高い** |
