# 02. トークスクリプト（v5）

> **v4からの変更**
> ① 着地を「引き継ぎ・教育」から「**採用しなくてよくなる**」に変更
> ② **質問で相手に話させるパートを大幅に増やした**（1問 → 6問）
> ③ 順番を変更：v4は「具体例 → 説明拒否 → 質問」だったが、v5は「**質問 → 具体例**」。
>    先に質問すると相手の状況が分かるので、**出す具体例を選べる**。そして自分の課題を口にした後だと具体例が自分ごとになる。

**全体で3〜4分。** v4より少し長い。質問が増えたぶん、相手が喋る時間が増えているので問題ない。

```
STEP 0  仕込み（架電前）      5分
STEP 1  受付突破             25秒   ← A/B 2ルート
STEP 2  AI社員フック         20秒   ← 説明しない
STEP 3  強みの一言           15秒   ← 「採用しないので」
STEP 4  質問で話させる      100秒   ← ★v5の本体。6問
STEP 5  具体例で殴る          40秒   ← 相手の答えに合わせて2体
STEP 6  説明を拒否する        20秒
STEP 7  アポ打診             30秒
STEP 8  確定と仕込み         40秒
```

---

## STEP 1 ｜受付突破（25秒）── 2ルートをA/Bで試す

### ルートA（安全・実績あり）── 求人の件

```
お世話になります。名古屋のヒダネと申します。

御社の求人の件でお電話しました。
Indeedに出されている「製造スタッフ」の募集を拝見しまして、
1つだけお伺いしたいことがあります。

社長さん、いらっしゃいますでしょうか。
```

### ルートB（攻め）── AI社員の件

```
お世話になります。名古屋のヒダネと申します。

うち、社員3人でAI社員を12人使って会社を回してまして、
その事例を東海の製造業さんにお話しして回っています。

社長さん、いらっしゃいますでしょうか。
```

**記録して比較する。** 架電管理列に「受付ルート（A/B）」を追加し、50件ずつ試して通ったほうに寄せる。

## STEP 3 ｜強みの一言（20秒）── ★v5の主軸

```
それで、人が足りなくなったら、AI社員を1人作るんです。

採用しないので。
```

（一拍）

```
人って、採用する時代から、作る時代になったなと思ってて。
```

### なぜこの順番なのか ── 事実が先、一般化が後

```
✕ 「人はもう採用する時代じゃないんですよ！」（いきなり一般化）
   → 意識高い系に聞こえる。「で、あなた何者？」となる

◯ 「うちは人が足りなくなったらAI社員を作ってます」（事実）
   （一拍）
   「人って、採用する時代から作る時代になったなと思ってて」（一般化）
   → 自社の実践が先にあるので、一般化に重みが乗る
```

**先に事実、後で一般化。逆にすると薄っぺらくなる。**

### 2つのバージョンを使い分ける

| 版 | 文面 | 使いどころ |
|---|---|---|
| **標準** | 「人って、採用する時代から、**作る時代になったなと思ってて**」 | **基本はこちら。**主観の形なので反論されない。ヒダネのトーンに合う |
| **強め** | 「人ってもう、**採用する時代じゃないんですよ。作る時代です**」 | 相手が乗ってきている／勢いのある社長／2回目以降の接触 |

> **強めは断定なので、直後に必ず根拠（自社の事実か具体例）を置く。**
> 断定したまま次に行くと「大きいこと言う人」で終わる。

### なぜこの一言が刺さるのか

| 要素 | 効き方 |
|---|---|
| 「人が足りなくなったら」 | **相手と同じ状況から入る。**共感の土台 |
| 「AI社員を1人作る」 | 行動が具体的。「人を増やす」と同じ動詞なので像が浮かぶ |
| **「採用しないので」** | **結論が短い。**しかも採用を否定していない（自社の方針を述べただけ） |
| **「採用する → 作る」** | **動詞が1つ変わるだけ。**理解が速く、対比が鮮やか。記憶に残る |

### ⚠️ 絶対に守る言い分け

| ✕ 言ってはいけない | ◯ 言う |
|---|---|
| 「**人を減らせます**」 | 「これから**増やさなくて済みます**」 |
| 「人件費を削減できます」 | 「**増員の判断をしなくて済みます**」 |
| 「AIに置き換えます」 | 「**今いる人の手が空きます**」 |

**20〜100名の社長は、社員を家族のように見ている人が多い。**
「AIで人を減らす」はリストラの話に聞こえ、**その瞬間に敵になる。**

> **原則：今いる人には触れない。これから増える予定の1人の話だけをする。**

詳細 → [05_採用しないという強み.md](05_採用しないという強み.md)

## STEP 4 ｜質問で話させる（100秒）── ★v5の本体

**ここからは、こちらが喋らない。** 目標は **相手7割**。

### 話させる4つの作法

| # | 作法 | 具体的に |
|---|---|---|
| 1 | **質問したら黙る** | 心の中で3秒数える。沈黙を埋めない |
| 2 | **答えやすい順に聞く** | 事実 → 状況 → 感情 → 数字 → 気づき の順 |
| 3 | **「なぜ」で聞かない** | 「なぜ採れないんですか」は責めに聞こえる。**「いつから」「どのくらい」**で聞く |
| 4 | **2問聞いたら1つ返す** | 尋問にしない。相手の言葉を1つ拾ってオウム返しする |

---

### Q1｜事実（答えやすい）

```
御社、今も募集出されてますよね。
何名くらい探されてるんですか？
```
> 「2人ですかね」

**狙い：** 最初は必ず**イエス/数字で答えられる質問**から。会話のリズムを作る。

---

### Q2｜状況

```
それ、いつ頃から出されてます？
```
> 「半年くらいかな…」

**狙い：** 期間が長いほど痛みが確定する。ここで長い数字が出たら、この電話は当たり。

**オウム返しを入れる：**
```
半年ですか。
```
（間）

---

### Q3｜感情に触れる ★ここが分岐点

```
…けっこう、しんどくないですか？
```
> 「まあ、しんどいですよ。応募自体こないですし」

**狙い：** **社長に愚痴を言わせる。** ここで喋り出したら、ほぼアポは取れる。

**この質問が効く理由：**
営業電話で**自分を気遣ってくる人間はいない**。だから警戒が一段下がる。
そして人は、自分の困りごとを話した相手の話を聞く。

**返しは共感だけ。解決策を出さない。**
```
そうですよね。今どこもそうみたいで。
```

---

### Q4｜数字（コストの実感）

```
もし1人採れたとして、
一人前になるまでどのくらいかかります？
```
> 「3か月くらいはかかりますね」

---

### Q5｜見えていないコストに気づかせる

```
その間、教える先輩の方の仕事って、
どのくらい止まっちゃいます？
```
> 「半分くらいは取られてるかも」

**ここで初めて、こちらが1つ返す：**
```
なるほど。じゃあ1人採ると、
実質もう1人分の手が3か月消える感じですね。
```

**狙い：** 社長は**採用コスト（30万円台前半）は知っている**が、
**教育中に消えるベテランの工数は計算していない。**
この一言で「思っていたより高い買い物だった」と気づく。

---

### Q6｜決定的な質問 ★今回の設計の核心

```
…そもそもなんですけど、

その仕事って、"人"じゃないとダメですか？
```

**（黙る。ここは長く待つ）**

> 「…どういう意味ですか？」
> 「まあ、人じゃないと無理でしょう」
> 「…考えたことなかったですね」

### なぜこの質問が刺さるのか

**採用は「やって当たり前のこと」なので、社長は一度も自問したことがない。**

```
人が足りない
     ↓
求人を出す        ← ここしか選択肢がないと思っている
     ↓
採れない / 採ってもすぐ辞める
     ↓
また求人を出す
```

**この輪の外側があることを、質問の形で見せる。**
こちらが「AIでできますよ」と言うより、**相手が自分で「あ」と思うほうが圧倒的に強い。**

### 反応別の受け方

| 反応 | 返し |
|---|---|
| **「考えたことなかった」** | **勝ち。**「うちもそうでした。3人しかいないので、考えざるを得なかっただけなんですけど」→ STEP 5 へ |
| 「人じゃないと無理でしょう」 | 「**現場は絶対に人ですよね。**うちが渡してるのも、資料作るとか調べるとか、そういう部分だけです」→ **即座に同意してから**STEP 5 へ |
| 「どういう意味？」 | 「たとえば──」で STEP 5 の具体例に直行 |

> **「人じゃないと無理」に反論しない。** 必ず同意してから、範囲を狭めて話す。
> 全部AIに置き換わると言った瞬間、嘘くさくなる。

### Q7｜（任意）アポへの橋渡し

相手の反応が良ければ、ここで1つ足す。

```
もし人を増やさずにその仕事が回るなら、
興味あります？
```

**イエスが取れたら、そのままSTEP 7（アポ打診）へ飛んでいい。**

## STEP 5 ｜具体例で殴る（40秒）── 相手の答えに合わせて2体

**STEP 4 で相手が何に困っていると言ったかで、出す体を変える。**

| 相手が言ったこと | 出す体 | 一言 |
|---|---|---|
| 「資料作りに時間が取られる」 | 営業準備担当 | 「会社名を1個渡すと、その会社を調べて提案書と商談の台本まで作って出してきます。人間がやってた時は1社で半日かかってたので」 |
| 「事務が回らない」 | リスト担当＋フォローメール担当 | 「リストの整理も、商談後のメールも、AIがやってます」 |
| 「数字をまとめる時間がない」 | 経理・KPI担当 | 「週次のKPIと月次のPL、AIが勝手に作って出してきます。人間は見るだけです」 |
| 「書類・申請が面倒」 | オンボーディング担当 | 「助成金の書類も、計画届から支給申請までAIが用意します」 |
| 特に何も出なかった | 営業準備担当＋失注分析担当 | 下の定番2体 |

### 定番の2体（迷ったらこれ）

**1体目（つかみ）**
```
たとえば、営業準備の担当が1人いるんですけど、

会社名を1個渡すと、その会社を調べて、
提案書と商談の台本まで作って出してきます。

人間がやってた時は、1社で半日かかってたので。
```

**2体目（笑いを取る）**
```
あと、失注の分析だけやってる担当もいて。

商談が流れると、なんで流れたかを分析して、
「次はこう言え」って台本を直してくるんです。

…わりと厳しいんですけど（笑）
```

> **笑いが取れると警戒が一段下がる。** ここで相手が笑ったら、ほぼアポは取れる。

**3体目を出さない。** STEP 4 で相手が喋っているので、v4より短くていい。

## STEP 6 ｜説明を拒否する（20秒）

```
12人いるんですけど、全員違う仕事してまして。

一番説明しづらいのが、
そいつら毎回自分で自分の仕事を採点して、
次から勝手に直してくるところで。

…電話だとちょっと説明しづらいんですけど。
```

> **説明しきらないことが、アポになる。** 全部説明すると「分かった、じゃあいいや」になる。
> そして**実際に複雑なので、この一言は嘘ではない。**

## STEP 7 ｜アポ打診（30秒）

```
30分だけいただいて、うちのAI社員12人が何やってるか、
全部お見せします。画面で。

その上で、さっきおっしゃってた◯◯の仕事、
AIに渡せそうかどうか、一緒に見てみませんか。

人を増やす前に、一回見てもらうだけで結構です。
売り込みはしません。

来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

### v5で変えた2箇所

| 箇所 | v4 | v5 |
|---|---|---|
| 対象業務 | 「どの仕事が渡せそうか」（抽象） | **「さっきおっしゃってた◯◯の仕事」**（STEP 4 で相手が言った具体名） |
| 動機づけ | 「持ち帰っていただければ」 | **「人を増やす前に、一回見てもらうだけ」** |

**「さっきおっしゃってた◯◯」が効く。** 話を聞いていた証拠になり、かつ相手の課題そのものなので断りにくい。
**「人を増やす前に」** は、採用の判断を止めない言い方。急かしていないのに緊急性が出る。

### 締めにもう一度、同じフレーズを置く（任意）

相手の温度が高ければ、最後にSTEP 3の一言を繰り返して切る。

```
人を採るか、作るか。
その選択肢があるって知ってもらえるだけでいいです。
```

**同じフレーズを冒頭と最後に置くと、電話を切ったあとに残る。**
ただし温度が低い相手にやると押しつけがましいので、**乗ってきたときだけ。**

## STEP 8 ｜確定と仕込み（40秒）

```
当日までに、「人を増やそうと思ってる仕事」を
1つだけ決めておいていただけますか。
```

```
当日は社長お一人ですか？
その仕事を今やられてる方に入っていただけると、その場で見れます。
```
→ **8/3改正で必要な「職務の特定」がその場で完了する。**

```
ちなみに御社、今何名くらいでやられてるんですか？
```
→ 助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

### 切る前の最終確認

```
□ 日時 / 参加者（社長のみ・現場の方も）
□ 増やそうとしている職種・業務
□ 従業員数
□ 募集期間（Q2の答え）
□ 一人前までの期間（Q4の答え）
□ 受付ルート（A/B）とその結果
□ 形式（オンライン / 訪問）/ メールアドレス
```

**当日中に確認メールを送る。**

| 相手の質問 | 返し |
|---|---|

| **「それって結局AIツールでしょ？」** | 「はい、実体はAIです。人格があるわけじゃないです。ただ**うちの仕事のやり方を覚えさせてある**ので、他社さんが同じものを買っても同じようには動かないです」 |
| **「結局、人を減らすってことでしょ」** | **「今いる方はそのままです。**これから増やす予定の1人の話です」 ← **最重要。即答できるように** |
| **「人がいないとできない仕事もある」** | 「そうです。**現場は絶対に人です。**うちが渡してるのも、資料作るとか調べるとか、そういう部分だけです」 |
| **「うちの仕事は特殊だから」** | 「そうだと思います。だから**うちの業務をそのまま渡せるとは言えない**んです。御社のどれが渡せるかは、見ないと分からないので」 |
| **「品質は大丈夫なのか」** | 「最初は落ちます。うちも。**人間が最後に見る前提**で回してます」 ← **正直に言う** |

| **「うちにも作れますか？」** | 「作れます。ただ、どの仕事を渡すかで難易度が全然違うので。**そこを一緒に選ぶのが当日やりたいことです**」 ← **理想的な質問。アポに直結** |
| **「本当に3人でやってるんですか？」** | 「はい。だから逆に、1人辞めたら終わりなんですよ。**それが一番の理由です**」 |

## NG集

| ✕ 言わない | なぜ |
|---|---|
| **「人を減らせます」「人件費削減」「省人化」** | **リストラに聞こえた瞬間に敵になる。**「増やさなくて済む」と言う |
| **「AI社員1人＝人間1人分です」** | **誇大。**言えるのは「うちは3人で回している」という事実だけ |
| **「全部AIでやってます」** | 嘘っぽくなる。**「ここは人、ここはAI」と線を引くほうが信用される** |
| **「AI社員を導入しませんか」** | 商品の輪郭が曖昧なまま話が進む。**電話では売らない** |
| **確認できていない4体について語る** | **嘘になる** → [04_AI社員カタログ.md](04_AI社員カタログ.md) |
| **「なぜ採れないんですか」** | 責めに聞こえる。**「いつから」「どのくらい」**で聞く |
| **「応募、来てないですよね」** | 決めつけ。社長のプライドを傷つける |
| **「助成金で実質10万円です」** | 期待値を先に上げすぎ。8/3改正で審査が厳しくなった今は特に危険 |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「営業ではありません」 | **嘘。**受付にも決裁者にも嘘をつかない |

## 押してはいけない相手

| 相手 | 理由 |
|---|---|
| 現場作業が中心（施工・運転・調理・介護の直接処遇） | **渡せる業務が少ない。**無理に押すと嘘になる |
| 「人を育てるのが経営」と明言する社長 | 価値観がぶつかる。**論破しない。**引き継ぎの切り口に変えるか、引く |
| 従業員5名未満 | 受講者を出せない＝助成金が使えない |
| **直近で人員整理をした会社** | **センシティブ。触れない** |

**2回断られたら引く。**
