# 02. トークスクリプト（v7）

> **v6からの変更**
> **台詞中心から、質問中心に組み替えた。**
> 短い質問（1行）を会話の要所に散らし、**相手が答えるたびに話が前に進む**構造にした。
> 質問は6問 → **17問**。ただし1問1行なので、通話時間はv6とほぼ同じ。

---

## なぜ短い質問を多用するのか

| | |
|---|---|
| **答えるコストが低い** | 「はい/いいえ」か一言で済む。考えさせない |
| **相手が喋る回数が増える** | 参加している感覚になる。聞き役から当事者になる |
| **沈黙が生まれない** | 沈黙は切られる隙。質問があれば会話が続く |
| **答えで台本が分岐する** | 決め打ちの営業トークにならない |

### ただし尋問にしない

> **2〜3問聞いたら、1つ自分の情報を返す。**

質問だけ続けると詰問になる。返す情報は短くていい（「うちもそうでした」程度）。
そして **誘導のために聞かない。本当に知りたいから聞く。** これがヒダネのトーン。

---

## 全体の流れ

```
STEP 1  受付突破                     25秒
STEP 2  名乗り＋自己紹介＋訂正        30秒   ← 質問2問
STEP 3  AIの温度を測る               25秒   ← 質問3問 ★v7で新設
STEP 4  人の話に入る                 50秒   ← 質問5問
STEP 5  教育コスト＋核心              45秒   ← 質問4問
STEP 6  具体例で殴る                 35秒
STEP 7  クロージング質問＋アポ        35秒   ← 質問3問
STEP 8  確定と仕込み                 35秒   ← 質問3問
```

---

## STEP 1 ｜受付突破（25秒）

**ルートA（安全）**
```
お世話になります、名古屋のヒダネと申します。
御社の求人の件でお電話しました。Indeedの「◯◯」の募集を拝見しまして、
1つだけお伺いしたいことがあります。社長さん、いらっしゃいますでしょうか。
```

**ルートB（攻め）**
```
お世話になります、名古屋のヒダネと申します。
うち、AI社員を作ってる会社でして。社員3人でAI社員12人使って回してるんですけど、
その事例を東海の◯◯業さんにお話しして回っています。社長さん、いらっしゃいますか。
```

> ⚠️ **受付には必ず「AI社員」と言う。**「社員を作ってる会社」だけだと人材紹介と誤解され、切られる。

> 🚨 **「採用担当が承ります」と回されたら、この台本を捨てる。**
> **この台本は社長専用。**「採用しなくてよくなる」は採用担当にとって**職業否定**であり、
> そのまま話すと敵になり、社内で潰される。
> **回された瞬間に [06_採用担当ルート.md](06_採用担当ルート.md) へ切り替える。**
>
> 切り替えの合図：**「あ、採用のご担当の方ですか。…求人の原稿って、◯◯さんが書かれてるんですか？」**

## STEP 2 ｜名乗り＋自己紹介＋訂正（30秒）

```
Q1 ◯◯社長でいらっしゃいますか？
```
> 「はい」　← **最初のイエス。名前を呼ばれると人は反応する**

```
突然すみません、名古屋のヒダネの◯◯と申します。

Q2 3分だけ、よろしいですか？
```
> 「まあ、はい」　← **時間の合意を取る。これがないと途中で切られる**

```
ありがとうございます。
弊社、社員を作ってる会社でして。
```

**（黙る）**

> 「人材紹介ですか？」／「派遣？」／「…どういうことですか？」

```
いえ、作るほうです。採用じゃなくて。
```

（一拍）

```
AI社員なんです。うち社員3人しかいないんですけど、AI社員が12人いまして。
```

### 相手が何も聞いてこない場合

```
（無反応・「はあ」）
→ 自分から短く聞く：

  「人材紹介っぽく聞こえますよね。違うんですけど、想像つきます？」
```

**無反応でも、質問を投げれば会話が再開する。**

> ⚠️「人材紹介ですか？」には**即座に否定する。**曖昧にすると商談で崩れる。

---

## STEP 3 ｜AIの温度を測る（25秒）── ★v7で新設

**ここで相手の立ち位置を確定させる。以降の話し方が全部変わる。**

```
Q3 社長、AIって使われてます？
```

| 答え | 次の一手 |
|---|---|
| **「使ってる」** | 「何に使われてます？」→ **話が早い。**具体例をその延長で話す |
| **「使ってない」** | 「ですよね。**うちも去年まで全然でした**」→ 警戒が下がる |
| **「よく分からない」** | 「ほとんどの方がそうです」→ **否定しない。**安心させる |

```
Q4 社内で使ってる方、います？
```
> 「若いのが少し」／「いないですね」

```
Q5 興味はあります？
```
> 「まあ、あるにはある」／「今はいいかな」

### 「今はいいかな」と言われても引かない

```
「ですよね。うちも売り込みじゃないので大丈夫です。
 ちょっとだけ状況伺ってもいいですか？」
→ STEP 4 へ
```

**AIの話で止まらない。** 本題は採用なので、そこへ移る。

### なぜここで温度を測るのか

- **「使ってる」相手に基礎から説明すると、バカにされたと感じる**
- **「使ってない」相手に専門用語を使うと、置いていかれる**
- 3問で分かるなら、聞かない理由がない

## STEP 4 ｜人の話に入る（50秒）

```
Q6 今、人は足りてます？
```
> 「足りてないですね」　← **ほぼ全員がこう答える**

```
Q7 募集は出されてます？
```
> 「出してます」

```
Q8 何名くらい探されてるんですか？
```
> 「2人ですかね」

```
Q9 それ、いつ頃から出されてます？
```
> 「半年くらいかな…」

**ここで1つ返す（尋問にしない）：**
```
半年ですか。
```
（間）

```
Q10 …けっこう、しんどくないですか？
```
> 「まあ、しんどいですよ。応募自体こないですし」

### ★Q10が分岐点

**社長に愚痴を言わせる。ここで喋り出したら、ほぼアポは取れる。**
営業電話で自分を気遣ってくる人間はいないので、警戒が一段下がる。

**返しは共感だけ。解決策を出さない。**
```
そうですよね。今どこもそうみたいで。
```

---

## STEP 5 ｜教育コスト＋核心（45秒）

```
Q11 もし1人採れたとして、入って何か月で戦力になります？
```
> 「3か月くらいはかかりますね」

```
Q12 教えるのって、どなたがやられてます？
```
> 「現場の先輩ですね」　← **職務が特定される。8/3改正で必要な情報**

```
Q13 その方の仕事、止まりますよね？
```
> 「まあ、半分は取られてますね」

**ここで1つ返す：**
```
なるほど。じゃあ1人採ると、実質もう1人分の手が3か月消える感じですね。
```

**社長は採用コストは知っているが、教育中に消えるベテランの工数は計算していない。**

```
Q14 …そもそもなんですけど、その仕事って“人”じゃないとダメですか？
```

**（黙る。ここは長く待つ）**

| 反応 | 返し |
|---|---|
| **「考えたことなかった」** | **勝ち。**「うちもそうでした。3人しかいないので、考えざるを得なかっただけなんですけど」 |
| 「人じゃないと無理でしょう」 | 「**現場は絶対に人ですよね。**うちが作ってるのも、資料作るとか調べるとか、そういう担当だけです」← **即座に同意** |
| 「どういう意味？」 | 「たとえば──」で STEP 6 へ直行 |

---

## STEP 6 ｜具体例で殴る（35秒）── 2体だけ

```
たとえば営業準備の担当が1人いて、会社名を1個渡すと、その会社を調べて
提案書と商談の台本まで作って出してきます。人間だと1社で半日でした。

あと失注の分析だけやってる担当もいて、「次はこう言え」って台本を
直してくるんです。…わりと厳しいんですけど（笑）
```

**相手が言った困りごとで差し替える：**

| 相手が言ったこと | 出す体 |
|---|---|
| 資料作りに時間が取られる | 営業準備担当 |
| 事務が回らない | リスト担当＋フォローメール担当 |
| 数字をまとめる時間がない | 経理・KPI担当 |
| 書類・申請が面倒 | オンボーディング担当 |

**3体目を出さない。**

## STEP 7 ｜クロージング質問＋アポ（35秒）

```
Q15 もし人を増やさずにその仕事が回るなら、興味あります？
```
> 「まあ、あるにはある」　← **イエスが取れたら次へ直行**

```
12人いるんですけど、全員違う仕事してまして。
一番説明しづらいのが、そいつら毎回自分で自分の仕事を採点して、
次から勝手に直してくるところで。

…電話だとちょっと説明しづらいので──
```

```
Q16 30分だけいただいて、御社の社員を1人、作らせてもらえませんか？
```

```
業務を1つ選んでいただければ、それを覚えさせて、そのまま御社で使っていただけます。
無料です。売り込みもしません。
うちがどういう会社かは、それ見てもらうのが一番早いので。
```

```
Q17 来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

### Q15 →「作らせてください」の接続

**Q15で「興味ある」と言った直後に提案するのが肝。**
自分で「興味ある」と言った手前、断りにくくなる。
ただし**誘導ではない** ── 本当に興味がないなら「ないです」と答えられるし、その場合は引く。

### 「興味ない」と言われたら

```
「承知しました。ありがとうございました」
→ 即引く。6か月空ける。押さない。
```

## STEP 8 ｜確定と仕込み（35秒）

```
Q18 当日までに、「これ人にやらせるの、もったいないな」と思ってる業務を
    1つだけ決めておいていただけますか？
```

```
Q19 当日は社長お一人ですか？
```
> 「たぶん自分だけ」

```
その業務をやられてる方も入っていただけると、その場で覚えさせられます。
```
→ **8/3改正で必要な「職務の特定」がその場で完了する。**

```
Q20 ちなみに御社、今何名くらいでやられてるんですか？
```
→ 助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

### 切る前の最終確認

```
□ 日時 / 参加者（社長のみ・業務担当者も）
□ 作る対象の業務
□ 従業員数
□ AIの温度（使ってる／使ってない／分からない）
□ 募集人数・募集期間
□ 受付ルート（A/B）とその結果
□ 形式（オンライン / 訪問）/ メールアドレス
```

**当日中に確認メールを送る。**

## 質問の作法（5つ）

| # | 作法 | 具体的に |
|---|---|---|
| 1 | **質問したら黙る** | 心の中で3秒数える。沈黙を埋めない |
| 2 | **短く聞く** | 1問1行。長い質問は考えさせるので答えが返ってこない |
| 3 | **「なぜ」で聞かない** | 責めに聞こえる。**「いつから」「どのくらい」「どなたが」**で聞く |
| 4 | **2〜3問聞いたら1つ返す** | 尋問にしない。「半年ですか」程度で十分 |
| 5 | **誘導しない** | 本当に知りたいから聞く。「ないです」と言われたら受け入れる |

## NG集

| ✕ 言わない | なぜ |
|---|---|
| **質問を5問以上連続で投げる** | **尋問になる。**2〜3問で1つ返す |
| **長い質問** | 考えさせるので答えが返ってこない。**1問1行** |
| **「なぜ採れないんですか」** | 責めに聞こえる。「いつから」「どのくらい」で聞く |
| **「AIに興味ないですか？」（否定形）** | 否定形の質問は「ない」を引き出す。**「興味はあります？」と肯定形で** |
| 受付に「社員を作ってる会社です」だけ | 人材紹介と誤解され切られる。受付には「AI社員」と言う |
| 「人材紹介ですか？」を曖昧にする | 誤解を放置すると商談で崩れる |
| できないのに「作れます」 | 商談で崩れて信用ごと失う |
| 「人を減らせます」「人件費削減」「省人化」 | リストラに聞こえた瞬間に敵になる |
| 「AI社員1人＝人間1人分です」 | **誇大。**言えるのは「うちは3人で回している」という事実だけ |
| 確認できていない4体について語る | **嘘になる** |
| 「助成金で実質10万円です」 | 期待値を先に上げすぎ。8/3改正で審査が厳しくなった今は特に危険 |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「営業ではありません」 | **嘘。**受付にも決裁者にも嘘をつかない |
