# 02. トークスクリプト（v6）

> **v5からの変更**
> ① 自己紹介を「**弊社、社員を作ってる会社です**」に変更。**人材紹介との誤解をわざと誘発し、訂正で驚かせる**
> ② アポを「12人お見せします」から「**御社の社員を1人、作らせてください**」に変更
> ③「説明を拒否する」ステップをアポ打診に統合（「電話だと説明しづらいので、作らせてください」が一続きになる）

**全体で3〜4分。**

```
STEP 0  仕込み（架電前）      5分
STEP 1  受付突破             25秒
STEP 2  自己紹介と訂正        30秒   ← ★v6の入口
STEP 3  強みの一言           20秒
STEP 4  質問で話させる      100秒   ← 相手7割
STEP 5  具体例で殴る          40秒
STEP 6  アポ打診             35秒   ← ★v6の本体「作らせてください」
STEP 7  確定と仕込み          40秒
```

---

## STEP 1 ｜受付突破（25秒）

### ルートA（安全）── 求人の件

```
お世話になります、名古屋のヒダネと申します。
御社の求人の件でお電話しました。
Indeedの「◯◯」の募集を拝見しまして、1つだけお伺いしたいことがあります。
社長さん、いらっしゃいますでしょうか。
```

### ルートB（攻め）── AI社員の件

```
お世話になります、名古屋のヒダネと申します。
うち、AI社員を作ってる会社でして。
社員3人でAI社員12人使って回してるんですけど、
その事例を東海の◯◯業さんにお話しして回っています。
社長さん、いらっしゃいますでしょうか。
```

> ⚠️ **受付には必ず「AI社員」と言う。**
> 受付に「社員を作ってる会社です」とだけ言うと**人材紹介と誤解され、「お断りしてます」で切られる**。
> 誤解を誘うのは社長に出てからだけ。**受付には正確に言う。**

---

## STEP 2 ｜自己紹介と訂正（30秒）── ★v6の入口

```
突然すみません、名古屋のヒダネの◯◯と申します。

弊社、社員を作ってる会社でして。
```

**（黙る）**

> 相手：「人材紹介ですか？」／「派遣？」／「…どういうことですか？」

```
いえ、作るほうです。

採用じゃなくて。
```

**（一拍）**

```
AI社員なんです。
うち社員3人しかいないんですけど、AI社員が12人いまして。
```

### なぜこの3段構えなのか

| 段 | 台詞 | 起きること |
|---|---|---|
| ① | 「社員を作ってる会社でして」 | **一言で意味不明。**しかし怪しくはない。相手が必ず何か聞いてくる |
| ② | 「作るほうです。採用じゃなくて」 | **誤解の訂正。**「採用」との対比が立つ |
| ③ | 「AI社員なんです。社員3人でAI社員12人」 | 種明かし。**ここで初めて「AI」を言う** |

**相手に質問させるのが目的。** こちらが説明を続けるより、相手が「どういうこと？」と聞いてきた形にするほうが、以降ずっと聞いてもらえる。

### ⚠️ 誤解を放置しない

「人材紹介ですか？」と聞かれたら、**必ずその場で否定する。**
誤解させたまま話を進めるのは、ヒダネのやり方ではないし、商談で崩れる。

```
◯「いえ、作るほうです。採用じゃなくて」（即座に訂正）
✕「まあ、人手の話ではあるんですけど…」（曖昧にする）
```

### 相手が何も聞いてこない場合

```
（無反応・「はあ」）
→ 間を置かずに続ける：
  「採用するんじゃなくて、作るほうなんですけど。
   うち社員3人で、AI社員が12人いまして」
```

## STEP 3 ｜強みの一言（20秒）

```
それで、人が足りなくなったら、AI社員を1人作るんです。
採用しないので。
```

（一拍）

```
人って、採用する時代から、作る時代になったなと思ってて。
```

**必ず「事実 → 一般化」の順。** 先に一般化を言うと意識高い系に聞こえる。

### ⚠️ 絶対に守る言い分け

| ✕ | ◯ |
|---|---|
| 「人を減らせます」 | 「これから**増やさなくて済みます**」 |
| 「人件費削減」 | 「**増員の判断をしなくて済みます**」 |
| 「AIに置き換えます」 | 「**今いる人の手が空きます**」 |

**今いる人には触れない。これから増える予定の1人の話だけをする。**

---

## STEP 4 ｜質問で話させる（100秒）── 相手7割

### 話させる4つの作法

1. **質問したら黙る**（心の中で3秒数える）
2. **答えやすい順に聞く**（事実 → 状況 → 感情 → 数字 → 気づき）
3. **「なぜ」で聞かない**（責めに聞こえる。「いつから」「どのくらい」で聞く）
4. **2問聞いたら1つ返す**（尋問にしない）

| # | 質問 |
|---|---|
| Q1 | 今も募集出されてますよね。何名くらい探されてるんですか？ |
| Q2 | それ、いつ頃から出されてます？ |
| **Q3** | **…けっこう、しんどくないですか？** ← 愚痴が出たら勝ち |
| Q4 | 1人採れたとして、一人前になるまでどのくらいかかります？ |
| Q5 | その間、教える先輩の方の仕事ってどのくらい止まります？ |
| **Q6** | **…そもそも、その仕事って"人"じゃないとダメですか？** ← 核心。長く待つ |

**Q5のあと1つだけ返す：**
```
なるほど。じゃあ1人採ると、実質もう1人分の手が3か月消える感じですね。
```

**Q6の反応別：**

| 反応 | 返し |
|---|---|
| **「考えたことなかった」** | **勝ち。**「うちもそうでした。3人しかいないので、考えざるを得なかっただけなんですけど」 |
| 「人じゃないと無理でしょう」 | 「**現場は絶対に人ですよね。**うちが作ってるのも、資料作るとか調べるとか、そういう担当だけです」← **即座に同意** |
| 「どういう意味？」 | 「たとえば──」で STEP 5 へ直行 |

## STEP 5 ｜具体例で殴る（40秒）── 2体だけ

```
たとえば、営業準備の担当が1人いるんですけど、
会社名を1個渡すと、その会社を調べて、提案書と商談の台本まで作って出してきます。
人間がやってた時は、1社で半日かかってたので。

あと、失注の分析だけやってる担当もいて。
商談が流れると理由を分析して、「次はこう言え」って台本を直してくるんです。
…わりと厳しいんですけど（笑）
```

**相手が STEP 4 で言った困りごとで差し替える：**

| 相手が言ったこと | 出す体 |
|---|---|
| 資料作りに時間が取られる | 営業準備担当 |
| 事務が回らない | リスト担当＋フォローメール担当 |
| 数字をまとめる時間がない | 経理・KPI担当 |
| 書類・申請が面倒 | オンボーディング担当 |

**3体目を出さない。**

## STEP 6 ｜アポ打診（35秒）── ★v6の本体

```
12人いるんですけど、全員違う仕事してまして。
一番説明しづらいのが、そいつら毎回自分で自分の仕事を採点して、
次から勝手に直してくるところで。

…電話だとちょっと説明しづらいので──
```

（ここで切り替える）

```
30分だけいただいて、
御社の社員を1人、作らせてもらえませんか。

業務を1つ選んでいただければ、それを覚えさせて、
そのまま御社で使っていただけます。

無料です。売り込みもしません。
うちがどういう会社かは、それ見てもらうのが一番早いので。

来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

### なぜ「作らせてください」が強いのか

| v5（見せる） | v6（作る） |
|---|---|
| 「12人が何やってるか全部お見せします」 | 「**御社の社員を1人、作らせてもらえませんか**」 |
| 相手は**見学者** | 相手は**当事者** |
| 持ち帰るのは印象 | **持ち帰るのは動くAI社員そのもの** |
| 断る理由：「忙しい」で足りる | 断る理由：**探しにくい** |

### 効いている4つの要素

| 要素 | 役割 |
|---|---|
| **「作らせてもらえませんか」** | **謙譲。**売り込みではなく「やらせてください」。押していないのに前に出ている |
| 「御社の社員を1人」 | **相手のもの**になる。サンプルではない |
| 「そのまま御社で使っていただけます」 | 成果物が残る。30分が無駄にならない |
| 「うちがどういう会社かは、それ見てもらうのが一番早い」 | **アポの目的が自己紹介**になる。営業ではないと言い切れる |

### 「説明しづらい → だから作らせてください」の流れ

**この接続がv6の設計の要。**
説明を拒否したまま終わると、ただの焦らしになる。
**「説明できないので、作って見せます」**なら、拒否が提案に変わる。

## STEP 7 ｜確定と仕込み（40秒）

```
当日までに、「これ人にやらせるの、もったいないな」と思ってる業務を
1つだけ決めておいていただけますか。
```

**v5から変更：**「人を増やそうと思ってる仕事」→「**人にやらせるのがもったいない業務**」。
「作る」というアポに合わせて、**作る対象を選んでもらう**言い方にする。

```
当日は社長お一人ですか？
その業務を実際にやられてる方に入っていただけると、その場で覚えさせられます。
```
→ **8/3改正で必要な「職務の特定」がその場で完了する。**

```
ちなみに御社、今何名くらいでやられてるんですか？
```
→ 助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

### 切る前の最終確認

```
□ 日時 / 参加者（社長のみ・業務担当者も）
□ 作る対象の業務
□ 従業員数
□ 募集人数・募集期間（Q1・Q2）
□ 受付ルート（A/B）とその結果
□ 形式（オンライン / 訪問）/ メールアドレス
□ 準備：作る対象の業務を1つ決めておいてもらう
```

**当日中に確認メールを送る。**

---

## ⚠️ 最重要の確認事項 ──「30分で1人作れるのか」

**この台本は「30分で1体作って渡せる」ことが前提。**
できないのに言うと、商談で崩れて信用ごと失う。

### 実力に合わせて言葉を変える

| ヒダネの実力 | 電話で言う言葉 | 強さ |
|---|---|---|
| **30分で簡易版1体を作って渡せる** | 「**1人作らせてください**」 | **◎ 最強** |
| 30分では完成しないが着手できる | 「1人**作り始めさせて**ください」 | ○ |
| 設計までしかできない | 「どんな社員を作るか、**設計だけ一緒に**やらせてください」 | △ |

**できることだけを言う。** できないことを言った瞬間、この設計は全部無効になる。

### 商談側で必要な線引き

「無料で1体もらえるなら、それで十分」で終わらせないために：

```
その場で作れるのは 簡易版1体 まで。
本格運用には、業務の棚卸し・判断基準の言語化・社内展開が要る。
        ↓
そこが研修（40万円/人）の価値になる。
```

**電話でも「1人だけ」と明示しておく。** 後出しで制限をかけると不誠実になる。

## 記録項目

| 列名 | 内容 |
|---|---|
| 受付ルート（A / B） | 突破率の比較用 |
| **「人材紹介ですか？」が出たか** | **v6で追加。**誤解誘発が機能しているかの指標（○/✕） |
| 募集人数・募集期間 | Q1・Q2 |
| **「しんどい」が出たか** | **Q3で愚痴が出たか ← 最重要の指標** |
| 一人前までの期間 / 削られる工数 | Q4・Q5 |
| **Q6の反応** | 「考えたことなかった」/「人じゃないと無理」/「どういう意味？」 |
| **作る対象に選ばれた業務** | **v6で追加。**商談の準備に直結 |
| 従業員数 | 助成金判定用 |
| 断り分類・次回接触時期 | 再架電の管理 |

> **「人材紹介ですか？」が出たかを記録する。**
> 出ているなら STEP 2 の誤解誘発が機能している。
> 出ずに無反応が続くなら、言い方が弱いか、早口で聞き取られていない。
