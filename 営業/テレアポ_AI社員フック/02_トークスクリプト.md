# 02. トークスクリプト（v2）

> **v1からの変更点**
> 主軸業務を「見積」から「**採用の応募者対応**」に変更。理由は [README.md](README.md) の判断②を参照。
> 受付トークも全面的に作り直した。

**全体で3分以内。**

```
STEP 0  仕込み（架電前）    5分   ← ここが本体
STEP 1  受付突破           25秒
STEP 2  インパクト         30秒   ← 「え？」を取る
STEP 3  一点確認           60秒   ← 取りこぼしを可視化する
STEP 4  アポ打診           30秒
STEP 5  確定と仕込み       40秒
```

---

## STEP 0 ｜仕込み（架電前・1社5分）

**この設計は、仕込みがすべて。** ここを飛ばすと受付で終わる。

### やること（1社5分）

```
1. 会社名 + 求人 で検索。Indeed / 求人ボックス / 自社採用ページを見る
2. 出している職種をメモする（例：「製造スタッフ」「営業事務」）
3. その原稿の「抜けている点」を1つ探す ← 下の8パターンから
4. 架電メモに書く：職種名 / 抜けている点
```

### 抜けている点の8パターン（どの業界の求人にもある）

| # | 抜けている点 | 応募者側の困りごと |
|---|---|---|
| **1** | **応募後、何日で連絡が来るか書いていない** | **一番不安。他社と並行応募中なので待てない** |
| 2 | 給与に幅がない／広すぎる（例：20万〜40万） | 自分がいくらか判断できない |
| 3 | 職種名が抽象的（「一般事務」だけ） | 検索でヒットしない |
| 4 | 1日の流れが書いていない | 働くイメージが湧かない |
| 5 | 写真がない／建物の外観だけ | 人が見えない |
| 6 | 「アットホームな職場です」で終わっている | 情報がゼロ |
| 7 | 未経験可なのに研修体制の記載がない | 入ってから困りそう |
| 8 | 1つの原稿に複数職種が混在 | 検索一致度が落ちる |

> **原則として「1」を使う。** 今回の設計の主軸（応募者対応のスピード）にそのまま繋がるため、
> 受付 → 社長 → インパクト → アポ が1本の話になる。
> 「1」が既に書かれている優良企業だった場合のみ、2〜8から選ぶ。

## STEP 1 ｜受付突破（25秒）

### v1がなぜ弱かったか

```
✕「AIで業務時間を減らす取り組みをしている会社でして…」
```
→ **受付が「営業ですね」と判断できてしまう。** 判断できるものは断られる。

### 受付が社長に取り次ぐ3条件

1. **受付の権限外の話である**（判断できないので、上げるしかない）
2. **固有名詞が入っている**（調べてきた＝リストへの一斉架電ではないと分かる）
3. **短い**（1つだけ、と分かる）

### v2

```
お世話になります。名古屋のヒダネと申します。

御社の求人の件でお電話しました。
Indeedに出されている「製造スタッフ」の募集を拝見しまして、
応募数に関わる点で1つだけお伝えしたいことがあります。

社長さん、いらっしゃいますでしょうか。
```

**効いている要素：**

| 要素 | 効き方 |
|---|---|
| 「求人の件」 | **人事案件は受付の権限外。**判断できないので上げるしかない |
| 「Indeedに出されている**「製造スタッフ」**の」 | **固有名詞。**実際に見てきた証拠。一斉架電ではないと分かる |
| 「応募数に関わる点」 | 会社の利益に直結。無視しづらい |
| 「1つだけ」 | 短いと分かる。時間の心配が消える |

### 「どういったご用件でしょうか？」と粘られたら

```
募集要項の書き方の件です。
今の原稿だと、応募される方が一番知りたい情報が1つ抜けてまして。
それをお伝えしたくてお電話しました。
```

**「1つ抜けている」は強い。** ただし**本当に用意しておくこと**（STEP 0）。
用意せずに使うと、社長が出た瞬間に詰む。**この一言は仕込みとセットでのみ成立する。**

### 受付の反応別

| 反応 | 返し |
|---|---|
| 「担当の者に代わります」 | 採用担当が出るなら**それでいい**。話す内容は同じ |
| 「資料を送ってください」 | 「承知しました。ただ御社の原稿を見ての具体的な話なので、1分だけお電話でお伝えできませんか」 |
| 「そういうお電話はお断りしてます」 | 「失礼しました」→ **即引く。6か月空ける** |
| 「社長は不在です」 | **「何時ごろお戻りでしょうか」→ 再架電。ここが一番数が取れる** |

## STEP 2 ｜インパクト（30秒）

決裁者が出たら、最初の20秒。**説明せずに、驚かせる。**

```
突然すみません、名古屋のヒダネの◯◯と申します。

御社のIndeedの求人、拝見しました。
1点だけお伝えしたくてお電話したんですが──

応募したあと何日で連絡が来るか、書かれてないですよね。
実は応募者が一番気にしてるの、そこなんです。

（一拍おく）

で、うち社員3人しかいない会社なんですけど、
夜中の2時に応募が来ても、3分で返信してます。

人間、誰も起きてないです。AIが返してるので。
```

### なぜこの組み立てなのか

| ブロック | 役割 |
|---|---|
| 「拝見しました」＋具体的な指摘 | **まず与える。**売り込みの前に価値を渡す |
| 「応募者が一番気にしてる」 | 社長が知らない事実。**教えてもらった立場**になる |
| （一拍おく） | ここで相手が考える時間を作る。畳みかけない |
| 「社員3人しかいない」 | 相手より小さい。警戒が下がる |
| 「夜中の2時」「3分」 | **具体的な時刻と数字。映像が浮かぶ** |
| **「人間、誰も起きてないです」** | **オチ。ここで「え？」が出る** |
| 「AIが返してるので」 | 種明かし。この順番が重要 |

### 順番が命

```
✕ 「AIで応募者対応を自動化してます」
   → 説明。想像できてしまう。驚きがない

◯ 「夜中の2時に応募が来ても3分で返信してます。人間、誰も起きてないです」
   → 事実 → 矛盾 → 「え？」→ 種明かし
```

**先に「AI」と言わない。** 「AIで◯◯します」は聞き飽きられている。
**不可能に聞こえる事実を先に置いて、後から種明かしする。**

### 相手が「え、どうやって？」と聞いてきたら（＝勝ち）

```
応募が来た瞬間にAIが読んで、その人向けの返信を書いて送ってます。
質問が来たらAIが答えますし、面接の日程調整もAIがやってます。

うち3人しかいないので、そうしないと回らないんですよ。
```

**まだ売らない。** 次のステップへ。

## STEP 3 ｜一点確認（60秒）— 取りこぼしを可視化する

**目的：「応募が来ない」ではなく「来た応募を取りこぼしている」に気づかせること。**

これが今回の設計で最も価値のある部分。社長は前者だと思っている。

```
御社だと、応募が来てから最初にご連絡されるまで、
だいたいどのくらいかかってます？
```
> 「2〜3日かな…」／「担当がやってるので分からないです」

```
なるほど。実は応募者側の目安って4〜6時間なんです。
24時間を超えると、だいたい他社で決まってます。
```

**← ここで公開データを出す。**（応募から初回返信の理想は4〜6時間、24時間以内の対応率90%が目標）
誇張ではなく事実なので、ヒダネのトーンルールに沿う。

```
御社、月に何件くらい応募来てます？
```
> 「5件くらいですかね」

```
そのうち、実際に会えてるのは何人ですか？
```
> 「2人くらいかな」

```
なるほど。じゃあ3人はどこかで消えてるんですね。
```

### この最後の一言が本体

社長は「応募が来ない」と思っている。実際は「**来た応募の6割を取りこぼしている**」。
**この気づきを渡すことが、この電話の最大の価値。**

そして中小企業の採用単価は**30万円台前半**（3〜300人規模）。
月3人取りこぼしていれば、**年間で相当な機会損失**になっている ── ただし電話で金額換算まではしない。踏み込みすぎ。

### 相手が数字を答えられない場合

| 状況 | 返し |
|---|---|
| 「担当がやってるので分からない」 | 「じゃあ当日、その方も入っていただけますか。数字が正確に出ます」→ **むしろ好都合** |
| 「今は募集してない」 | 「失礼しました。次に募集されるのはいつ頃ですか」→ 時期だけ取って引く |
| 「応募自体が来ない」 | 「原稿の話になりますね。それも見れます」→ STEP 0 で用意した指摘に戻る |

## STEP 4 ｜アポ打診（30秒）

```
30分だけいただいて、2つやります。

1つは、御社の求人原稿をその場でAIに書き直させます。
どう変わるか、見ていただければ。

もう1つは、応募が来てから会うまでに何人消えてるか、
御社の実際の数字で出します。

それだけ持ち帰っていただければ、それで結構です。
売り込みはしません。

来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

### 「その場でAIに書き直させる」が効く理由

**「AIでできるの!?」を言葉で説明せず、体験させる。**
テレアポの相手は「AIで効率化」という言葉を100回聞いている。でも**目の前で自社の求人原稿が書き変わるのを見た人**はほぼいない。

| 要素 | 役割 |
|---|---|
| 「その場で」 | 実演。持ち帰りの資料ではない |
| 「御社の求人原稿を」 | **相手のもの**。サンプルではない |
| 「2つやります」 | 中身が具体的。30分の使い道が見える |
| 「売り込みはしません」 | 実際にしないので嘘にならない |

> **「売り込みはしない」は必ず守る。** 実演で提案を始めた瞬間、この設計は壊れる。
> 原稿が良くなるのを見れば、**相手から「で、これうちでもできるんですか？」と聞いてくる。**
> そこで初めて研修の話になる。順番を守る。

## STEP 5 ｜確定と仕込み（40秒）

### ① 事前準備を1つだけ頼む

```
当日、Indeedの管理画面を開ける状態にしておいていただけますか。
その場で原稿を触るので。
```

準備を頼むとドタキャン率が下がる。**ただし1つだけ。**

### ② 参加者を確認する

```
当日は社長お一人ですか？
応募者への返信を実際にやられてる方も入っていただけると、数字が正確に出ます。
```

→ その担当者が入ると、**8/3改正で必要な「職務の特定」がその場で完了する**（＝採用担当者という職務）。

### ③ 従業員数をさらっと聞く

```
ちなみに御社、今何名くらいでやられてるんですか？
```

助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

### ④ 形式と連絡先

```
オンラインと訪問、どちらがよろしいですか。
（オンラインなら）URLをお送りしたいので、メールアドレスをお願いします。
```

### 切る前の最終確認

```
□ 日時
□ 参加者（社長のみ / 採用担当も）
□ 対象の求人（どの職種か）
□ 従業員数
□ 月間の応募数・面談到達数（聞けていれば）
□ 形式（オンライン / 訪問）
□ メールアドレス
□ 準備：Indeed管理画面を開ける状態に
```

**当日中に確認メールを送る。**

## 断られたときの処理

| 断り文句 | 返し | その後 |
|---|---|---|
| **今は募集してない** | 「失礼しました。次に募集されるのはいつ頃ですか」 | **時期だけ取って引く。**再架電リストへ |
| **採用は間に合ってる** | 「そうなんですね。差し支えなければ、どちらの媒体で採れてますか」 | 情報を取って引く。6か月後 |
| **人材紹介はお断り** | 「あ、紹介会社ではないんです。求人原稿の話でして」 | **誤解を即座に解く。**ここで引かない |
| **担当に聞かないと分からない** | 「では担当の方に代わっていただけますか」 | 担当でOK。話す内容は同じ |
| **AIはうちには早い** | 「そう仰る会社さんが多いです。もし興味が出たら、いつ頃だと話しやすいですか」 | 次の接触時期だけ取る |
| **資料を送って** | 「承知しました。メールアドレスをお願いできますか」 | **送る。リード化。**断りではない |
| **金額は？** | 「求人の状況で変わるので、実際に見てからでないと出せないんです」 | **電話で金額を言わない** |
| **興味ない** | 「承知しました。ありがとうございました」 | 即引く。6か月空ける |

> **2回断られたら引く。** 3回目を押すと会社の名前が傷つく。

## NG集（電話で絶対に言わないこと）

| ✕ 言わない | なぜ |
|---|---|
| **「AIで応募者対応を自動化しませんか」** | **説明になってしまう。驚きが消える。**事実→矛盾→種明かしの順を守る |
| **「助成金で実質10万円です」** | 期待値を先に上げすぎ。8/3改正で審査が厳しくなった今は特に危険 |
| **「研修のご案内です」** | 研修営業は即切られる |
| **「採用のご支援を」** | 人材紹介と誤解される。**「求人原稿の件」と言い切る** |
| **「応募、来てないですよね」** | 決めつけ。社長のプライドを傷つける |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「今年度で助成金が終わるので急いだほうが」 | 事実だが急かす道具に使わない |
| 「営業ではありません」 | **嘘。**受付にも決裁者にも嘘をつかない |

## ⚠️ この台本を使う前提条件

```
「夜中の2時に応募が来ても3分で返信してます。AIが返してるので。」
```

**この一言は、ヒダネが実際に採用AIを運用していて初めて使える。**

やっていないなら**嘘**になり、商談で「見せてください」と言われた瞬間に終わる。
そしてヒダネの強みは「自分たちが実際に使っているものを売る」ことそのもの。ここが崩れると全部崩れる。

### まだ運用していない場合の手順

```
1. まずヒダネの採用フローにAIを組む（応募検知 → 一次返信 → 質問対応 → 日程調整）
2. 1〜2か月運用して、実際の数字を取る（返信までの中央値、応募→面談の到達率）
3. その数字を持ってから架電を始める
```

**運用実績のない台本は使わない。** これは設計上の前提であって、努力目標ではない。

## 記録項目（架電管理列に追加）

| 列名 | 内容 |
|---|---|
| 出している求人 | 職種名（架電前に記入） |
| 使った指摘 | 8パターンのどれを使ったか（架電前に記入） |
| **応募までの返信時間** | 相手が言った数字（例：2〜3日） |
| **月間応募数** | 相手が言った数字（例：5件） |
| **面談到達数** | 相手が言った数字（例：2人） |
| **取りこぼし数** | 応募数 − 面談到達数（例：3人） |
| 従業員数 | 助成金判定用 |
| 断り分類 | 募集なし／間に合ってる／紹介と誤解／担当不在／早い／資料希望／興味なし |
| 次回接触時期 | 再架電の日付 |

**「取りこぼし数」を必ず残す。** 次に電話するとき「前回、月5件の応募で2人しか会えていないと伺いましたが」から入れる。
半年後でも刺さる。
