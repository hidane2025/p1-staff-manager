# 02. トークスクリプト（v4）

> **v3からの変更**
> **「AI社員」を主役に据え直した。** v3までは「AI社員は証拠として使い、商品として売らない」＝
> フックを自己紹介の位置に留めていたが、**「AI社員」という聞き慣れない単語そのものが最大の武器**なので、
> これを前面に出す設計に変更。
>
> 主軸業務（引き継ぎ・教育）は、AI社員の話から自然に降りていく形で残した。

**全体で3分以内。**

```
STEP 0  仕込み（架電前）    5分
STEP 1  受付突破           25秒   ← A/B 2ルート用意
STEP 2  AI社員フック       20秒   ← 説明しない
STEP 3  具体例で殴る       50秒   ← 名指しで2体
STEP 4  説明を拒否する     20秒   ← 最強のアポ誘導
STEP 5  一点確認           45秒
STEP 6  アポ打診           30秒
STEP 7  確定と仕込み       40秒
```

---

## なぜ「AI社員」が刺さるのか

**「AIツール」「AI導入」「業務効率化」は聞き飽きられている。** 相手の頭の中に既に棚があり、そこに入れられて終わる。

**「AI社員」には棚がない。**

| | |
|---|---|
| 「AI」も「社員」も、単語としては誰でも知っている | → 危険ではない・怪しくない |
| でも「AI社員」という組み合わせは知らない | → **意味が分からない** |
| しかも「12人」と数えられる | → **ツールは数えない。社員は数える** |

> **既知と未知の差が適度なときに、人は一番知りたくなる。**
> 完全に未知だと無視される。完全に既知でも無視される。
> **「単語は分かるのに、組み合わせが分からない」が最適。**

そして電話の目的は理解させることではない。**「よく分からないけど聞いてみよう」を作ること。**

## STEP 0 ｜仕込み（架電前・1社5分）

```
1.「会社名 + 求人」で検索。職種と掲載期間を確認
2. HPを見て、社長の名前・従業員数・業種を確認
3. 相手のタイプを推測し、【出す3体目】を決めておく  ← v4で追加
4. 架電メモに書く：社長名 / 職種 / 3体目
```

### 3体目の決め方（→ [04_AI社員カタログ.md](04_AI社員カタログ.md)）

| 相手のタイプ | 出す体 |
|---|---|
| 数字を見たがる社長 | 経理・KPI担当 |
| 書類・申請が面倒そう | オンボーディング担当 |
| 教育・人材の話が多い | カリキュラム担当 |
| 営業を強くしたい | リスト担当＋フォローメール担当 |
| 改善したいがやり方が分からない | 報告書担当（アップセル検出） |

## STEP 1 ｜受付突破（25秒）── 2ルートをA/Bで試す

**どちらが通るかは実際にかけないと分からない。両方使って記録し、比較する。**

### ルートA（安全・実績あり）── 求人の件

```
お世話になります。名古屋のヒダネと申します。

御社の求人の件でお電話しました。
Indeedに出されている「製造スタッフ」の募集を拝見しまして、
1つだけお伺いしたいことがあります。

社長さん、いらっしゃいますでしょうか。
```

**強み：** 人事案件は受付の権限外。固有名詞があるので一斉架電に見えない。
**弱み：** AI社員の話に持っていくのに、ブリッジが1本必要。

### ルートB（攻め）── AI社員の件

```
お世話になります。名古屋のヒダネと申します。

うち、社員3人でAI社員を12人使って会社を回してまして、
その事例を東海の製造業さんにお話しして回っています。

社長さん、いらっしゃいますでしょうか。
```

**強み：** 受付も「え？」となる。**判断できないので上げるしかない。**
**弱み：** 「怪しい」と判断されて弾かれるリスク。受付は怪しいものを弾く。

**リスクを下げる工夫：**
- 社名を先に、はっきり名乗る
- 「名古屋の」を必ず入れる（地元＝実在する会社に聞こえる）
- 「事例をお話しして回っています」＝ 売り込みではなく共有の体
- 早口にしない。怪しさは声のスピードから出る

### 記録して比較する

```
架電管理列に「受付ルート（A/B）」を追加し、突破率を集計する。
50件ずつ試して、通ったほうに寄せる。
```

### 「ご用件は？」と粘られたら

| ルート | 返し |
|---|---|
| A | 「採用された方の受け入れ体制のことでして。未経験の方も可、と書かれていたので、その後どうされているのか伺いたくて」 |
| B | 「うちが社員3人でどうやって回してるかという話です。同じ規模の会社さんに聞かれることが多くて、お話しして回っています」 |

## STEP 2 ｜AI社員フック（20秒）── 説明しない

```
突然すみません、名古屋のヒダネの◯◯と申します。

うち、社員3人しかいない会社なんですけど、
AI社員が12人いまして。
```

**（一拍。ここで説明しない）**

> **説明した瞬間に「AIで効率化」の棚に入る。**
> 沈黙に耐える。相手が「え？」と言うまで待つ。

### 相手の反応別

| 反応 | 意味 | 次の一手 |
|---|---|---|
| 「え？」「どういうこと？」 | **勝ち。** 好奇心が立った | STEP 3 へ |
| 「…はあ」（無反応） | 伝わっていない | STEP 3 に進んで具体例で殴る |
| 「AIね、うちはいいです」 | 既存の棚に入れられた | 「あ、ツールの話じゃないんです」で一度切り返す |

### ルートAで入った場合のブリッジ

求人の話から入ったなら、1本渡してから繋ぐ。

```
未経験の方が入られたあと、教えるのって
どなたがやられてるんですか？
```
> 「現場の先輩ですね」

```
そうですよね。教えてる間、その先輩の仕事は止まりますよね。

──うち、社員3人しかいない会社なんですけど、
AI社員が12人いまして。
```

## STEP 3 ｜具体例で殴る（50秒）── 名指しで2体

**抽象的な説明をしない。名前と担当業務を、具体的に言う。**

### 1体目（つかみ）── 営業準備担当

```
たとえば、営業準備の担当が1人いるんですけど、

会社名を1個渡すと、その会社を調べて、
提案書と商談の台本まで作って出してきます。

人間がやってた時は、1社で半日かかってたので。
```

**なぜこれが1体目か：** 全業種に伝わる。かつ「調べる → 資料を作る」は誰でも像が浮かぶ。

### 2体目（笑いを取る）── 失注分析担当

```
あと、失注の分析だけやってる担当もいて。

商談が流れると、なんで流れたかを分析して、
「次はこう言え」って台本を直してくるんです。

…わりと厳しいんですけど（笑）
```

> **笑いが取れると警戒が一段下がる。** 押し売りの人間は自分を笑わせない。
> ここで相手が笑ったら、ほぼアポは取れる。

### 3体目（STEP 0 で決めておいたもの）

相手のタイプに合わせて1体だけ。→ [04_AI社員カタログ.md](04_AI社員カタログ.md)

**例：数字を見たがる社長なら**
```
あと、週次のKPIと月次のPL、AIが勝手に作って出してきます。
人間は見るだけです。
```

**例：書類が面倒そうな社長なら**
```
助成金の書類も、計画届から支給申請までAIが用意します。
```

### ⚠️ 3体で止める

**4体目を出さない。** 説明が長いほど「結局AIツールの話か」の棚に戻る。

## STEP 4 ｜説明を拒否する（20秒）── 最強のアポ誘導

```
12人いるんですけど、全員違う仕事してまして。

一番説明しづらいのが、
そいつら毎回自分で自分の仕事を採点して、
次から勝手に直してくるところで。

…電話だとちょっと説明しづらいんですけど。
```

### この4行が今回の設計の中心

| 要素 | 効き方 |
|---|---|
| 「全員違う仕事してまして」 | **情報の欠落を作る。**残り9人が気になる |
| 「自分で自分を採点して、次から勝手に直してくる」 | **これが「AI社員」と呼ぶ根拠。**ツールは繰り返す。社員は反省を持ってくる |
| **「電話だとちょっと説明しづらいんですけど」** | **説明を拒否することで、相手が「じゃあ会って聞く」となる** |

> **説明しきらないことが、アポになる。**
> 全部説明すると「分かった、じゃあいいや」になる。
> そして**実際に複雑なので、この一言は嘘ではない。**

## STEP 5 ｜一点確認（45秒）── 相手の会社に着地させる

**ここまでは全部ヒダネの話。ここで初めて相手の話にする。**

```
御社だと、この人が辞めたら止まるな、っていう業務ありますか？
```
> 「◯◯さんの担当してるところですね」

```
その方、何年目です？
```
> 「20年くらい」

```
その方に引き継ぎ書を書いてもらったとして、
判断のところまで書けそうですか？
```
> 「…難しいでしょうね」

```
そこなんです。
うちも3人しかいないので、1人辞めたら終わりなんですよ。

だから、手順じゃなくて判断のほうを
AIに移してあるんです。

手順書だと書けないんですよね、そこは。
```

### なぜここで「引き継ぎ」に降りるのか

AI社員の話は面白いが、**そのままでは相手の課題にならない**。
「うちには関係ない話」で終わらせないために、**必ず相手の会社の具体的な業務に着地させる。**

そして「引き継ぎ・判断の継承」は、
- どの業界にもある
- 社長が痛みを知っている
- **既存ツールと被っていない**（マニュアルツールは手順しか残せない）

→ 選定の根拠は [03_刺さる業務カタログ.md](03_刺さる業務カタログ.md)

### 相手が「属人化はしてない」と言ったら

```
それはすごいですね。どうやられてるんですか？
```

**素直に聞いて引く。** 学ぶ姿勢が印象に残る。無理に課題を作らない。

## STEP 6 ｜アポ打診（30秒）

```
30分だけいただいて、うちのAI社員12人が何やってるか、
全部お見せします。画面で。

その上で、御社だとどの仕事が渡せそうか、
1個だけ一緒に選んでみませんか。

それだけ持ち帰っていただければ、それで結構です。
売り込みはしません。

来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

| 要素 | 役割 |
|---|---|
| **「12人が何やってるか、全部お見せします」** | **STEP 4 で拒否した説明を、ここで約束する。**未回収の好奇心が回収される |
| 「画面で」 | 見せられるものがあると分かる。空論ではない |
| 「1個だけ一緒に選ぶ」 | 相手の作業が軽い。かつ**職務の特定が終わる**（8/3改正対応） |
| 「売り込みはしません」 | 実際にしないので嘘にならない |

> **STEP 4 の「説明しづらい」と STEP 6 の「全部お見せします」はセット。**
> 片方だけだと効かない。**焦らして、回収する。**

## STEP 7 ｜確定と仕込み（40秒）

```
当日までに、「これが止まると困る」という業務を
1つだけ決めておいていただけますか。
```

```
当日は社長お一人ですか？
その業務を実際にやられてる方に入っていただけると、その場で移せます。
```
→ **8/3改正で必要な「職務の特定」がその場で完了する。**

```
ちなみに御社、今何名くらいでやられてるんですか？
```
→ 助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

```
オンラインと訪問、どちらがよろしいですか。
（オンラインなら）URLをお送りしたいので、メールアドレスをお願いします。
```

### 切る前の最終確認

```
□ 日時 / 参加者（社長のみ・業務担当者も）
□ 対象業務（止まると困るもの）
□ 従業員数
□ 受付ルート（A/B）とその結果  ← 記録用
□ 形式（オンライン / 訪問）/ メールアドレス
□ 準備：業務を1つ決めておいてもらう
```

**当日中に確認メールを送る。**

## 想定される質問と返し

| 相手の質問 | 返し |
|---|---|
| **「AI社員って何ですか？」** | 「うちの仕事のやり方を、AIに1個ずつ覚えさせたものです。担当を分けてあるので、社員みたいに呼んでます」 |
| **「それって結局AIツールでしょ？」** | 「はい、実体はAIです。人格があるわけじゃないです。ただ**うちの仕事のやり方を覚えさせてある**ので、他社さんが同じものを買っても同じようには動かないです」 |
| **「どこのツール使ってるんですか？」** | 「特定のツールというより、業務ごとに覚えさせた形なので。**そこは当日お見せしたほうが早いです**」 |
| **「うちにはまだ早い」** | 「うちも3人しかいないので、**早いも遅いもなくて、やらないと回らなかった**んです」 |
| **「12人分の費用は？」** | 「作るのに時間はかかりましたけど、月額でどこかに払ってるわけではないです」※実態と違うなら言わない |
| **「本当に3人でやってるんですか？」** | 「はい。だから逆に、1人辞めたら終わりなんですよ。**それが一番の理由です**」 |
| **「うちにも作れますか？」** | 「作れます。ただ、どの仕事を渡すかで難易度が全然違うので。**そこを一緒に選ぶのが当日やりたいことです**」 ← **理想的な質問。アポに直結** |

## NG集

| ✕ 言わない | なぜ |
|---|---|
| **「AI社員を導入しませんか」** | 商品の輪郭が曖昧なまま話が進む。**電話では売らない** |
| **12体を全部説明する** | 説明が長いほど「AIで効率化」の棚に戻る。**3体で止める** |
| **確認できていない4体について語る** | **嘘になる。**知らないものは言わない → [04](04_AI社員カタログ.md) |
| **AI社員に人格があるかのように言い張る** | 聞かれたら**正直に「実体はAIです」と言う** |
| **「応募者への返信をAIで」** | ATSの標準機能。「うちもうやってます」で信用ごと失う |
| **「マニュアルをAIで作ります」** | Teachme Biz 等と被る。**「判断」と言い切る** |
| **「助成金で実質10万円です」** | 期待値を先に上げすぎ。8/3改正で審査が厳しくなった今は特に危険 |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「営業ではありません」 | **嘘。**受付にも決裁者にも嘘をつかない |

## 断られたときの処理

| 断り文句 | 返し | その後 |
|---|---|---|
| **怪しい / 何の話か分からない** | 「失礼しました。名古屋のヒダネという研修の会社です」 | **社名と業種だけ残して引く。**ルートBのリスク |
| **属人化はしてない** | 「それはすごいですね。どうやられてるんですか」 | 素直に聞いて引く |
| **ツール入れてるから大丈夫** | **「どちらのツールですか？」** | **必ず聞く。**被っていれば潔く引く。記録に残す |
| **AIはうちには早い** | 「うちも3人しかいないので、やらないと回らなかったんです」 | 1回だけ返して、押さない |
| **資料を送って** | 「メールアドレスをお願いできますか」 | **送る。リード化。**断りではない |
| **金額は？** | 「どの仕事を渡すかで変わるので、見てからでないと出せないんです」 | **電話で金額を言わない** |
| **興味ない** | 「承知しました。ありがとうございました」 | 即引く。6か月空ける |

**2回断られたら引く。**

## 記録項目

| 列名 | 内容 |
|---|---|
| **受付ルート（A / B）** | **v4で追加。**突破率を比較するため |
| 受付突破の可否 | ○ / ✕ |
| 出した3体目 | どの体を出したか |
| **「え？」が出たか** | STEP 2 で好奇心が立ったか（○/✕） |
| **笑いが出たか** | STEP 3 の失注分析担当で（○/✕） |
| 止まると困る業務 | 相手が言った業務名 |
| 導入済みツール | 「ツール入れてる」と言われたときに聞いた名前 |
| 従業員数 | 助成金判定用 |
| 断り分類・次回接触時期 | 再架電の管理 |

> **「え？が出たか」「笑いが出たか」を必ず記録する。**
> この2つが取れているのにアポにならないなら、問題はSTEP 6（アポの切り方）にある。
> 取れていないなら、問題はSTEP 2〜3（フックと具体例）にある。**切り分けができる。**
