# 02. トークスクリプト（v3）

> **v2からの変更**
> 主軸を「応募者への自動返信」から「**引き継ぎ・教育**」に変更。
> 理由：応募者の自動返信も面接の日程調整も、**ATSの標準機能**（無料ATSにも搭載）。
> 「うちもうやってます」と言われた瞬間に信用ごと失う球だった。
>
> **受付突破の「求人ルート」は維持。** ここは有効に機能する設計なので変えない。

**全体で3分以内。**

```
STEP 0  仕込み（架電前）    5分
STEP 1  受付突破           25秒   ← 求人の件（v2から変更なし）
STEP 2  ブリッジ           25秒   ← 求人 → 教育 へ話を渡す
STEP 3  インパクト         30秒   ← 「え？」を取る
STEP 4  一点確認           60秒   ← 見えていないコストを可視化する
STEP 5  アポ打診           30秒
STEP 6  確定と仕込み       40秒
```

---

## STEP 0 ｜仕込み（架電前・1社5分）

```
1.「会社名 + 求人」で検索。Indeed / 求人ボックス / 自社採用ページを見る
2. 出している職種をメモする（例：「製造スタッフ」）
3. 下の4パターンのどれに当たるかを判定する
4. 架電メモに書く：職種名 / パターン / 使う球
```

### 判定の4パターン

| パターン | 求人に書いてあること | 読み取れること | 使う球 |
|---|---|---|---|
| **A** | **未経験可** | 教える人が必要になる | **球2（聞ける相手）** |
| **B** | **経験者優遇 / 経験者必須** | **教える余裕がない** | **球1（引き継ぎ）** |
| **C** | **同じ職種を3か月以上掲載** | 採れていない or 採ってもすぐ辞める | 球1 or 球2（確認して分岐） |
| **D** | 「研修制度あり」と書いてある | 教育に投資している。話が早い | 球2 |

> **Cが最強のシグナル。** 3か月以上出し続けている＝社長が一番イライラしているところ。
> しかも原因が「採れない」か「辞める」のどちらかで、**後者なら教育の話に直結する**。

## STEP 1 ｜受付突破（25秒）

**v2から変更なし。** ここは機能する設計なので触らない。

```
お世話になります。名古屋のヒダネと申します。

御社の求人の件でお電話しました。
Indeedに出されている「製造スタッフ」の募集を拝見しまして、
1つだけお伺いしたいことがあります。

社長さん、いらっしゃいますでしょうか。
```

| 要素 | 効き方 |
|---|---|
| 「求人の件」 | **人事案件は受付の権限外。**判断できないので上げるしかない |
| 「Indeedの**「製造スタッフ」**の」 | **固有名詞。**実際に見てきた証拠 |
| 「1つだけ」 | 短いと分かる |

> **v2からの微修正：**「お伝えしたいことがあります」→「**お伺いしたいことがあります**」に変更。
> 今回の本題は指摘ではなく質問から入るため。嘘をつかないための調整。

### 「どういったご用件でしょうか？」と粘られたら

```
採用された方の受け入れ体制のことでして。
未経験の方も可、と書かれていたので、
その後どうされているのか伺いたくてお電話しました。
```

### 受付の反応別

| 反応 | 返し |
|---|---|
| 「担当の者に代わります」 | 採用担当・現場責任者ならそれでいい。話す内容は同じ |
| 「資料を送ってください」 | 「御社の求人を見ての話なので、1分だけお電話でお伺いできませんか」 |
| 「お断りしてます」 | 「失礼しました」→ **即引く。6か月空ける** |
| 「社長は不在です」 | **「何時ごろお戻りでしょうか」→ 再架電** |

## STEP 2 ｜ブリッジ（25秒）— 求人から教育へ話を渡す

**ここがv3で新設したステップ。** 受付突破の弾（求人）と本題（教育）を繋ぐ。

### パターンA（未経験可）の場合

```
突然すみません、名古屋のヒダネの◯◯と申します。

御社のIndeedの求人、拝見しました。
未経験の方も可、と書かれてますよね。

未経験の方が入られたあと、教えるのって
どなたがやられてるんですか？
```
> 「現場の先輩ですね」

```
その先輩の方、教えてる間は自分の仕事止まりますよね。

そこ、求人票には出てこないんですけど、
実は一番コストが掛かってるところで。
```

### パターンB（経験者優遇/必須）の場合

```
御社のIndeedの求人、拝見しました。
経験者の方に絞られてますよね。

これって、教える余裕がないから、という感じですか？
```
> 「まあ、そうですね…」

```
そうですよね。未経験を採れたら選択肢は広がるんですけど、
教える人が取られるので、そこがネックになりますよね。
```

### パターンC（3か月以上掲載）の場合

```
御社のIndeedの求人、拝見しました。
◯◯の募集、けっこう長く出されてますよね。

これって、応募が来てないんですか？
それとも、入っても続かない感じですか？
```

> **この質問は強い。** どちらに転んでも話が進む。
> 「応募が来ない」→ 原稿の話（第2の入口）
> 「続かない」→ **教育の話。ど真ん中**

### 共通の効かせ方

- **こちらから指摘しない。質問する。**（社長のプライドを傷つけない）
- 相手に「そうなんですよ」と言わせてから、次へ
- **まだ商品の話をしない**

## STEP 3 ｜インパクト（30秒）

```
（一拍おく）

うち、社員3人しかいない会社なんですけど、
引き継ぎってものがないんです。

人が辞めても、次の人がその日から同じことできるので。

その人の判断の仕方だけ、AIに移してあるんですよ。
```

### 構造

| ブロック | 役割 |
|---|---|
| （一拍おく） | 前のステップの共感から、話題を切り替える間 |
| 「社員3人しかいない」 | 相手より小さい。警戒が下がる |
| **「引き継ぎってものがないんです」** | **不可能に聞こえる事実。**全社長が引き継ぎで苦しんでいる |
| 「次の人がその日から同じことできる」 | **矛盾。**ここで「え？」が出る |
| 「判断の仕方だけ、AIに移してある」 | 種明かし。**AIは最後** |

### なぜ「判断」なのか

マニュアル作成ツールは既にある（Teachme Biz、tebiki 等）。**手順は残せる。**
でも**判断は手順書に書けない**。ここが空いている。

```
書ける   ： この機械はこのボタンを押す
書けない ： この客からこの条件で来たら、受けない
書けない ： この症状が出たら、たぶん◯◯が原因
書けない ： この見積は、いつもより1割乗せる
```

**「手順書だと書けないんですよ、そこは」** の一言を必ず入れる。
既存ツールとの違いを、相手が聞く前に自分から示す。

### 「え、どうやって？」と聞かれたら（＝勝ち）

```
本人に作業してもらいながら、横で理由だけ聞いていくんです。
「なんで今それを選んだんですか？」って。

それをAIに覚えさせると、
次の人が同じ場面で「どうすればいい？」と聞いたときに、
その人と同じ答えが返ってくるようになります。
```

**まだ売らない。**

### 未経験可（パターンA）の場合は、球2に差し替えてもいい

```
あと、うちの新人、先輩に質問しないんですよ。

AIに聞くので。

24時間聞けますし、同じことを100回聞いても
嫌な顔されないので。
```

> **「同じことを100回聞いても嫌な顔されない」が効く。**
> 新人が聞けなくなる理由は「分からないこと」ではなく「**聞きづらいこと**」。
> これは社長が忘れている感覚。

## STEP 4 ｜一点確認（60秒）— 見えていないコストを可視化する

**目的：社長が計算したことのない数字を、社長自身に計算させること。**

### 球2（教育）で進める場合

```
新しい方が入って、一人でできるようになるまで
どのくらいかかります？
```
> 「3か月くらいかな」

```
その間、教えてる先輩の方は、
自分の仕事どのくらい削られてます？
```
> 「半分は取られてるかも」

```
なるほど。
じゃあ1人採ると、実質もう1人分の手が3か月消える計算ですね。
```

### この最後の一言が本体

> **「1人採ると、もう1人分の手が3か月消える」**

社長は**採用コスト**（中小企業で30万円台前半）は知っている。
でも**教育中に消えるベテランの工数**は計算していない。
しかも**新人が3か月で辞めたら、その投資は全部消える。**

### 球1（引き継ぎ）で進める場合

```
今、この人が辞めたら止まるな、って業務ありますか？
```
> 「◯◯さんの担当してるところですね」

```
その方、何年目です？
```
> 「20年くらい」

```
その方に引き継ぎ書を書いてもらったとして、
判断のところまで書けそうですか？
```
> 「…難しいでしょうね」

**最後の質問が効く。** 社長は「引き継ぎ書を書かせればいい」と思っている。
**判断は書けない**ことを、聞かれて初めて自覚する。

### 相手が数字を答えられない場合

| 状況 | 返し |
|---|---|
| 「現場のことは分からない」 | 「じゃあ当日、現場の方も入っていただけますか」→ **むしろ好都合** |
| 「新人は入ってない」 | 「では、ベテランの方が辞められたときの話になりますね」→ 球1に切り替え |
| 「属人化はしてない」 | 「それはすごいですね。どうやられてるんですか」→ **素直に聞く。学ぶ姿勢で引く** |

## STEP 5 ｜アポ打診（30秒）

```
30分だけいただいて、2つやります。

1つは、御社の業務を1つ選んでいただいて、
その場でAIに覚えさせるところをお見せします。
どんな感じか、見ていただければ。

もう1つは、今の教育に何時間かかってるかを
御社の数字で出します。

それだけ持ち帰っていただければ、それで結構です。
売り込みはしません。

来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？
```

### 「その場でAIに覚えさせる」が効く理由

**「AIでできるの!?」を言葉ではなく体験で示す。**
相手は「AIで効率化」を100回聞いている。でも**自社の業務がAIに移るところを見た人はほぼいない。**

| 要素 | 役割 |
|---|---|
| 「御社の業務を1つ選んでいただいて」 | **相手のもの。**サンプルではない |
| 「その場でAIに覚えさせる」 | 実演。持ち帰り資料ではない |
| 「2つやります」 | 30分の使い道が見える |
| 「売り込みはしません」 | 実際にしないので嘘にならない |

> **「売り込みはしない」は必ず守る。** 実演で提案を始めた瞬間、この設計は壊れる。
> 業務が本当にAIに移るのを見れば、**相手から「これ、うちの他の業務でもできますか？」と聞いてくる。**
> そこで初めて研修の話になる。順番を守る。

## STEP 6 ｜確定と仕込み（40秒）

### ① 事前準備を1つだけ頼む

```
当日までに、AIに覚えさせる業務を1つ決めておいていただけますか。
「これが止まると困る」というものが一番いいです。
```

**準備を頼むとドタキャン率が下がる。ただし1つだけ。**

### ② 参加者を確認する

```
当日は社長お一人ですか？
その業務を実際にやられてる方に入っていただけると、その場で移せます。
```

→ その担当者が入ると、**8/3改正で必要な「職務の特定」がその場で完了する**。

### ③ 従業員数をさらっと聞く

```
ちなみに御社、今何名くらいでやられてるんですか？
```

助成金の判定に必須。**ただし助成金の話は電話では一切しない。**

### ④ 形式と連絡先

```
オンラインと訪問、どちらがよろしいですか。
（オンラインなら）URLをお送りしたいので、メールアドレスをお願いします。
```

### 切る前の最終確認

```
□ 日時
□ 参加者（社長のみ / 業務担当者も）
□ 対象業務（AIに移すネタ）
□ 従業員数
□ 教育期間・工数（聞けていれば）
□ 形式（オンライン / 訪問）
□ メールアドレス
□ 準備：AIに覚えさせる業務を1つ決めておく
```

**当日中に確認メールを送る。**

## 断られたときの処理

| 断り文句 | 返し | その後 |
|---|---|---|
| **属人化はしてない** | 「それはすごいですね。どうやられてるんですか」 | **素直に聞いて引く。**学ぶ姿勢が印象に残る |
| **マニュアルは作ってある** | 「判断のところまで書けてますか？」 | 書けていれば引く。詰まったら本題に戻れる |
| **今は募集してない** | 「失礼しました。人の出入りが落ち着かれてるんですね」 | 球1（引き継ぎ）に切り替えて1球だけ試す |
| **AIはうちには早い** | 「そう仰る会社さんが多いです。いつ頃だと話しやすいですか」 | 次の接触時期だけ取る |
| **ツール入れてるから大丈夫** | **「どちらのツールですか？」** | **必ず聞く。**被っていれば潔く引く。記録に残す |
| **資料を送って** | 「メールアドレスをお願いできますか」 | **送る。リード化。**断りではない |
| **金額は？** | 「業務によって変わるので、見てからでないと出せないんです」 | **電話で金額を言わない** |
| **興味ない** | 「承知しました。ありがとうございました」 | 即引く。6か月空ける |

> **「どちらのツールですか？」は必ず聞く。**
> 競合情報になるうえ、**次回の架電設計に直接効く**（v2の失敗は、これを知らなかったせい）。

### 引き際

**2回断られたら引く。** 3回目を押すと会社の名前が傷つく。

## NG集（電話で絶対に言わないこと）

| ✕ 言わない | なぜ |
|---|---|
| **「AIで業務を自動化しませんか」** | 説明になり驚きが消える。**事実→矛盾→種明かし**の順を守る |
| **「応募者への返信をAIで」** | **ATSの標準機能。**「うちもうやってます」で信用ごと失う |
| **「面接の日程調整をAIで」** | 同上。ATSにカレンダー連携が標準搭載されている |
| **「マニュアルをAIで作ります」** | Teachme Biz 等と被る。**「判断」と言い切る** |
| **「助成金で実質10万円です」** | 期待値を先に上げすぎ。8/3改正で審査が厳しくなった今は特に危険 |
| **「研修のご案内です」** | 研修営業は即切られる |
| **「属人化してますよね」** | 決めつけ。社長のプライドを傷つける。**質問の形にする** |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「営業ではありません」 | **嘘。**受付にも決裁者にも嘘をつかない |

## 記録項目

| 列名 | 内容 |
|---|---|
| 出している求人 | 職種名（架電前に記入） |
| 判定パターン | A（未経験可）/ B（経験者）/ C（3か月以上）/ D（研修あり） |
| 使った球 | 球1（引き継ぎ）/ 球2（聞ける相手）/ その他 |
| **一人前までの期間** | 相手が言った数字（例：3か月） |
| **教育中に削られる工数** | 相手が言った割合（例：半分） |
| **止まると困る業務** | 相手が言った業務名 |
| **導入済みツール** | 「ツール入れてる」と言われたときに聞いた名前 |
| 従業員数 | 助成金判定用 |
| 断り分類・次回接触時期 | 再架電の管理 |

> **「導入済みツール」の列を必ず埋める。**
> これが溜まると、**次にどの球が死んでいるかが分かる**。v2の失敗を繰り返さないための仕組み。

## ⚠️ この台本を使う前提条件

```
「引き継ぎってものがないんです。判断の仕方だけ、AIに移してあるので。」
```

**ヒダネが実際にやっていて初めて使える。**

商談で「見せてください」と言われる。そのとき出せないものは、電話で言ってはいけない。
ヒダネの最大の強みは「**自分たちが実際に使っているものを売る**」ことそのもの。

### まだやっていない場合の手順

```
1. ヒダネの業務を1つ選び、判断基準ごとAIに移す
   （例：商談前リサーチの進め方、提案書の作り方の判断）
2. 実際に「別の人がその日からできる」状態を作る
3. その事例を持ってから架電を始める
```

**運用実績のない台本は使わない。** 設計上の前提であって、努力目標ではない。
