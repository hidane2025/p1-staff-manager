# 02. トークスクリプト

**全体で3分以内。** 長い電話は取れない。

```
STEP 1  受付突破        20秒
STEP 2  AI社員フック    30秒   ← ここが勝負
STEP 3  一点確認        60秒   ← 相手に数字を言わせる
STEP 4  アポ打診        30秒
STEP 5  確定と仕込み    40秒
```

---

## STEP 1 ｜受付突破（20秒）

```
お世話になります。名古屋のヒダネと申します。
社長の◯◯様、いらっしゃいますでしょうか。
```

**ポイント：**
- **社名を先に名乗る。**「名古屋の」を付ける（地元＝警戒が下がる）
- 代表者名を事前に調べておいて**名指しする**。「社長様」より通る
- 声のトーンは低め・ゆっくり。早口は営業だとバレる

### 「ご用件は？」と聞かれたら

```
AIで業務時間を減らす取り組みをしている会社でして、
御社の見積作成について少しお伺いしたくお電話しました。
3分だけお時間いただけますか。
```

- **嘘をつかない。**「営業ではありません」とは言わない（ヒダネのトーンルール）
- 「見積作成について」＝ 具体的な業務名を出すと、受付が判断できず通しやすい
- 「3分」と時間を切る

### 受付が固い場合

| 受付の反応 | 返し |
|---|---|
| 「担当の者から折り返します」 | 「承知しました。◯◯（自分の名前）と申します。見積作成の時間短縮の件、とお伝えいただけますか」 |
| 「そういうお電話はお断りしてます」 | 「失礼しました。ありがとうございます」→ **即引く。記録して6か月空ける** |
| 「社長は不在です」 | **「何時ごろお戻りでしょうか」→ 再架電。ここが一番数が取れる** |

> **「戻り時間を聞く」が最重要。** 不在は失敗ではなく、次のアポイントメント。必ず時間を聞いて記録する。

---

## STEP 2 ｜AI社員フック（30秒）

決裁者が出たら、最初の15秒で決まる。

```
突然すみません、名古屋のヒダネの◯◯と申します。

うち、社員3人しかいない会社なんですけど、
AIを12体、社員みたいに使って回してまして。

それで、同じことを製造業さんでやると
どのくらい時間が減るのか、試算して回ってるんです。
```

### なぜこの言い方なのか（1行ずつ）

| セリフ | 効いている理由 |
|---|---|
| 「社員3人しかいない会社」 | **相手より小さいことを先に言う**。売り込まれる警戒が下がる |
| 「AIを12体、社員みたいに」 | 数字の意外性。「え？」が出る。**質問を誘発する** |
| 「試算して回ってるんです」 | 提案ではなく**調査の体**。断る対象がない |
| 「製造業さんで」 | 相手の業種を名指し。**自分ごと化**する |

### この時点で「売り込み」を一切していないことを確認する

言っているのは **自社の事実** と **やっている活動** だけ。
商品名も価格も助成金も出していない。だから相手は断る理由を持てない。

**これが「AI社員は証拠であって商品ではない」という設計の実装。**

### 相手が「どういうこと？」と聞いてきたら（＝勝ち）

```
見積書とか報告書とか、うちだと社員がやってた作業を
AIに型を覚えさせて、ほぼ全部そっちに回してるんです。

なので3人でも回るんですけど、
これ製造業さんだと効き方が違うので、実際どうなのか調べてまして。
```

**ここでも商品を出さない。** 次のステップに進む。

---

## STEP 3 ｜一点確認（60秒）— ここが本当の勝負

**目的：相手の口から数字を出させること。**

```
御社だと、見積書って月に何件くらい出されてますか？
```
> 「30件くらいかな」

```
1件あたり、どのくらい時間かかります？
```
> 「30分くらいかな」

```
なるほど、月15時間くらいですね。
```

### なぜ相手に計算させるのか

自分が出した数字は疑われる。**相手が自分で言った数字は疑えない。**
「月15時間」という数字が相手の頭に残った状態で次に進む。

### そして試算を提案する

```
うちの試算だと、そういう作業が1/5くらいになるケースが多いんですけど、
これ会社によって全然違うので、一般論だと意味がなくて。

御社の見積を1件、実物で試算すると何分になるか、出せます。
```

**「会社によって全然違う」「一般論だと意味がない」がポイント。**
誇張していないことを自分から示している。ヒダネのトーンルールに沿う。

### 相手が数字を答えられない場合

```
（社長が現場を把握していない）
→ 「担当されてる方だと分かりますかね？」
   → 同席してもらう理由ができる。むしろ好都合

（業務自体がない）
→ 別の業務を探る：「では、社内で一番時間食ってる作業って何ですか？」
   → 出てこなければ引く。無理に作らない
```

---

## STEP 4 ｜アポ打診（30秒）

```
30分だけいただいて、御社の見積を1件、実際に使って試算します。

その場で数字が出るので、それだけ持ち帰っていただければ。
売り込みはしないので、合わなければそれで終わりで大丈夫です。

来週だと、火曜の午後か木曜の午前、
どちらが動きやすいですか？
```

### 4つの装置

| 要素 | 役割 |
|---|---|
| 「30分だけ」 | 時間を明示。長引かないと分かる |
| 「その場で数字が出る」 | **成果物の約束**。手ぶらで帰らせない |
| 「**売り込みはしない**」 | 実際にしないので嘘にならない。ヒダネの誠実さがそのまま武器になる |
| 「火曜の午後か木曜の午前」 | 二者択一。ただし押し付けない範囲で |

> **「売り込みはしない」は必ず守る。** 試算アポで提案を始めた瞬間、この設計は壊れる。
> 提案は次のアポでやる。試算の結果が良ければ、相手から「で、どうすれば？」と聞いてくる。

---

## STEP 5 ｜確定と仕込み（40秒）

アポが取れてから切るまでにやることが4つ。**ここを雑にするとドタキャンされる。**

### ① 事前準備を1つだけ頼む

```
当日、実際の見積を1件だけご用意いただけますか。
それがあると試算が具体的になるので。
```

**準備を頼むとドタキャン率が下がる。** 相手に「約束したこと」ができるため。
ただし**1つだけ**。多いと負担になって逆効果。

### ② 参加者を確認する

```
当日は社長お一人ですか？
実際に見積を作られてる方も入っていただけると、数字が正確に出ます。
```

→ 現場の人が入ると、**8/3改正で必要な「職務の特定」がその場で終わる**。

### ③ 従業員数をさらっと聞く

```
ちなみに御社、今何名くらいでやられてるんですか？
```

**助成金の判定に必須。** ただし助成金の話は電話では一切しない。
数字だけ持ち帰って、社内で判定する。

### ④ 形式と連絡先

```
オンラインと訪問、どちらがよろしいですか。
（オンラインなら）URLをお送りしたいので、メールアドレスをお願いします。
```

### 切る前の最終確認

```
□ 日時
□ 参加者（社長のみ / 現場も）
□ 対象業務（試算のネタ）
□ 従業員数
□ 形式（オンライン / 訪問）
□ メールアドレス
□ 準備してもらうもの（実物1件）
```

**当日中に確認メールを送る。** これでドタキャンがさらに減る。

## 断られたときの処理

**断りは失敗ではなく、情報。** 分類して記録する。

| 断り文句 | 返し | その後 |
|---|---|---|
| **「間に合ってます」** | 「差し支えなければ、どちらとお付き合いされてますか」<br>→ 答えたら「ありがとうございます」で引く | 競合情報として記録。6か月後に再架電 |
| **「AIはうちにはまだ早い」** | 「そう仰る会社さんが多いです。<br>もし興味が出たら、いつ頃だと話しやすいですか」 | **次の接触時期だけ取る**。押さない |
| **「資料を送って」** | 「承知しました。メールアドレスをお願いできますか」 | **送る。リード化する**。断りではない |
| **「忙しい」** | 「失礼しました。何時ごろだとお手すきですか」 | 再架電の時間を取る |
| **「興味ない」** | 「承知しました。ありがとうございました」 | **即引く**。記録して6か月空ける |
| **「金額は？」** | 「業務によって変わるので、試算してからでないと出せないんです」 | **電話で金額を言わない**。これが試算アポの入口になる |

### 引き際のルール

> **2回断られたら引く。** 3回目を押すと、会社の名前が傷つく。
> ヒダネは名古屋のローカルで信用を積む会社。1件の無理押しが、あとで効いてくる。

## NG集（電話で絶対に言わないこと）

| ✕ 言わない | なぜ |
|---|---|
| **「助成金で実質10万円です」** | 期待値を先に上げすぎる。**8/3改正で審査が厳しくなった今は特に危険**。判定前に金額を言うと後で覆せない |
| **「AI社員を導入しませんか」** | 商品の輪郭が曖昧なまま話が進む。フックは自己紹介に留める |
| **「研修のご案内です」** | 研修営業は即切られる。売るのは次の30分だけ |
| 「今だけ」「お得」「特別」「絶対」「必ず」 | ヒダネのトーンルール違反 |
| 「今年度で助成金が終わるので急いだほうが」 | 事実だが、**急かす道具に使わない**。聞かれたら答える |
| 「御社は遅れています」 | 課題は仮説として出す。断定しない |
| 「営業ではありません」 | **嘘。** 受付にも決裁者にも嘘をつかない |

## 記録項目（架電管理列に追加する）

`hidane-teleapo-list` が出力する架電管理列に、本設計用の項目を足す。

| 列名 | 内容 |
|---|---|
| 狙う職務 | 架電前に決めておく（例：営業事務） |
| 定型業務 | 架電前に決めておく（例：見積書作成） |
| **相手が言った件数** | 「月30件」← 相手の口から出た数字 |
| **相手が言った所要時間** | 「1件30分」 |
| 従業員数 | 助成金判定用 |
| 断り分類 | 間に合ってる／早い／資料希望／忙しい／興味なし |
| 競合名 | 「間に合ってる」と言われたときに聞けた先 |
| 次回接触時期 | 再架電の日付 |

**「相手が言った数字」を残すのが肝。** 次に電話するとき、
「前回、見積が月30件で1件30分と伺いましたが」から入れる。これは強い。
