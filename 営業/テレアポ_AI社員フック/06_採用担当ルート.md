# 06. 採用担当ルート（旧版・経緯）── 社長への「経由地」として設計する

作成日：2026-08-17 ／ 改訂：2026-08-17（位置づけとアポを訂正）

> 🚨 **この章はもう使わない。担当ルートの最新は [09章（担当秘書ルート）](09_担当秘書ルート.md)。**
>
> 本章の設計は主語が「会社」だった（「社長に出す報告資料を作ります」）。
> **担当にとって得が間接的で、自分に何が起きるか分からないので刺さらない。**
> → 09章で主語を相手に変えた（「**◯◯さんに、秘書を1体つけます**」）。
>
> 本章に残る有効な部分：**代理店が原稿を書いているという前提**（→ 09章の切り返しに継承）、
> **担当を敵にしないためのNG集**、**担当は決裁者ではなく推進者という位置づけ**。
> **台詞はどの章のものも使わないこと。**

## 0. 前提の訂正 ── 採用担当ルートは「アポがゴール」ではない

### 結論から

> **受注を取るなら、相手は社長。**
> **採用担当は決裁者ではなく、社長への"経由地"であり"推進者"。**

ヒダネの商材はすべて経営マター（研修導入・助成金・業務内製化）で、
**40万円/人の決裁は採用担当にはできない。**

だから採用担当ルートのゴールは受注ではない。

```
採用担当とのアポ → 受注                    ← ✕ 成立しない
採用担当とのアポ → 味方にする → 社長に会う  ← ◎ これが正しい
```

### 初版の設計の誤り（2点）

**誤り①：アポの中身が、07章の発見と矛盾していた**

初版のアポは「**求人の原稿を1本、その場でAIに書かせてみませんか**」だったが、
[07章](07_商材の再設計.md)で判明したとおり、**求人原稿のAI生成は媒体側が既に搭載している**
（ビズリーチAI「求人自動作成機能」2025年4月／「スカウトメッセージAIカスタマイズ機能」2025年10月）。

**媒体次第では「うちのビズリーチがやってます」で終わる。** v2のATSと同じ轍。

**誤り②：無料オファーが、社長への橋になっていなかった**

原稿を1本作っても、**担当がそれを社長に持っていく理由がない。**
経由地として設計するなら、**無料オファー自体が社長への手土産**でなければならない。

### 訂正後のアポ

> **「社長さんに出す報告資料を1本、無料で作らせてもらえませんか」**

| | 初版（求人原稿） | 訂正後（報告資料） |
|---|---|---|
| 既存ツール | **媒体AIが搭載済み** | **なし。媒体をまたぐのでツールでは不可能** |
| ヒダネの実績 | 媒体次第 | **効果分析は実績あり** |
| 撮影工数 | なし | なし |
| **社長への橋** | **ならない** | **なる ── 担当が社長に見せる前提の成果物** |

```
採用担当に「社長への報告資料を無料で作ります」
        ↓
担当がそれを社長に見せる（自分の手柄として）
        ↓
社長「これ誰が作ったの？」
        ↓
社長との商談が生まれる
```

**無料オファーが、そのまま社長への導線になる。** これが初版に欠けていたピース。

**誤り③（2026-08-17 追記）：共感の入口が、事実として外れていた**

初版〜第2版の入口は「**求人の原稿って、どなたが書かれてるんですか？**」だったが、
**求人原稿は採用担当ではなく求人広告代理店が書いている。**

「原稿に時間を取られてますよね」は共感どころか**「この人は現場を知らない」**になる。
→ 入口を「**代理店さん通されてますか？**」＝ **当たる確認**に差し替えた（→ [10章](#10-通し台本そのまま読む版a4カードと同一)）。

**そして代理店の存在は障害ではなく追い風。** 代理店は自社取扱媒体の分しかレポートを出さず、
媒体を売る側なので「やめましょう」と言えない。**掲載費（代理店側）と面接・入社・定着（社内側）を
突き合わせた人がどこにもいない。** そこだけを商品にする。

## 1. なぜ別台本が必要なのか

**社長向けトークを採用担当にそのまま投げると、敵になる。**

| 社長にとって | 採用担当にとって |
|---|---|
| 「採用しなくてよくなる」＝ **コストが減る朗報** | **自分の仕事がなくなる宣告** |
| 「人は採用する時代から作る時代へ」＝ 経営の話 | **職業そのものの否定** |
| 「増員の判断をしなくて済む」＝ 意思決定が楽 | **予算と権限が減る** |

そして中小企業では、**採用担当がゲートキーパーになる**。
社長が「採用のことは◯◯に聞いて」と振るケースが多く、**ここで敵を作ると社長に永久に届かない。**

> ⚠️ **タグライン「人は、採用する時代から、作る時代へ」は社長専用。採用担当には絶対に使わない。**

## 2. 採用担当の実像（20〜100名の会社）

### 誰なのか

- **専任はほぼいない。** 総務・人事・労務の兼任、または管理部長
- 実態は「**採用業務を押し付けられている人**」
- 社長の右腕であることが多い ＝ **社長への影響力がある**

### 何に苦しんでいるか

| 表向きの課題 | 本当の痛み |
|---|---|
| 応募が来ない | **社長に詰められる** |
| 媒体費が高い | 経費で詰められる |
| 採ってもすぐ辞める | また詰められる |
| — | **原稿作成・面接調整・報告資料で本業（総務・労務）が回らない** |
| — | **評価が「採れたか」だけで測られる** |

### 決定的な洞察

> **採用担当は「採用したい」わけではない。「採用のノルマから解放されたい」。**

矛盾しているようで、していない。
**解放されたいのは"ノルマ"であって、"仕事"ではない。**
だから「採用しなくていいですよ」と言うと仕事を奪われると感じ、
「**作業を減らします**」と言うと味方になる。

## 3. 訴求の作り替え

| ✕ 社長向け（担当にはNG） | ◎ 採用担当向け |
|---|---|
| 採用しなくてよくなります | **◯◯さんの手が空きます** |
| 人を増やさずに済みます | **作業のほうを減らす話です** |
| 採用コストが下がります | **採れなかった時の第2案を持てます** |
| 人は採用する時代から作る時代へ | **採用の"作業"を、AIに** |
| 御社の社員を1人作らせてください | **◯◯さんの作業を1つ、移させてください** |

### 3つの価値（この順で出す）

**① 作業が減る（一番わかりやすい）**
求人原稿の作成、面接記録のまとめ、社長への報告資料、媒体別の効果分析。
**ATSがカバーしていないのは「書く」「まとめる」「分析する」の部分。**

**② 社長に詰められた時の第2案を持てる（一番刺さる）**

```
今：  社長「まだ採れないの？」→ 担当「応募が来なくて…」→ 詰められる
     言えることが「媒体費を増やしてください」しかない

後：  社長「まだ採れないの？」→ 担当「採れないので、この業務はAIに寄せる設計にしました」
     → 評価が変わる
```

**③ 手柄になる**
「これ、◯◯さんから社長に持っていってもらう形にできませんか。うちから直接言うより、そのほうがいいと思うので」
→ **手柄を譲る。** これが最後の一押しになる。

## 4. トークスクリプト（旧版・使わない）

> 🚨 **この章は破棄した。** 入口の「求人の原稿って、どなたが書かれてるんですか？」が
> **事実として外れる**（原稿は求人広告代理店が書く）。
> **使うのは [10章の通し台本](#10-通し台本そのまま読む版a4カードと同一)。** 以下は経緯の記録。

**全体で3分。** 社長向けより柔らかく、共感の比率を上げる。

### STEP 1 ｜受付突破

```
お世話になります、名古屋のヒダネと申します。
御社の求人の件でお電話しました。
採用のご担当の方、いらっしゃいますでしょうか。
```

**社長より簡単に通る。** 「求人の件」＝ 採用担当に繋ぐのが受付の仕事。

---

### STEP 2 ｜共感から入る（社長向けと最も違う部分）

```
Q1 採用のご担当の方でいらっしゃいますか？
```
> 「はい」

```
突然すみません、名古屋のヒダネの◯◯と申します。

Q2 3分だけ、よろしいですか？
```

```
Q3 あの、求人の原稿って、どなたが書かれてるんですか？
```
> 「私ですね」

```
Q4 …あれ、けっこう時間取られませんか？
```
> 「取られますね（笑）」

**★ここが分岐点。** 採用担当は「応募が来ない」ことより、
**日常的に「時間を取られること」に苦しんでいる。**
そこに共感されると、一気に味方だと認識される。

```
そうですよね。しかも書いても応募来ないと、
社長さんにも言われるじゃないですか。
```
> 「…そうなんですよ」　← **ここまで来たら、ほぼ話を聞いてもらえる**

---

### STEP 3 ｜自己紹介（社長向けと同じだが、着地が違う）

```
うち、AI社員を作ってる会社でして。
社員3人しかいないんですけど、AI社員が12人いまして。

求人の原稿も、面接の記録まとめも、
社長への報告資料も、全部AIにやらせてます。

うち、採用担当がいないので。
```

**「採用担当がいないので」は自社の状況説明であって、相手の否定ではない。**

---

### STEP 4 ｜⚠️ 最重要 ── 明示的に「仕事はなくならない」と言う

**相手が聞く前に、こちらから言う。**

```
あ、先に言っておくと、
◯◯さんの仕事を減らす話であって、なくす話ではないです。

うちがやってるのは、原稿書くとか記録まとめるとか、
そういう作業のほうなので。

誰を採るか決めるのは、絶対に人です。
```

### なぜ先回りするのか

**採用担当は必ず「自分の仕事は？」と考える。**
聞かれてから答えると言い訳に聞こえる。
**聞かれる前に言うと、分かっている人だと思われる。**

---

### STEP 5 ｜社内政治の話をする（ここが本命）

```
Q5 採用って、採れなかった時の説明が一番しんどくないですか？
```
> 「…そうですね」

```
Q6 今って、採れなかった時に言えることって
   「媒体費増やしてください」くらいですか？
```
> 「まあ、そうなりますね」

```
うち、「この業務は採用しない」って決めた時に、
その代わりどうするかをセットで出せるようにしてまして。

◯◯さんが社長に説明する時の材料になると思うんです。
```

**「採れませんでした」ではなく「採れないので、こう寄せます」と言えるようになる。**
→ **採用担当の評価が変わる。** これは金の話より効く。

---

### STEP 6 ｜アポ打診（社長向けとは別物）

**まず媒体を聞く。**

```
Q6.5 どちらの媒体を使われてます？
```
> Indeed／求人ボックス／Airワーク → 原稿の話をしてもよい
> **ビズリーチ／doda → 原稿とスカウトの話はしない**（媒体AIが搭載済み）

**本命のアポ：**

```
Q7 30分だけいただいて、
   社長さんに出す報告資料を1本、無料で作らせてもらえませんか？

御社の媒体別に、何件来て、何人会えて、いくら掛かったか。
そこまで出して、社長さんに渡すだけの形にします。

無料です。売り込みもしません。
```

### なぜこの形なのか

| 社長向け | 採用担当向け |
|---|---|
| 「御社の社員を1人、作らせてください」 | 「**社長さんに出す報告資料を1本、作らせてください**」 |
| → 担当には「自分の代わりが来る」と聞こえる | → **担当が社長に持っていける手土産になる** |

**3つ同時に成立する：**

| | |
|---|---|
| **既存ツールと被らない** | 媒体をまたぐ分析は、どのATSにも媒体AIにもできない |
| **担当の一番やりたくない仕事** | 報告資料の作成は半日かかる |
| **社長への橋になる** | 担当がそれを社長に見せる ＝ **無料オファーが導線そのもの** |

### 予備のアポ（相手が報告資料に反応しない場合）

```
・面接の記録を1人分、評価シートの形にしてみませんか
・採ったあとの受け入れ計画を1つ、組んでみませんか
```

**どちらも撮影不要・営業1人・30分で完結する。**（→ [07章 0-3](07_商材の再設計.md)）

> ⚠️ **求人原稿は「予備の予備」。**媒体を聞いてビズリーチ等が出たら、絶対に出さない。

---

### STEP 7 ｜手柄を譲る（クロージング）

```
Q8 もし良さそうだったら、これ◯◯さんが作った形で
   社長さんに出してもらって大丈夫です。

うちの名前は出さなくていいので。
```

**★初版より踏み込んだ。**「持っていってもらえませんか」ではなく
**「◯◯さんが作った形でいい」「うちの名前は出さなくていい」**と言い切る。

### なぜそこまでするのか

**担当が社内で動く理由を作るため。**
名前を出さない提案をされると、逆に**担当のほうから「いや、ヒダネさんが作ってくれて」と言う。**
人は、手柄を譲られると譲り返す。

そして社長が「これ誰が作ったの？」と聞いた時点で、**商談が生まれる。**

> **採用担当ルートの成功とは、受注ではない。**
> **「社長がヒダネの名前を口にする」ことがゴール。**

## 5. NG集（採用担当向け・社長向けと違う点）

| ✕ 採用担当に言わない | なぜ |

## 7. 社長ルートとの使い分け

```
受付で「社長」を指名     → 社長ルート（v7・採用しなくてよくなる）
受付で「採用担当」を指名 → 採用担当ルート（本書・作業を減らす）

社長に出た → そのまま社長ルート
採用担当に回された → ★即座に採用担当ルートへ切り替える
```

> ⚠️ **「社長さんいますか」→「採用担当が承ります」と回されたときが一番危ない。**
> 社長ルートのまま話すと、担当を敵にする。**回された瞬間に台本を切り替える。**

### 切り替えの合図

```
「あ、採用のご担当の方ですか。
 …求人の原稿って、◯◯さんが書かれてるんですか？」
```

**この一言で採用担当ルートに入れる。** 覚えておく。

## 7-2. 決裁構造 ── 採用担当は「推進者」

```
        決裁者                    推進者                実務担当
        ┌─────┐              ┌─────────┐        ┌─────────┐
        │ 社長 │ ←── 提案 ──  │ 採用担当  │ ←──   │ 現場     │
        └─────┘              └─────────┘        └─────────┘
           ↑                        ↑
      40万円/人の決裁          受講者になる人
      助成金の申請主体          ＝ 8/3改正の「職務」
```

**採用担当は、決裁者ではないが受講者。** つまり：

- 研修を受けるのは採用担当（＝職務が特定される。8/3改正をクリア）
- 決裁するのは社長
- **担当が「これ受けたい」と言うのが、一番強い提案になる**

> **担当を"説得する相手"ではなく"一緒に社長を説得する相手"として扱う。**
> これがBtoB営業の基本だが、初版では明示していなかった。

## 8. どちらを狙うべきか

| | 社長ルート | 採用担当ルート |
|---|---|---|
| 受付突破 | 難しい | **易しい**（「求人の件」で繋がる） |
| 決裁 | **その場で進む** | 社長に上げてもらう必要がある |
| 敵になるリスク | 低い | **扱いを誤ると社内で潰される** |
| 商談までの距離 | 近い | 1ステップ多い |
| **中期的な強さ** | 単発 | **社内に味方ができる** |

**推奨：まず社長を狙い、回されたら採用担当ルートに切り替える。**
採用担当を最初から狙うのは、社長に3回断られた会社の再アタック時。

### ⚠️ 期待値を正しく持つ

| | 社長ルート | 採用担当ルート |
|---|---|---|
| アポの意味 | **商談そのもの** | **社長に会うための1ステップ** |
| 成功の定義 | 受注に向かう | **社長がヒダネの名前を口にする** |
| 所要 | 1回 | **2回**（担当 → 社長） |

**「採用担当とアポが取れた」を成果としてカウントしない。**
カウントするのは「**社長との商談が設定された**」から。

記録項目に **「社長に繋がったか（○/✕）」** を入れて、
採用担当ルートの本当の歩留まりを測ること。

- [ ] 面接記録のまとめ・受け入れ計画をAIで作った実例があるか（**ないなら予備のアポに使わない**）
- [ ] **相手の媒体とATSが何かを先に聞く**（ビズリーチ等なら原稿・スカウトの話をしない）

**「採用担当の仕事を奪わない」は口先ではなく、提案の中身で守ること。**
商談で「じゃあ担当は何をするんですか」と聞かれて答えられなければ、この設計は成立しない。

## 10. 通し台本（そのまま読む版・A4カードと同一）

印刷用は `テレアポ台本カード_採用担当_A4.pdf`（A4縦1枚）。
以下はその文字起こし。**カードとこの節が食い違ったらこちらが正**。

> ⚠️ **2026-08-17 改訂：初版の入口（「求人の原稿は誰が書いてるんですか？」）を破棄した。**
> **求人原稿は採用担当ではなく求人広告代理店が書いている。**
> 「原稿に時間を取られてますよね」は事実として外れるので、共感どころか「この人は分かっていない」になる。
> → 入口を **「代理店さん通されてますか？」** に差し替えた。

### なぜ代理店が入っているほうが良いのか

代理店の存在は障害ではなく**追い風**。

| 事実 | 意味 |
|---|---|
| 代理店に払っている | **媒体費の予算がある会社**。助成金ターゲットとしても良い |
| 原稿は代理店が書く | 原稿工数は担当に無い。**だから原稿の話は刺さらない** |
| 代理店のレポートは**自社取扱媒体の分だけ** | ハローワーク・直接応募・紹介・リファラルは入らない |
| 代理店は媒体を売る側 | **「この媒体はやめましょう」と構造的に言えない** |
| 掲載費は代理店側、面接・入社・定着の数は社内側 | **突き合わせた人がどこにもいない** ← ★ここが穴 |

**ATSがあっても埋まらない。** ATSは応募〜内定の歩留まりを出せるが、**掲載費を持っていない**ので
「1人採るのにいくら掛かったか」は出ない。定着（3か月・半年で残っているか）は労務側にある。

> **費用（代理店の請求書）× 歩留まり（社内）× 定着（労務）の突き合わせ。**
> **代理店にもATSにも媒体AIにもできない。ここだけを商品にする。**

### 1｜受付突破（社長指名より通る）

> お世話になります、名古屋のヒダネと申します。
> 御社の**求人の件**でお電話しました。
> **採用のご担当の方**、いらっしゃいますでしょうか。

「求人の件」＝ 採用担当に繋ぐのが受付の仕事になる。社長指名は"用件を説明させられる"が、これは説明させられない。

### 2｜名乗り・時間の合意（20秒）

- **Q1** 採用のご担当の方でいらっしゃいますか？
- **Q2** 突然すみません、名古屋のヒダネの◯◯と申します。**3分だけ**、よろしいですか？

### 3｜共感から入る（★ここが分岐点・40秒）

- **Q3** 求人って、**代理店さん通されてますか？**
  - ▶「はい、お願いしてます」 ← **当てられると「分かってる人」だと思われる**
- **Q4** じゃあ原稿は代理店さんですね。**◯◯さんは、そのやりとりと社長への報告のほうですか？**
  - ▶「そうですね…」
- **Q5** あの、**代理店さんって「この媒体はやめましょう」って言ってくれます？**
  - ▶「…言わないですね（笑）」 ← **ここで同じ側に立てる。ほぼ聞いてもらえる**

**Q3は"確認"であって"推測"ではない。** ここが初版との決定的な違い。
初版は「原稿書いてますよね？」＝ 外れる推測だった。**当たる確認で入ると、最初の15秒で信用が立つ。**

Q5は誰も悪者にしない。**代理店の人格ではなく構造の話**なので、担当は安心して本音を言える。

### 4｜自己紹介（25秒）

> うち、AI社員を作ってる会社でして。
> 社員3人しかいないんですけど、AI社員が12人いまして。
>
> **面接の記録まとめも、媒体別の集計も、社長への報告資料も、全部AIにやらせてます。**
> うち、採用担当がいないので。

**原稿は挙げない。** 代理店の領域なので、挙げると「それは代理店がやってます」で終わる。
**代理店がやらない仕事だけを並べる。**

### 5｜先回りする（★必須・聞かれる前に言う）

> あ、先に言っておくと、
> **◯◯さんの仕事を減らす話であって、なくす話ではないです。**
> **それと、代理店さんを替える話でもないです。**
>
> うちがやってるのは、集計とかまとめとか、そういう作業のほうなので。
> **誰を採るか決めるのは、絶対に人です。**

消しておく敵が**2つ**ある。
① 担当の仕事を奪う疑い　② 代理店を奪う疑い。
**②を消し忘れると、担当が代理店をかばって話が終わる。**（代理店の営業と担当は年単位の付き合いがある）

### 6｜2点だけ確認（★ここで刺す場所が決まる）

- **Q6** 媒体はどちらを？　**ハローワークと紹介も併用されてます？**
- **Q7** 応募の管理って、**ATS（採用管理システム）入れてます？**

| 回答 | 刺し方 |
|---|---|
| **ATSなし** | 集計そのものが手作業。そのまま刺さる |
| **ATSあり** | 歩留まりは出る。ただし**ATSは掲載費を持っていない**ので**1人あたりいくら掛かったかは出ない**。そこを突く |

> ⚠️ **原稿・スカウト文面の話は一切しない。** 代理店の領域であり、かつ媒体AI（ビズリーチ等）の領域。二重に被る。

### 7｜社内政治の話（★一番刺さる・45秒）

- **Q8** 社長さんへの報告って月1くらいで出されてます？　あれ、どのくらいかかります？
  - ▶「半日はかかりますね…」
- **Q9** **代理店さんのレポートって、扱ってる媒体の分だけですよね？**
  - ▶「…そうですね」
- **Q10** じゃあ、**媒体ごとに1人採るのにいくら掛かったかって、出せてます？**
  - ▶「…ざっくりしか」 ← **★本命。掲載費は代理店側、面接と入社の数は社内側。突き合わせた人がどこにもいない**

> うち、そこもAIにやらせてまして。
> 媒体別に、いくら払って、何人面接まで来て、何人入って、何人残ってるか。
> そこまで出して、社長に渡すだけの形にしてます。

Q9・Q10は**構造的に必ず「出せていない」に着地する。** 相手を追い詰める質問ではなく、
**「出せていないのが当たり前」だと分かっている人だけができる質問**なので、詰問に聞こえない。

### 8｜アポ打診（★本命・無料オファーが社長への手土産になる）

> **30分だけいただいて、社長さんに出す報告資料を1本、無料で作らせてもらえませんか。**
>
> 代理店さんのレポートに、ハローワークと直接応募と紹介の分を足して、
> いくら払って、何人面接まで来て、何人入ったかまで並べた1枚にします。
> **代理店さんを替える話ではないので、そこはご安心ください。** 無料です。

- **Q11** 来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？

予備：**面接の記録を1人分、評価シートの形にする** ／ **採ったあとの受け入れ計画を1つ組む**（撮影不要・営業1人・30分で完結）

> ⚠️ **求人原稿は予備にも入れない。** 代理店 × 媒体AIで二重に埋まっている。

### 9｜手柄を譲る（★これが社長への橋になる）

> これ、**◯◯さんが作った形で社長さんに出してもらって大丈夫です。
> うちの名前は出さなくていいので。**

**名前を出さない提案をされると、逆に担当のほうから「ヒダネさんが作ってくれて」と言う。** 人は手柄を譲られると譲り返す。**社長が名前を口にした時点で商談が生まれる。**

### 10｜確定と仕込み（30秒）

- **Q12** 当日、**代理店さんのレポートと請求書**を見られる状態にしておいていただけますか？
- **Q13** ちなみに社長さんって、なんてお名前でしたっけ？（← 次回の名指し用。**不発でもこれは残す**）
- **Q14** 御社、今何名くらいでやられてます？（助成金判定。**電話では助成金の話をしない**）

Q12が重要。**請求書（＝掲載費）を出してもらわないと、当日の30分で採用単価が作れない。**
ここを電話で仕込んでおかないと、商談が「次回データください」で終わる。

> **これ、国の助成金が使える可能性があるんですけど、
> その話って◯◯さんの範囲ですか？　社長さんの範囲ですか？**

### 言わない

- ✕ 採用しなくてよくなります（**職業否定**）
- ✕ 人は採用する時代から作る時代へ（**社長専用のタグライン**）
- ✕ **求人原稿AIで書けます**（**代理店の領域。担当の痛みではない**）
- ✕ **代理店のレポート意味ないですよ／代理店替えたほうがいい**（**担当が代理店をかばう。その場で終わる**）
- ✕ 採用コストが下がります（予算＝権限が減る）
- ✕ 採用担当いらなくなりますね（冗談でも）
- ✕ 応募来てないですよね（決めつけ）／✕ 営業ではありません（嘘）
