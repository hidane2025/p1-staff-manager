## 🔑 電話で出す体 ── 蒔田ユイ ＋ 桐生ソウ

### 1体目：蒔田 ユイ（事務・法務・経理）

```
うちに、蒔田ユイっていう事務のやつがいるんですけど。

  ▶「え、社員さんですか？」

AIです。          ← ★ここで落ちる

受注が決まると、契約書と、名簿と、請求書と、スケジュール表が、
1時間で全部できてるんです。
契約書の中身もチェックして、
「ここの表記が古いので直しました」って言ってくる。
```

**なぜ蒔田ユイなのか**

| 条件 | 判定 |
|---|---|
| 全業界にあるか | **◎ 事務は100%ある。受注が発生する会社ならすべて** |
| 成果物が具体的か | **◎ 契約書・名簿・請求書・スケジュール表。物として明確** |
| 数字があるか | **◎ 受注後の書類作成 平均60分／申請の出し忘れゼロ** |
| 手抜きに聞こえないか | **◎ 相手への提案物ではない**（→ 下記の禁止事項） |
| 「勝手に」が言えるか | **◎「表記が古いので直しました」＝指摘してくる。指示していない証明** |
| ツール被り | 契約書レビュー（LegalForce等）は大企業向け。請求書は会計ソフト。**"受注したら書類一式が揃う"というまとまりは空いている** |

### 2体目：桐生 ソウ（AI部長）── 一言だけ

```
あと、AI部長っていうのがいて。桐生ソウっていうんですけど。
その12人に仕事を振り分けてるの、そいつなんです。人じゃなくて。
```

**AIの上司がAI。** この像を持っている社長はまずいない。**1日6.2件／月186件**という数字も出せる。

| **瀬川 リサ**（営業の下調べ・提案書） | **相手との商談の準備をAIでやっていると言うと、「私への提案も手抜きなんだな」と聞こえる。** 次のステップが相手との商談なので最悪の位置（2026-08-17 判断） |
| **鷹城 レン**（営業・フォローメール） | 同じ理由。営業系はすべて手抜きに聞こえるリスクがある |

## 🔑 全員に共通する、一番強い特徴

自社サイトの表現：

> **「学習し続ける、唯一の社員。」**
> **毎週、すべての機能を自動で改善。仕事から得た気づきがたまるほど、来月のAI社員は今月より必ず賢い。**
> **辞めることも、引き継ぎもない。**

電話で使う一言：

```
うちのAI社員、毎週勝手に自分を直してるんです。
先月より今月のほうが、確実に賢くなってて。

しかも辞めないので、引き継ぎもないんです。
```

**「辞めない・引き継ぎがない」は社長に一番効く。** 人を採る話の対比になる。

## 朝の会議（商談で使える絵）

自社サイトの記載：

> **毎朝、AI社員と会議をしている。**
> ソウが昨日のタスクを総括し、各社員に今日の優先順位を割り振る。
> **人間が判断するのは、最終承認だけ。**
> 人とAI社員が話し合う朝の30分。**その日にこなせる仕事量の8割は、ここで決まる。**

**電話ではなく商談で出す。** 「どうやって運用してるんですか」と聞かれた時の答え。
