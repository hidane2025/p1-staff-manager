```
✕ 「AI社員が12人います」→ 説明から入る

        ↓
   相手：「え、社員さんですか？」
```

**人名で紹介して、相手が人だと思った直後に明かす。**
本章の「事実 → 矛盾 → 種明かし」の型が、名前ひとつで成立する。

## 🔑 全員に共通する、一番強い特徴

**この8体には全員、同じ仕組みが入っている。**

```
仕事を1回終えるごとに、自分で自分を5軸で採点する
  （出力品質 / 要求合致度 / 情報精度 / 効率性 / 実用性）
        ↓
成功パターン・失敗パターン・上司の好みを記録に残す
        ↓
次回はそれを読んでから仕事に入る
        ↓
5回に1回、「今こういう状態です」と自分から報告してくる
```

**これが「ツール」ではなく「社員」と呼んでいる理由。**

> **ツールは同じことを繰り返す。社員は前回の反省を持って次に来る。**

電話で使う一言：

```
うちのAI社員、毎回自分で自分の仕事を採点して、
次から勝手に直してくるんです。

5回に1回、「最近こういう傾向があります」って
報告も上げてきますし。
```

**ここが「よく分からないけど聞いてみたい」の中心。**
AIが自己評価して改善する、という像は多くの社長が持っていない。

## 電話で出す順番

**12人いる、と言ったあとに全部説明しない。1〜2体だけ、具体的に。**

### 1番目に出す体（つかみ）

**営業準備担当**が最も無難で、かつ全業種に伝わる。

```
たとえば、営業準備の担当が1人いるんですけど、
会社名を1個渡すと、その会社を調べて、
提案書と商談の台本まで作って出してきます。

人間がやってた時は、1社で半日かかってたので。
```

### 2番目に出す体（笑いを取る）

**失注分析担当**。ここで空気が緩む。

```
あと、失注の分析だけやってる担当もいて。

商談が流れると、なんで流れたかを分析して、
「次はこう言え」って台本を直してくるんです。

…わりと厳しいんですけど（笑）
```

> **笑いが取れると警戒が一段下がる。** 押し売りの人間は笑わせない。

## 一番驚かれる可能性が高い体

### 報告書担当の「アップセル検出」

```
研修が終わったあと、受講者のアンケートをAIに読ませるんですけど、

報告書を作るだけじゃなくて、
「この会社、次はこの研修が要りますね」って
AIが勝手に見つけてくるんです。
```

**「AIが次の商談を見つけてくる」は、多くの社長が想像していない。**
しかも自社の話なので嘘がない。

## ❌ 言ってはいけないこと

| ✕ | なぜ |
|---|---|
| **「AI社員がいます」（人格があるかのように）** | 実体はAIに業務を覚えさせたもの。**聞かれたら正直に言う** |
| **「AI社員を導入しませんか」** | 商品の輪郭が曖昧なまま話が進む。**電話では売らない** |
| **確認できていない4体について具体的に語る** | 嘘になる。**知らないものは言わない** |
| **12体全部を電話で説明する** | 説明が長いほど「AIで効率化」の棚に入る。**1〜2体だけ** |

### 「それって結局AIツールでしょ？」と言われたら

```
はい、実体はAIです。人格があるわけじゃないです。

ただ、ツールと違うのは、
うちの仕事のやり方を覚えさせてあるところで。

だから他社さんが同じものを買っても、
たぶん同じようには動かないです。
```

**正直に認めたうえで、違いを1つだけ言う。** ごまかすと信用を失う。
