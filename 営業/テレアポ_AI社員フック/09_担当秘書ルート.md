# 09. 担当秘書ルート ── 「全員に秘書をつけます」で担当アポを取る

作成日：2026-08-17

> 🚨 **担当ルートはこれが最新。[06章](06_採用担当ルート.md)は経緯として残しているだけで、使わない。**
> 印刷用は `テレアポ台本カード_担当秘書_A4.pdf`（A4縦1枚）。

---

## 0. 何を変えたのか

06章（採用担当ルート）は**担当に刺さらない**。理由は3つ。

| 06章の問題 | なぜ刺さらないか |
|---|---|
| 主語が「会社」だった | 「社長に出す報告資料を作ります」＝ **担当の得が間接的**。自分に何が起きるか分からない |
| 商材が採用業務に限定されていた | 相手は総務・人事・労務の兼任。**採用は担当業務の一部でしかない** |
| 「AI社員」という言葉を隠していた | 隠すと具体性が消える。担当は「何をされるのか」が分からないまま断る |

### 転換

> **✕「御社の業務を効率化します」（会社が主語・抽象）**
> **◎「◯◯さんに、秘書を1人つけます」（相手が主語・具体）**

そして全社に広げる。

> **「社員さん一人ひとりに、秘書を1体つけます。」**

---

## 1. なぜ「秘書」なのか ── 社員と秘書は同じものだが、逆に聞こえる

**ヒダネが作るものは同じ。呼び方だけを相手によって変える。**

| | 社長に言うとき | 社員・担当に言うとき |
|---|---|---|
| 呼び方 | **AI社員** | **担当秘書** |
| 聞こえ方 | 人を増やさずに済む＝**コストが減る朗報** | 自分に補佐がつく＝**純粋に得** |
| 買う理由 | **代替**を買う | **補佐**を歓迎する |
| 言ってはいけない相手 | 社員（自分の代わりに聞こえる） | 社長（増員に聞こえる） |

> ⚠️ **能力を偽ってはいけない。変えるのは「範囲の言い方」だけ。**
> 「社長には代替と言い、担当には補佐と言う」が矛盾しないのは、**秘書を本人が作るから**。

### 「本人が作る」が全ての根拠

ヒダネは研修の会社なので、**秘書は受講者本人が作る。**

```
本人が作る → 本人の言い方・判断・段取りを覚える → 本人の秘書になる
                                              ↓
                          だから「代わり」ではなく「補佐」で、これは事実
```

**この一文が言えないと、この台本は全部嘘になる。** 逆にここが言えると、
「仕事がなくなるのでは」という最大の反論に**構造で答えられる**。

## 2. なぜ担当アポとして機能するのか

| 理由 | 中身 |
|---|---|
| **職業否定がゼロ** | 秘書がつくのは誰にとっても嬉しい。「手が空きます」より「秘書がつきます」 |
| **担当が主役になれる** | 全社員に配るのは総務・人事の管轄。**社内で「秘書を配った人」になる** |
| **社長案件に自然に化ける** | 全員分＝人数×なので予算が必要 → **担当自身が「社長ですね」と言う** |
| **見せるものを持って社長に行ける** | 担当の1体目を無料で作る＝ **手土産が動くデモになる** |
| **助成金と噛み合う** | 研修なので人数分の規模が出る。ヒダネの本商材そのもの |

### 06章との決定的な違い

```
06章：無料オファー（報告資料）→ 紙 → 社長が見る → たぶん商談
09章：無料オファー（担当の秘書1体）→ 動くもの → 担当が毎日使う → 担当が社長に見せたくなる
```

**担当が自分の秘書を毎日使っている状態を作れば、担当が売り込む側になる。**

## 3. 助成金との整合（電話では出さない）

**2026-08-03 改正**で「全社員向けAIリテラシー研修」「汎用プロンプト講座」は助成対象外になった。
汎用のAI研修は、もう売れない。

> **「社員一人ひとりが、自分の職務専用の秘書を作る」＝ 職務直結。**
> **改正後に残る形はこれ。**

| | 対象外になった形 | 本商材の形 |
|---|---|---|
| 内容 | 全社員向けAIリテラシー／汎用プロンプト | **各自の職務に直結した秘書を各自が作る** |
| 成果物 | なし（知識） | **本人の業務を実行する秘書1体** |
| 職務との関係 | 汎用 | **職務そのもの** |

⚠️ **数字と可否は社労士確認が前提。** 二次情報のみ。**電話では助成金を出さない**（商談で出す）。

## 1-2. 受付で誰を呼び出すか ── 答えは「総務」

### 受付が転送を決めている3つの基準

| 基準 | 中身 |
|---|---|
| ① **その役職が実在するか** | 存在しない役職を指名すると「そういう者はおりません」で即終了 |
| ② **受付の権限で断れる用件か** | 「営業はお断りしてます」と言えるカテゴリなら切られる |
| ③ **繋いだ後に怒られないか** | 受付が最も恐れるのは「なんでこんな電話繋いだの」と言われること |

### 候補の評価

| 指名 | 実在するか | 判定 |
|---|---|---|
| **総務のご担当の方** | **20〜100名でほぼ100%** | **◎ 本命** |
| 人事のご担当の方 | 30名以下では独立していない | △ 100名超なら可 |
| 社内システムのご担当の方 | **肩書きとしては存在しない**（総務兼任・PCに詳しい人） | **✕**（下記） |
| AIのご担当の方 | **ほぼ存在しない** | **✕ 最悪** |
| 教育・研修のご担当の方 | 専任はいない | ✕ 研修の営業と即分類される |
| 管理部の方 | 名称が会社ごとに違う（総務部・経営管理部・業務部…） | △ 外すと即死 |

### なぜ「AIのご担当」が最悪か

**20〜100名でAI担当を置いている会社はほぼない。** 「おりません」で終わる。
さらに悪いのは、**一度受付に「該当者なし」と判断させると、次に別の役職を言っても言い訳がましくなって復帰できない。**

### なぜ「社内システムのご担当」がダメか

繋がりはする（受付は「PCが壊れたとき呼ぶ人」を思い浮かべられる）。**繋がる先が悪い。**

- 情シス寄りの人は「**ITツール導入の検討**」のフレームで聞く
  → 「もう入れてます」「セキュリティが」「稟議が必要」で終わる
- **予算も決裁権も社長への影響力も弱い**ことが多い
- 「AIツールの営業」と分類されやすい

**秘書の話が"ツール検討"にすり替わった時点で負け。**

### なぜ「総務」が正解か

| 理由 | 中身 |
|---|---|
| **実在する** | 20〜100名で**ほぼ確実に存在する唯一の名称**。兼任でも「総務」という言葉は通じる |
| **受付自身が総務のことが多い** | 20〜50名だと電話を取っているのが総務。**指名した相手がすでに電話に出ている＝転送ロスがゼロ** |
| **外れても正しい人を教えてくれる** | 総務は社内で誰が何をやっているか知っている**唯一の部署**。指名を外した時のリカバリが唯一きく |
| **用件と噛み合う** | 「全社員に1体ずつ配る」は総務の管轄そのもの。人事だと「採用の話？」と誤解される |

### ⚠️ 通るかを決めているのは役職名ではない

**役職名の役割は「その人が実在する」ことを担保するだけ。**
実際に切るか通すかを決めているのは、**用件が分類できるかどうか。**

> 「社員さん一人ひとりに秘書をつける、という仕事をしてまして」

これが分類できないので、受付は断り文句を選べない。
**「研修の件」「AIのご提案」だとその場で営業と分類されて終わる。**

だから「ご用件は？」と聞かれたら **同じ言葉をそのまま繰り返す。言い換えない。**

### 規模での使い分け

| 従業員数 | 指名 |
|---|---|
| 〜30名 | **総務のご担当の方**（そもそも社長か総務しかいない） |
| 30〜100名 | **総務のご担当の方** → 出たら「社員さんの研修とかも◯◯さんが見られてますか？」で正しい人に辿る |
| 100名〜 | 人事のご担当の方も成立する |

## 3-2. 当日見せるもの ── ヒダネのGoogleカレンダーで、その場で実演する

**確認済み（2026-08-17）：**

- 予定を言うだけで**Googleカレンダー**に入り、リマインドする秘書は**既にヒダネが使っている**
- 30分で相手専用の1体は作れない。**が、作る必要がない**
- **商談の場で営業が予定を言い、ヒダネのカレンダーに入るところを実際に見てもらう**

### だから「作ってから伺います」ではなく「見てもらうだけ」

| | ✕ 作らせてください | ✕ 専用を作ってから伺います | ◎ その場でお見せします |
|---|---|---|---|
| 当日できるか | **できない** | **できない**（相手専用は用意できない） | **できる。今使っているものだから** |
| 相手の負担 | 30分作業する | 見るだけ | **見るだけ** |
| 事前準備 | — | **1件ごとに必要** | **ゼロ** |
| 営業1人で回るか | ✕ | △（件数が増えると破綻） | **◎ 何件でも回る** |

> **「30分だけ、見てもらうだけでいいので、いただけませんか。」**
> **「うちが今使ってる秘書を、その場でお見せします。**
> **私が予定を言って、カレンダーに入るところまで、実際に。」**
> **「同じものを、◯◯さん専用に作れます。」**

**「見てもらうだけ」は、断る理由が作れない一番低いお願い。**
そして実演そのものが「**本当に使っている**」の証明になる ──
「社員3人にAI社員12人」という話の裏付けが、その場で取れる。

> ⚠️ **「◯◯さん専用を作ってから伺います」とは言わない。** 当日用意できないので崩れる。
> 専用に作るのは**導入後（研修）の話**として言う。

### ⚠️ 被りチェック ── 機能で勝とうとしない

「予定を声で入れる」だけなら **Siri／Googleアシスタント／Outlookの音声入力でも一応できる。**
**機能の説明で勝とうとすると「それSiriでできますよね」で終わる。**（→ v2のATSと同じ轍）

| 論点 | 状況 |
|---|---|
| 予定を声・文で登録する | **コンシューマのAIアシスタントで可能。ここでは勝てない** |
| リマインドする | カレンダー標準機能 |
| **全社員が実際に使えている状態** | **ここは誰も埋めていない。ヒダネの商材（研修）そのもの** |

> 切り返し：「それSiriでできますよね」
> → **「できます。でも部署の全員が使ってる状態って、なってます？」**
> → **「うちは全員に1体ずつ配って、使える状態にするところまでなので。」**

**機能勝負を避けて、研修としての価値に着地させる。**

### Googleでない相手にどう答えるか

- **Google** → 「そのまま同じ形でいけます」
- **Outlook・その他** → **実演は見せられる。導入可否は「確認してお答えします」**

> ⚠️ **「たぶんできます」と言わない。** 確認していないことを言うと商談で崩れる。
> 電話のQ10で先に聞いておけば、Google以外の相手には最初から言い方を変えられる。

## 3-3. 事前準備と、当日30分の使い方

### 事前準備 ── 1件ごとの準備はゼロ

1. **営業の端末で、秘書とGoogleカレンダーにログイン済みにしておく**
2. 対面ならPCを開いて見せる／オンラインなら画面共有
3. カレンダーに**見せられない予定が映らないようにしておく**（別カレンダーか、表示を絞る）

**相手ごとに作るものは何もない。** だから
「無料オファーは営業1人が30分で完結するか」という原則（→ [07章](07_商材の再設計.md)）を
**完全に満たす。テレアポの本数をいくら増やしても破綻しない。**

### 当日30分の配分

| 時間 | 中身 |
|---|---|
| 0–10分 | **実演。** 営業が予定を言う → Googleカレンダーに入る → リマインドを見せる |
| 10–20分 | **全員分の話。** 「これを全員に1体ずつ」→ 人数×＝社長の決裁 |
| 20–30分 | **社長を5分呼ぶ**（or 担当から社長に話してもらう約束＋次回に同席） |

**助成金は商談で出す。** 全員分＝研修なので、人数分の規模が出る。

## 4. 通し台本（A4カードと同一）

**全体で3分。** カードとこの節が食い違ったらこちらが正。

### 1｜受付突破

> お世話になります、名古屋のヒダネと申します。
> **社員さん一人ひとりに秘書をつける、という仕事をしてまして。**
> **総務のご担当の方**、いらっしゃいますか。

**分類できない言葉なので、受付が断り文句を選べない。**
「研修の件」だと営業と判定されて切られる。「秘書」は聞き返される＝会話が始まる。

分岐：

| 受付の反応 | 返し |
|---|---|
| **「私が総務ですが」** | そのままQ1へ。**20〜50名では一番多い（受付＝総務）** |
| **「ご用件は？」** | **言い換えず同じ言葉を繰り返す。** 言い換えたら営業になる |
| **「総務はおりません」** | 「社員さんの研修とか見られてる方は、どなたになりますか？」 |

> ⚠️ **✕AI担当・✕社内システム担当・✕研修担当は指名しない。**
> 理由は [1-2節](#1-2-受付で誰を呼び出すか--答えは総務)。

### 2｜名乗り・時間の合意（20秒）

- **Q1** 総務のご担当の方でいらっしゃいますか？
- **Q2** 突然すみません、名古屋のヒダネの◯◯です。**3分だけ**、よろしいですか？

### 3｜引っかける（★ここが分岐点・30秒）

- **Q3** ◯◯さん、**秘書ってついたことあります？**
  - ▶「ないです（笑）」

> ないですよね。うち、社員3人しかいないんですけど、
> **全員に秘書がついてまして。** 私にも1人、専属で。

- ▶「え、3人で？」 ← **ここで聞き返させる**

> はい。AIで作った秘書なんですけど、**1人1体**。

> ⚠️ **「AI社員」と言わない。** 社員＝自分の代わりに聞こえる。**秘書＝自分に補佐がつく。**
> ここを間違えると3秒で敵になる。

### 4｜具体的に言う（★どの職種でも成立する話から・40秒）

- **Q4** ◯◯さん、**予定って自分でカレンダーに入れてますか？**
  - ▶「入れてますね」

> それ、秘書に言うだけで済みます。
> 「来週の火曜14時に◯◯社」って言ったら、そのままカレンダーに入って、
> 当日の朝に「今日はこれです」って教えてくれます。
>
> **今この電話でもできるんですけど、画面がないので。当日お見せします。**

最後の一言が**アポの理由を先に作る**。「見せる」と言われた側は、見たくなる。

- **Q5** あと◯◯さんの場合…**社内から質問される回数って、1日何回くらいですか？**
  - ▶「けっこう来ますね…」 → 有給の残り・経費の出し方・書類の場所。**そこも秘書が一次対応します**

**予定の話は全職種で通る（＝誰にかけても使える）。** そこに相手の職種の話を1つだけ足す。
**計2つだけ。並べると薄まる。**

> ⚠️ **機能の説明で勝とうとしない。**「予定を声で入れる」はSiriでもできる。
> **売り物は「全員が使えている状態を作る」こと。**（→ [3-2節](#3-2-当日持っていく秘書--予定の登録リマインド)）

### 5｜先回りする（★必須・聞かれる前に言う）

> 先に言っておくと、**◯◯さんの代わりを作る話ではないです。**
> **部下でもなくて、秘書です。** 指示を出すのは◯◯さんなので。
>
> うち研修の会社なので、**1体目はうちが作りますけど、2体目は◯◯さんが作れるようになります。**

**本人が作れるから、本人の言い方と判断を覚える。** これが「代替ではない」の根拠。

**「1体目はうち、2体目から本人」**が、事前に作って持参する形と矛盾しない唯一の言い方。
（「全部本人が作ります」と言うと、当日ヒダネが作ったものを見せる説明がつかない）

### 6｜全員分の話にする（★ここで社長案件になる）

> これ、最終的には**全員に1体ずつ配る形**になるんですけど、
> **最初の1体は◯◯さんのを作りたいんです。** 使ってもらわないと、配れないので。

- **Q6** 御社、今何名くらいでやられてます？（＝秘書の体数。助成金判定も兼ねる）

**秘書を配る側になるのは総務。** 担当が主役になり、社内で「配った人」になる。

### 7｜新人の話（採用の文脈に接続・25秒）

- **Q7** 新しく入った方って、最初の1か月、誰が見てます？
  - ▶「私か、現場ですね」

> これ、**新人さんにも入社初日から1体つけられます。**
> 同じことを10回聞かれるのが、◯◯さんじゃなくて秘書になるので。

採ったあとの教育工数は、**担当の痛みなのに職業否定にならない唯一の場所。**
採用の話をするならここだけ。

### 8｜アポ打診（★本命・見てもらうだけ）

> **30分だけ、見てもらうだけでいいので、いただけませんか。**
>
> うちが今使ってる秘書を、その場でお見せします。
> 私が予定を言って、カレンダーに入るところまで、実際に。
> **同じものを、◯◯さん専用に作れます。**

- **Q8** 来週だと、火曜の午後か木曜の午前、どちらが動きやすいですか？

| | |
|---|---|
| ✕「御社の社員を1人作らせてください」 | ＝**自分の代わりが来る** |
| ✕「◯◯さんの秘書を**作らせてください**」 | ＝相手の30分を作業に使う＋**当日作れない** |
| ✕「専用のを**作ってから伺います**」 | ＝**当日用意できないので崩れる** |
| ◎「**その場でお見せします**」 | ＝**断る理由が作れない一番低いお願い** |

**「見てもらうだけ」が最強の理由：相手が失うものが30分の時間だけで、作業がゼロ。**
そして専用に作る話は、**導入後（研修）の話として後ろに置く。**

### 9｜社長へ渡す（★動くものがあるから当日呼べる）

- **Q9** 全員分だと人数×の話になるので、そこは**社長さんの決裁ですよね？**
  - ▶「そうですね」

> じゃあ当日、**社長さんも5分だけ覗いてもらうことできませんか。**
> 実際に動かして見せるので、そのほうが早いと思うんです。

**実演があるから「当日の同席」を頼める。** ここが06章から一番変わった点。
しかも社長に頼むのも「**見るだけ5分**」なので断りにくい。

断られたら2段構え：
> 「じゃあ◯◯さんから社長さんに、**見た話をしてもらえませんか**」

**助成金は電話で出さない。商談で出す。**

### 10｜確定と仕込み（30秒）

- **Q10** **◯◯さんのところ、カレンダーってGoogleですか？**
  - **Google** → 「そのまま同じ形でいけます」
  - **他** → 実演は見せられる。**導入可否は「確認してお答えします」**（できると言わない）
- **Q11** ちなみに社長さんって、なんてお名前でしたっけ？（← 次回の名指し用。**不発でもこれは残す**）
- **Q12** 当日は◯◯さんが普段使ってるパソコンで大丈夫ですか？

> ⚠️ **Q10は「当日動くか」ではなく「同じものを約束できるか」の確認。**
> 実演はヒダネのカレンダーで完結するので、相手が何を使っていても実演自体はできる。

## 7. 言わない

- ✕ **AI社員**（**社長専用。担当には必ず「秘書」**）
- ✕ 人が要らなくなります／省人化／人件費
- ✕ **部下ができます**（管理が増えると取られる。秘書と部下は違う）
- ✕ ◯◯さんの**手が空きます**（暇だと言われたと取られる）→ ◎「**秘書がつきます**」
- ✕ 御社の社員を1人作らせてください（**自分の代わりが来ると聞こえる**）
- ✕ 全員分でいくらです（**電話で金額を出さない**）
- ✕ 助成金（**電話では出さない。商談で出す**）
- ✕ 求人原稿AIで書けます（代理店の領域＋媒体AIと二重に被る）
- ✕ 営業ではありません（嘘）
