## 2-2. ① ギグワーク／フードデリバリー市場 — 「稼ぎにくくなっている」

| 指標 | 数値 |
|---|---|
| 国内フードデリバリー市場 | 2019年 約2,600億円 → 2025年 約7,500億円 |
| Uber Eats 配達員数 | 全国 約10万人（2020〜21年時点）／全国展開時 最大20万人見通し |
| 時給換算 | 約1,200〜1,800円 |
| 副業レンジ（週10〜15h） | 月5万〜10万円 |
| 専業レンジ（週40h〜） | 月25万〜40万円 |

**2026年の実情：** 報酬体系の変動により「**稼げる人と稼げない人の二極化**」が進行。完全出来高制のため最低賃金保証がなく、注文の少ないエリア・時間帯は収入ゼロのリスクがある。単純に時間を投下するだけでは成立しなくなっている。

**制度面：** 2024年11月施行の「特定受託事業者に係る取引の適正化等に関する法律（フリーランス法）」により、ギグワーカーを含むフリーランスの就業環境整備が進行中。

> **商談での使いどころ：** 「6月から始めて、思ったより単価読めなくないですか？」は事実に基づいた共感になる。相手は3ヶ月目で、ちょうど二極化を体感し始める時期。

## 2-3. ② MLM／連鎖販売取引市場 — 「縮小し、規制が強まる」

| 指標 | 数値・動向 |
|---|---|
| 業界売上（国内） | **2025年 前年比 ▲3.0%（減少）** |
| 大手動向 | 業界最大手も二桁の減収を記録。一部企業（フォーデイズ等）のみ安定成長 |
| 若年層トラブル | 「**モノなしマルチ商法**」の相談は20歳代・20歳未満で増加傾向 |
| 相談構造（参考値） | マルチ商法相談 10,526件のうち「役務（モノなし）」5,490件、うち29歳以下 2,481件 |
| 全国の消費生活相談総数 | 2024年度 91.0万件（前年度 89.3万件から約2万件増） |

**規制動向（重要）：**
- 2025年の特商法改正で、**誇大広告・不当勧誘への罰則が強化**
- 2026年1月に検討会が設置され、**2026年夏頃に中間とりまとめ**の予定
- 論点に **「SNS広告規制」「連鎖販売取引の追加ルール」** が含まれる
- 改正法の成立・施行は**2027年以降**の見込み
- 現行法上も、連鎖販売取引の勧誘時には**氏名等の明示義務**（統括者名を含む）、不当勧誘の禁止、概要書面・契約書面の交付義務がある

**関連する行政処分の例：**
2025年12月、関東経済産業局がアドネス株式会社に特商法違反で行政処分。**支払い能力に見合わない高額契約を、借入させてまで即決させる勧誘**が「適合性原則違反」と認定された。
消費者庁も2025年12月19日に「在宅ワークの求人情報をきっかけに、高額なコンサルティング契約をさせる事業者に関する注意喚起」を公表。

> **商談での意味：** 相手が言う「リアルな人脈に頼る集客の限界」は、個人の努力不足ではなく**市場全体の構造的な縮小と規制強化**の反映。ここを理解していることを示せると、一気に信頼を得られる。
> **同時にヒダネ側のリスク：** この市場はいま規制強化のど真ん中にある（→ 04_商談台本.md の「線引き」）。

## 2-4. ③ Web広告市場 — 「相手が正しく賭けている市場」

**電通「2025年 日本の広告費」（2026年3月5日発表）**

| 区分 | 金額 | 前年比 |
|---|---|---|
| 総広告費 | **8兆623億円** | 105.1%（4年連続で過去最高） |
| インターネット広告費 | **4兆459億円** | 110.8%（**初の4兆円超・構成比50.2%で初の過半**） |
| ビデオ（動画）広告 | **1兆275億円** | 121.8%（**推定開始以降 初の1兆円突破**） |
| ソーシャル広告 | **1兆3,067億円** | 118.7%（ネット広告媒体費の39.5%） |

**読み取れること：** 相手が「Web広告の現場で修行」を選んだ判断そのものは、市場的に**極めて合理的**。広告費が初めてネット中心（過半）に転換した年に、その現場に入っている。

> **商談での使いどころ：** ここは素直に肯定していい唯一かつ最大のポイント。「Web広告に振ったのは、数字で見ると正解だと思います」から入ると、相手の防御が下がる。

## 2-5. ④ ショート動画市場 — 「相手が欲しがっているピース」

| 指標 | 数値 |
|---|---|
| 生活者のショート動画視聴 | **5割が日常的に視聴**、そのうち **7割が「購買行動に影響を受けた」** |
| 動画広告市場 | 1兆275億円（前年比121.8%）／2026年に1兆円超の見通し |
| マイクロドラマ（縦型連続コンテンツ） | 世界78億ドル規模に到達 |
| ライブコマース×ショート連動 | 日本市場 2,000億円超の予測 |

**Threads（相手の主戦場）の伸び：**

| 指標 | 数値 |
|---|---|
| 世界の月間アクティブアカウント | **5億突破**（2026年6月、Meta発表） |
| 国内ユーザー数 | **約1,700万人**（2年で約4倍） |
| 国内の利用時間 | **前年比130%増（＝2.3倍）**。アジア太平洋で日本が突出 |

**相場観（相手が値付けを知らない可能性が高い領域）：**

| 業務 | 相場 |
|---|---|
| SNS運用代行（フリーランス） | 月2万〜10万円 |
| SNS運用代行（代行会社） | 月10万〜50万円 |
| ショート動画制作（単発） | 1本 7,500円〜（業界最安値水準の事例） |
| フリーランスの収入レンジ | 複数アカウント担当で月10万〜30万円／専業で月30万〜50万円以上も |

> **商談での使いどころ：** 相手は「ショート動画が得意な人と協業したい」と言っているが、**その業務にいくら払うつもりなのかを恐らく設計していない**。ここを一緒に整理してあげるだけで、相手にとって明確な価値提供になる（→ 無料で渡せるギブ）。
